# Анализ: Первый запрос

## Запрос от клиента

Клиент отправляет:
- `context.new_task`: "исправить импорты"
- `codeBlocks`: package.json, composer.json

## Проблема

Пользователь НЕ указал:
- Какие файлы перемещены
- Откуда и куда
- Какие импорты сломаны

## Что система ДОЛЖНА сделать

### Шаг 1: Понять контекст
Система НЕ знает:
- Что произошло в проекте
- Какие изменения были сделаны
- Какие файлы затронуты

### Шаг 2: Получить информацию
Варианты:
1. **Git diff** — посмотреть, что изменилось
2. **Анализ проекта** — найти несоответствия
3. **Вопрос пользователю** — уточнить детали

### Шаг 3: Выполнить задачу
После понимания контекста — механически исправить импорты.

## Ключевой вопрос

**Как система узнает, что произошло в проекте?**

Без знания изменений — задача нерешаема даже для механического случая.

## Варианты решения

### Вариант 1: Git-интеграция
- Клиент анализирует `git status` / `git diff`
- Отправляет список изменённых файлов
- Сервер понимает контекст

### Вариант 2: Анализ проекта
- Найти все импорты
- Проверить существование файлов
- Найти сломанные импорты

### Вариант 3: Интерактивный диалог
- Сервер спрашивает: "Какие файлы перемещены?"
- Пользователь отвечает
- Система выполняет
