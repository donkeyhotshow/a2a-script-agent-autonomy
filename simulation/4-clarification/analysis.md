# Анализ: Уточнение и инструкции

## Что произошло

1. Клиент ответил на вопрос сервера: выбран вариант `Domain\` для `src/Domain/`
2. Клиент добавил правило в `psr4_rules`: `"Domain\\": "src/Domain/"`
3. Сервер пересчитал expected_namespace для файлов
4. Сервер сформировал инструкции для исправления

## Ключевой момент

Сервер НЕ исправляет файлы сам. Он только:
1. Анализирует контекст
2. Определяет нарушения
3. Формирует инструкции

Клиент применяет исправления локально.
