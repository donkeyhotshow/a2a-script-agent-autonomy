# Вариант 1: Сбор контекста для внешнего AI

## Описание варианта

Система выступает в роли интеллектуального помощника для внешних AI-систем (Claude, GPT, другие LLM). Основная задача — найти и подготовить релевантный контекст из кодовой базы, чтобы внешний AI мог эффективно анализировать код и предлагать изменения.

## Роль клиента

Клиентская часть (`a2a-client`) выполняет следующие функции:

1. **Сканирование проекта** — определение структуры, технологий, зависимостей
2. **Индексация кода** — создание векторных индексов для семантического поиска
3. **Формирование запросов** — подготовка структурированных запросов к серверу
4. **Получение контекста** — запрос релевантных файлов по задаче
5. **Подготовка промпта** — упаковка контекста для внешнего AI

### Пример workflow клиента

```
Пользователь: "Нужно добавить валидацию email в форме регистрации"
    ↓
Клиент: Семантический поиск → "registration", "validation", "email"
    ↓
Клиент: Запрос к серверу → получить релевантные файлы
    ↓
Клиент: Формирование промпта для Claude/GPT с контекстом
    ↓
Внешний AI: Анализ и предложение изменений
```

## Роль сервера

Серверная часть (`a2a-server`) выполняет:

1. **Хранение индексов** — векторные индексы кодовых баз
2. **Семантический поиск** — поиск релевантных фрагментов по embedding
3. **Анализ связей** — использование графа знаний для расширения контекста
4. **Ранжирование результатов** — сортировка по релевантности
5. **Формирование ответа** — структурированный контекст для клиента

### API endpoints

```
POST /api/v1/requests
{
  "project_path": "/path/to/project",
  "query": "email validation registration",
  "max_files": 10,
  "include_related": true
}
```

## Преимущества

| Преимущество | Описание |
|--------------|----------|
| **Минимальная сложность** | Сервер не требует интеграции с LLM API |
| **Гибкость** | Пользователь выбирает любой внешний AI |
| **Контролируемость** | Человек видит весь контекст перед отправкой |
| **Экономия** | Не платим за AI-токены на сервере |
| **Прозрачность** | Понятно, какие файлы передаются AI |

## Недостатки

| Недостаток | Описание |
|------------|----------|
| **Ручной процесс** | Требуется копирование результатов в AI |
| **Ограниченный контекст** | Внешний AI не видит весь проект целиком |
| **Нет обратной связи** | AI не может запросить дополнительный контекст |
| **Задержка** | Дополнительный шаг между поиском и анализом |

## Пример использования

### CLI

```bash
# Получить контекст для задачи
npm run context "add email validation to registration"

# Результат: список файлов с релевантными фрагментами
# Готов для копирования в Claude/GPT
```

### Программно

```javascript
const client = new A2AClient('http://localhost:3000');

const context = await client.getContext({
  query: 'email validation registration',
  maxFiles: 10,
  includeRelated: true
});

// context.files — релевантные файлы
// context.snippets — ключевые фрагменты
// context.graph — связанные сущности
```

## Метрики успеха

1. **Точность поиска** — доля релевантных файлов в топ-10
2. **Полнота контекста** — процент необходимых файлов найден
3. **Время поиска** — скорость получения контекста
4. **Удовлетворённость** — полезность контекста для AI
