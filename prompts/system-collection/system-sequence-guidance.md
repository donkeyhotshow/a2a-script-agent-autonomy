# System Sequence Guidance for Gray-Room Prompts

Собрали рекомендации из `prompts/version-1/` и `!!!!!!!!cursor_file_analysis_for_versioning_an.md`, которые описывают последовательный pipeline и шаги для AI-редактора:

## 1. Базовые файлы, которые уже покрывают регламент
- `system/process.txt`, `system/standards.txt`, `system/guides.txt` (валидация, проверки, мониторинг, очередь)
- `system/start.txt` и `system/claude_instructions.txt` задают общий входной контекст, ограничения и способ взаимодействия

## 2. Что добавить для последовательности (Chain)
-- **`system/sequence.txt`** (или аналог) описывает типовую цепочку действий:
  1. Валидация структуры
  2. Поиск проблемной ноды
  3. Генерация промта для правки
  4. Применение мутации
  5. Повторная валидация
  6. Переход к следующей ноде/итерации
  7. Финальный сборник результата
- Дополнительные инструкции по шагам размещаются в `mutation/step_prompts.txt` и `mutation/chain_examples.txt`

## 3. Пример содержания step-by-step промтов
```
## 1. Find Error
Input: <JSON>
Prompt: Найди первую ошибочную ноду и опиши ошибку.

## 2. Propose Fix
Input: <JSON>, <описание ошибки>
Prompt: Предложи минимальное исправление.

## 3. Apply Mutation
Input: <JSON>, <исправление>
Prompt: Применить исправление и показать результат.

## 4. Validate
Input: <JSON>
Prompt: Проверь, остались ли ошибки. Если да — повтори.

## 5. Chain Example
Input: <исходный JSON>
Output: <шаги> … <финальный JSON>
```

## 4. Общие принципиальные пожелания
- Разделять input, prompt, output и объяснение в каждом файле
- Поддерживать примеры edge-case (вложенные структуры, смешанные типы)
- Помнить, что промты показывают методику; фактическим ответом остаются данные очереди и подтверждения шага от агента.
- В `system/ai_editor_instructions.txt` (или аналог) описать роль "AI-редактор" и ожидаемый формат для каждой итерации
- Общий pipeline должен быть задокументирован в `system/sequence.txt` или связанном README

Этой коллекцией теперь можно запатчить `prompts/system-collection` под серую комнату — все важные системные файлы, шаблоны и последовательности собраны рядом.
