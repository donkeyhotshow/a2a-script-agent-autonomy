# S11: Редкие request.md/response.md в sync — слабое покрытие промпт-пайплайна

## Проблема
- В sync-симуляциях мало файлов `request.md` и `response.md`
- Это означает слабое покрытие LLM snapshot-тестирования
- Промпт-пайплайн не проверяется на реальных данных

## Связь с AGENTS.md
- AGENTS.md указывает на необходимость тестирования промпт-пайплайна
- Без request.md/response.md нет возможности проверить трансформации

## Критерий 完成
- Каждая симуляция с server-transforms должна иметь request.md/response.md
- Покрытие промпт-пайплайна значительно улучшено
