# Задача: Дедупликация функций валидации конфигурации

## Проблема
Функции валидации конфигурации дублируются в нескольких файлах:
- `a2a-server/packages/server-config/index.ts` (строки 212-230)
- `a2a-server/packages/server-config/loader.ts` (строки 27-50)
- `a2a-server/packages/server-config/index.js` (строки 189-205)

## Дублирующиеся функции
- `validateConfig()` - одинаковая логика в нескольких местах
- `validateConfigSafe()` - повторяется с идентичной реализацией
- `validatePorts()` - несколько реализаций в разных файлах

## Тип
ВЫСОКИЙ приоритет (HIGH SEVERITY)

## Решение
1. Создать единственный модуль валидации конфигурации `config-validator.ts`
2. Перенести все функции валидации в этот модуль
3. Переэкспортировать из barrel-файлов (`index.ts`)
4. Обновить импорты во всех зависимых файлах
5. Удалить дублирующиеся функции из `loader.ts` и `index.js`

## Ценность
- Упрощение обслуживания
- Единая точка для изменений конфигурации
- Снижение риска ошибок при обновлении
