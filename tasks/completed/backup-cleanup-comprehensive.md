# Задача: Полная очистка папки резервных копий и артефактов миграции

## Проблема
Папка `.kilo/scripts/duplicates/backups/` содержит все резервные копии файлов и артефакты с предыдущих миграций:
- Файлы из `final-1775839775762/` с полной копией структуры проекта
- Файлы с суффиксами `.import-fix-backup` и `.comprehensive-fix-backup`
- Старые скрипты миграции, которые больше не используются

## Тип
СРЕДНИЙ приоритет (MEDIUM SEVERITY)

## Решение
1. Скопировать важные данные (если они есть) в DEV_STATE или документацию
2. Удалить всю папку `.kilo/scripts/duplicates/`
3. Удалить все файлы с суффиксами миграций из активной кодовой базы
4. Обновить `.gitignore` для игнорирования артефактов миграции:
   ```
   *.import-fix-backup
   *.comprehensive-fix-backup
   .kilo/scripts/duplicates/backups/
   ```
5. После удаления выполнить `git gc` для очистки репозитория

## Ценность
- Чистый репозиторий без мусора
- Уменьшение размера клонирования репо
- Упрощение навигации по проекту
