# Задача: Дедупликация логики валидации запросов

## Проблема
Логика валидации запросов дублируется в нескольких пакетах:
- `a2a-server/packages/server/src/routes/index.ts` (строка 37)
- `a2a-server/packages/protocol/src/types/entity.guards.ts` (строка 23)
- `a2a-client/packages/sdk/src/server/lib/session-routes-shared.ts` (строка 82)

## Дублирующиеся функции
- `validateRequestToServer()` - повторяется в нескольких пакетах
- `isRequestLike()` - guard функция дублируется
- `validateInvokeRequest()` - логика валидации разбросана по файлам

## Тип
СРЕДНИЙ приоритет (MEDIUM SEVERITY)

## Решение
1. Переместить все функции валидации в `a2a-server/packages/protocol/src/types/validators.ts`
2. Создать единый модуль для всех guard-функций запросов
3. Экспортировать функции из protocol barrel
4. Обновить импорты в SDK и серверных пакетах
5. Удалить дублирующиеся реализации из других файлов

## Ценность
- Единая средняя точка для валидации протокола
- Упрощение синхронизации между клиентом и сервером
- Меньше ошибок из-за несогласованности реализаций
