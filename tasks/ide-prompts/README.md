# IDE Prompts

Documentation, methodology, ADR, and simulation authoring resources for copy-paste use in IDE (Cursor).

## Purpose

This folder contains materials for:
- Developer Experience (DX) improvements
- Architecture Decision Records (ADRs)
- Simulation authoring guidelines
- Methodology documentation
- Module planning documents

These resources are designed to be referenced directly in IDE workflows, not processed by the Task Monitor.

## Contents

Place documentation files here that support:
- ADR compliance and creation
- Simulation creation and validation
- Module development planning
- Coding standards and best practices
- API contract documentation

## Usage

Files in this directory are intended for:
1. Reference during development work
2. Copy-paste into IDE comments or documentation
3. Guiding architectural decisions
4. Supporting simulation authoring workflows

They are NOT scanned by the Task Monitor for automated processing.
