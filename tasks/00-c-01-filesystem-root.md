# C-01: Client Filesystem Root Strategy

## Status
- [x] Completed

## Description
Choose and document canonical `A2A_CLIENT_STORAGE_DIR` strategy (repo-local vs home) for dev and CI.

## Details
- Определить стратегию хранения: репозиторий локально или home directory
- Документировать для dev и CI окружений
- Согласовать с требованиями безопасности

## Decision
Выбрана стратегия репозиторно-локального хранилища для dev и CI окружений:
- **Dev окружения**: `./storage` относительно корня репозитория (значение по умолчанию)
- **CI окружения**: `./storage` относительно корня репозитория (изолированное для каждого запуска)
- **Переопределение**: Можно изменить через переменную окружения `A2A_CLIENT_STORAGE_DIR`
- **Обоснование**: 
  - Изоляция между различными копиями репозитория
  - Упрощение очистки и управления в CI
  - Соответствие текущей реализации по умолчанию
  - Предсказуемое поведение для разработчиков
  - Соответствует требованиям безопасности (данные остаются в рабочей директории)
