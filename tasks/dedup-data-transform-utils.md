# Задача: Дедупликация утилит трансформации данных

## Проблема
Утилиты для трансформации данных дублируются в нескольких местах:
- `tests/integration/simulations/scripts/sim-validate/validators.ts` (строки 140, 117)
- `a2a-server/packages/server-utils/src/deep-clone-json.ts` (строка 5)

## Дублирующиеся функции
- `deepCloneJson()` - появляется в обеих локациях
- `normalizeServerInvokeRequest()` - логика нормализации дублируется
- `normalizeServerInvokeResponse()` - логика ответа повторяется

## Тип
НИЗКИЙ приоритет (LOW SEVERITY)

## Решение
1. Убедиться, что все утилиты определены в `a2a-server/packages/server-utils/src/`
2. Экспортировать `deepCloneJson()` из единого источника
3. Создать модуль `data-normalization.ts` для функций нормализации
4. Обновить импорты в тестовых валидаторах
5. Рассмотреть перемещение тестовых утилит в `packages/test-utils`

## Ценность
- Единая реализация операций с данными
- Упрощение отладки логики трансформации
- Проще обновлять логику нормализации
