# Задача: Консолидация переменных окружения и конфигурации

## Проблема
Паттерны для переменных окружения и путей повторяются в нескольких конфиг-файлах:
- `a2a-client/vite.config.js` (строки 8-10)
- `a2a-client/vite.config.prod.ts` (строки 40-41)
- `a2a-client/playwright.config.ts` (строки 89-110)
- `a2a-server/vitest.config.ts` (строка 5)
- `a2a-server/vitest.human-review.config.ts` (строка 5)

## Дублирующиеся паттерны
- Разрешение переменных окружения: `process.env.WEB_PORT`, `process.env.CLIENT_API_PORT`
- Разрешение путей: `path.resolve(__dirname, ...)` с аналогичными паттернами
- Конфигурация алиасов: `'@'` и `'@shared'` определяются несколько раз

## Тип
НИЗКИЙ приоритет (LOW SEVERITY)

## Решение
1. Создать модуль `packages/config/src/env-config.ts` для централизации переменных окружения
2. Переместить все разрешения путей в отдельный модуль `packages/config/src/path-config.ts`
3. Создать единый источник для конфигурации алиасов
4. Обновить все конфиг-файлы для импорта из централизованных модулей
5. Добавить типизацию для переменных окружения

## Ценность
- Меньше магических строк в конфиг-файлах
- Проще управлять портами и путями
- Упрощение добавления новых переменных окружения
