# Задача: Дедупликация кода инициализации тестовых моков

## Проблема
Код инициализации тестовых моков дублируется в нескольких тестовых файлах:
- `a2a-client/tests/search.test.js` (строки 8-35)
- `a2a-client/tests/mocks/storage/mock-storage.ts` (строки 2-7)
- `a2a-client/tests/integration/session-storage.test.js` (строки 71-120)

## Дублирующиеся элементы
- Создание mock-элементов DOM
- Инициализация `vi.fn()` mock-функций с аналогичными паттернами
- Инициализация в `beforeEach()` с повторяющимися паттернами mock DOM

## Тип
СРЕДНИЙ приоритет (MEDIUM SEVERITY)

## Решение
1. Создать модуль `a2a-client/tests/helpers/mock-setup.ts` для общих утилит моков
2. Переместить функции создания mock-элементов в отдельный модуль
3. Создать фабрики для кастомных mock-функций
4. Обновить все тестовые файлы для использования shared mock setup
5. Добавить документацию по использованию

## Ценность
- Упрощение написания новых тестов
- Снижение кода boilerplate в тестах
- Единая точка для изменения стратегии моков
