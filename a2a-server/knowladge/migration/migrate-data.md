# migrate-data

| Параметр | Значение |
|----------|----------|
| actionId | migrate-data |
| categoryId | migration |
| executorSystemId | agent |
| title | Миграция данных |
| canMigrateToScript | ⏳ |

## Описание

Агент выполняет миграцию данных между системами, базами данных или форматами.

## Типы миграции данных

### System to System
- Миграция с одной БД на другую
- Миграция между серверами
- Переход на новую платформу

### Format Transformation
- CSV → JSON
- XML → YAML
- Legacy format → Modern format

### Data Cleansing
- Удаление дубликатов
- Исправление ошибок
- Нормализация данных

## Процесс миграции

```
1. Анализ исходных данных
   ↓
2. Создание mapping правил
   ↓
3. Трансформация данных
   ↓
4. Валидация
   ↓
5. Загрузка в целевую систему
   ↓
6. Проверка целостности
   ↓
7. Синхронизация изменений
   ↓
8. Cutover
```

## Стратегии

### Big Bang
- Всё и сразу
- Минимальное время синхронизации
- Большой риск

### Incremental
- Постепенная миграция
- Параллельные системы
- Длительный период

### Hybrid
- Комбинация подходов
- Пилотный запуск
- Постепенное расширение

## Best practices

- Backup данных
- Тестирование на копии
- Валидация на каждом этапе
- Логирование
- Rollback план
- Мониторинг
- Проверка целостности
