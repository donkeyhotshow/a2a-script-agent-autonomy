# rotate-keys

| Параметр | Значение |

| categoryId | security |

## Описание

Агент управляет ротацией API ключей, токенов и других секретов для обеспечения безопасности.

## Процесс ротации

1. Генерация новых ключей
2. Обновление конфигурации
3. Тестирование с новыми ключами
4. Отзыв старых ключей
5. Логирование изменений

## Типы ключей

- API keys
- Database credentials
- SSH keys
- TLS certificates
- OAuth tokens
- JWT secrets
- Encryption keys

## Требования

- Безотказный процесс
- Обратная совместимость
- Аудит изменений
- Уведомление команды
- План отката
