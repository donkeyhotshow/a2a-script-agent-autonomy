# ADR-004: Аутентификация и авторизация

## Дата
2026-02-25

## Авторы
- Команда разработки

## Статус
Предложено

## Контекст

Система A2A Script Agent требует механизма аутентификации и авторизации для защиты API endpoints и обеспечения безопасного доступа к данным пользователей. Используется JWT (JSON Web Token) для stateless аутентификации.

### Требования к безопасности

- **JWT_SECRET:** минимум 32 символа (валидация через Zod)
- **ENCRYPTION_KEY:** ровно 32 символа (для тестов)
- **Срок жизни токена:** настраиваемый (по умолчанию 24 часа)
- **Refresh токен:** для продления сессии

## Решение

### JWT Токены

#### Access Token

```typescript
interface JWTPayload {
  sub: string;           // User ID
  email: string;         // User email
  role: UserRole;        // User role
  iat: number;           // Issued at
  exp: number;           // Expiration
  iss: string;           // Issuer
}

interface AccessToken {
  token: string;         // JWT token
  expiresIn: number;     // Seconds until expiration
}
```

#### Refresh Token

```typescript
interface RefreshToken {
  token: string;
  userId: string;
  expiresIn: number;
}
```

#### Конфигурация JWT

```typescript
const jwtConfig = {
  secret: process.env.JWT_SECRET,       // Min 32 characters
  algorithm: 'HS256',
  accessTokenExpiry: '24h',            // 24 hours
  refreshTokenExpiry: '7d',             // 7 days
  issuer: 'a2a-server',
};
```

### Роли пользователей

```typescript
enum UserRole {
  ADMIN = 'admin',           // Полный доступ
```

#### Проверка прав доступа

```typescript
const permissions = {
  admin: ['*'],
  user: [
    'auth:token',
    'auth:refresh',
    'auth:me',
    'requests:create',
    'requests:read:own',
    'requests:delete:own',
    'sessions:create',
    'sessions:read:own',
    'sessions:update:own',
    'sessions:delete:own',
  ],
  guest: [],
  api_client: [
    'auth:token',
    'auth:refresh',
    'requests:create',
    'requests:read:own',
  ],
};

function hasPermission(role: UserRole, permission: string): boolean {
  const rolePermissions = permissions[role];
  return rolePermissions.includes('*') || 
         rolePermissions.includes(permission);
}
```

### Auth Flow

```
1. Регистрация (только ADMIN)
   POST /api/v1/auth/register
   { email, password, role }
   
2. Получение токена
   POST /api/v1/auth/token
   { email, password }
   
   Response: { accessToken, refreshToken, expiresIn }

3. Использование токена
   Authorization: Bearer <accessToken>
   
4. Обновление токена
   POST /api/v1/auth/refresh
   { refreshToken }
   
   Response: { accessToken, refreshToken, expiresIn }

5. Выход (инвалидация refresh токена)
   POST /api/v1/auth/logout
   { refreshToken }
```

### Middleware аутентификации

```typescript
interface AuthMiddlewareOptions {
  requiredRoles?: UserRole[];
  optional?: boolean;
}

const authMiddleware = (options: AuthMiddlewareOptions = {}) => {
  return async (req: Request, res: Response, next: NextFunction) => {
    const authHeader = req.headers.authorization;
    
    if (!authHeader?.startsWith('Bearer ')) {
      if (options.optional) {
        return next();
      }
      return res.status(401).json({ 
        error: { code: -32001, message: 'Unauthorized' } 
      });
    }

    const token = authHeader.substring(7);
    
    try {
      const decoded = jwt.verify(token, jwtConfig.secret);
      req.user = decoded as JWTPayload;
      
      if (options.requiredRoles?.length) {
        if (!options.requiredRoles.includes(req.user.role)) {
          return res.status(403).json({ 
            error: { code: -32003, message: 'Forbidden' } 
          });
        }
      }
      
      next();
    } catch (error) {
      return res.status(401).json({ 
        error: { code: -32001, message: 'Invalid token' } 
      });
    }
  };
};
```

### Хеширование паролей

```typescript
import bcrypt from 'bcrypt';

const SALT_ROUNDS = 12;

async function hashPassword(password: string): Promise<string> {
  return bcrypt.hash(password, SALT_ROUNDS);
}

async function verifyPassword(password: string, hash: string): Promise<boolean> {
  return bcrypt.compare(password, hash);
}
```

## Последствия

### Положительные

- **Stateless:** Не требует хранения сессий на сервере
- **Масштабируемость:** JWT легко проверяются на любом сервере
- **Безопасность:** Использование refresh token снижает риски
- **Гибкость:** Легко добавить новые роли и разрешения

### Отрицательные

- **Отзыв токенов:** Сложнее отозвать JWT (требуется blacklist)
- **Размер:** JWT больше чем session ID

### Ограничения

- Max failed login attempts: 5
- Lockout duration: 15 минут
- Password requirements: min 8 chars, 1 uppercase, 1 number
