# ADR-005: RAG система на клиенте

## Дата
2026-02-25

## Авторы
- Команда разработки

## Статус
Предложено

## Контекст

Система A2A Script Agent использует RAG (Retrieval-Augmented Generation) на стороне клиента для индексации и поиска по кодовой базе. Клиент хранит все индексы и выполняет поиск локально.

### Требования к RAG

- **Индексация кода:** Поддержка различных языков программирования
- **Hybrid Search:** Комбинация BM25 и semantic search
- **Chunking:** Интеллектуальное разбиение кода на чанки
- **Обновление индексов:** Инкрементальная индексация при изменениях

## Решение

### Hybrid Search (BM25 + Semantic)

Система использует комбинацию двух подходов для достижения лучших результатов:

```typescript
interface HybridSearchConfig {
  bm25Weight: number;      // Вес BM25 (по умолчанию 0.3)
  semanticWeight: number;   // Вес semantic (по умолчанию 0.7)
  topK: number;             // Количество результатов
  rerank: boolean;          // Применять переранжирование
}

class HybridSearch {
  async search(query: string, config: HybridSearchConfig): Promise<SearchResult[]> {
    // Параллельный поиск
    const [bm25Results, semanticResults] = await Promise.all([
      this.bm25.search(query),
      this.semantic.search(query),
    ]);

    // Нормализация и объединение результатов
    const normalizedBm25 = this.normalizeResults(bm25Results);
    const normalizedSemantic = this.normalizeResults(semanticResults);

    // Взвешенное объединение
    const combined = this.combineResults(
      normalizedBm25,
      normalizedSemantic,
      config.bm25Weight,
      config.semanticWeight
    );

    // Переранжирование
    if (config.rerank) {
      return this.reranker.rerank(query, combined, config.topK);
    }

    return combined.slice(0, config.topK);
  }
}
```

#### BM25 (Keyword Search)

```typescript
interface BM25Params {
  k1: number;     // Term frequency saturation (default: 1.5)
  b: number;      // Length normalization (default: 0.75)
  avgdl: number; // Average document length
}

class BM25 {
  private documents: Map<string, string>;
  private docLengths: Map<number, number>;
  private termFrequencies: Map<string, Map<string, number>>;
  private idf: Map<string, number>;

  score(query: string, docId: string): number {
    const terms = this.tokenize(query);
    let score = 0;

    for (const term of terms) {
      const tf = this.termFrequencies.get(term)?.get(docId) || 0;
      const idf = this.idf.get(term) || 0;
      
      const numerator = tf * (this.params.k1 + 1);
      const denominator = tf + this.params.k1 * (
        1 - this.params.b + 
        this.params.b * (this.docLengths.get(docId) || 0) / this.params.avgdl
      );
      
      score += idf * (numerator / denominator);
    }

    return score;
  }
}
```

#### Semantic Search (Embedding)

```typescript
interface EmbeddingConfig {
  model: string;           // Модель эмбеддингов
  dimensions: number;      // Размерность вектора
  batchSize: number;      // Размер батча
}

class SemanticSearch {
  private embeddings: Map<string, number[]>;
  private model: EmbeddingModel;

  async search(query: string, topK: number): Promise<SearchResult[]> {
    const queryEmbedding = await this.model.embed(query);
    
    // Cosine similarity
    const results = [];
    for (const [docId, docEmbedding] of this.embeddings) {
      const similarity = this.cosineSimilarity(queryEmbedding, docEmbedding);
      results.push({ docId, score: similarity });
    }

    return results
      .sort((a, b) => b.score - a.score)
      .slice(0, topK);
  }
}
```

### Chunking стратегии

#### Типы чанкинга

| Стратегия | Описание | Преимущества | Недостатки |
|-----------|----------|--------------|------------|
| `fixed` | Фиксированный размер | Простота | Может разрывать логические блоки |
| `by_language` | По грамматике языка | Сохраняет контекст | Сложность реализации |
| `by_function` | По функциям/классам | Логические единицы | Неравномерный размер |
| `recursive` | Иерархический | Адаптивность | Вычислительно сложнее |

#### Реализация чанкинга

```typescript
interface ChunkConfig {
  strategy: 'fixed' | 'by_language' | 'by_function' | 'recursive';
  chunkSize: number;        // Максимальный размер чанка
  overlap: number;          // Перекрытие между чанками
  minChunkSize: number;    // Минимальный размер
}

class ChunkManager {
  async chunk(file: FileInfo, config: ChunkConfig): Promise<Chunk[]> {
    switch (config.strategy) {
      case 'fixed':
        return this.fixedChunking(file, config);
      case 'by_language':
        return this.languageAwareChunking(file, config);
      case 'by_function':
        return this.functionChunking(file, config);
      case 'recursive':
        return this.recursiveChunking(file, config);
    }
  }

  private async functionChunking(file: FileInfo, config: ChunkConfig): Promise<Chunk[]> {
    const ast = await this.parseAST(file);
    const functions = this.extractFunctions(ast);
    
    return functions.map(fn => ({
      id: generateChunkId(file.path, fn.startLine),
      content: fn.content,
      metadata: {
        filePath: file.path,
        startLine: fn.startLine,
        endLine: fn.endLine,
        functionName: fn.name,
        language: file.language,
      },
    }));
  }
}
```

### RAG интеграция с API

```typescript
interface RAGSearchResult {
  chunks: Chunk[];
  totalHits: number;
  queryTime: number;
  searchMethod: 'bm25' | 'semantic' | 'hybrid';
}

class RAGIntegration {
  async search(
    query: string, 
    options: SearchOptions = {}
  ): Promise<RAGSearchResult> {
    const startTime = Date.now();
    
    // Определение типа поиска
    const searchType = this.determineSearchType(query, options);
    
    let results: SearchResult[];
    switch (searchType) {
      case 'hybrid':
        results = await this.hybridSearch.search(query, options);
        break;
      case 'bm25':
        results = await this.bm25.search(query, options);
        break;
      case 'semantic':
        results = await this.semantic.search(query, options);
        break;
    }

    return {
      chunks: this.mapToChunks(results),
      totalHits: results.length,
      queryTime: Date.now() - startTime,
      searchMethod: searchType,
    };
  }
}
```

## Последствия

### Положительные

- **Локальная обработка:** Нет зависимости от внешних сервисов
- **Контекстуальность:** Сохранение связей между кодом
- **Гибкость:** Настраиваемые стратегии поиска
- **Инкрементальность:** Быстрое обновление индексов

### Отрицательные

- **Ресурсоёмкость:** Требует памяти для индексов
- **Сложность:** Множество компонентов для поддержки

### Ограничения

- Max file size: 1MB
- Max index size: 10GB
- Supported files: code, markdown, text
