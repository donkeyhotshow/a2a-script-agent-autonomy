# fix-vue-imports

Исправить сломанные импорты в Vue файлах.

## Sub-actions (4 steps)

Каждый step - отдельное действие:

### 1. vue-import-detect
Определить сломанные импорты.

**Вход:** none  
**Выход:** массив сломанных импортов

### 2. vue-import-resolve  
Разрешить правильные пути для сломанных импортов.

**Вход:** массив сломанных импортов  
**Выход:** массив исправлений (from -> to)

### 3. vue-import-apply
Применить исправления к файлам.

**Вход:** массив исправлений  
**Выход:** исправленные файлы

### 4. vue-import-cleanup
Очистить временные файлы.

**Вход:** none  
**Выход:** количество удалённых файлов

## Контекст

- Framework: Vue 3
- Build tool: Vite
- Aliases: @ -> resources/js, ~ -> resources
