# generate-api-docs

| Параметр | Значение |
|----------|----------|
| actionId | generate-api-docs |
| categoryId | documentation |
| executorSystemId | script |
| title | Генерация API docs |
| canMigrateToScript | ✅ |

## Описание

Автоматическая генерация документации API на основе исходного кода или спецификаций.

## Инструменты

- Swagger / OpenAPI
- JSDoc
- phpDocumentor
- Sphinx
- Doxygen
- API Blueprint

## Генерируемая документация

- Список эндпоинтов
- Параметры запросов
- Тела запросов/ответов
- Коды ошибок
- Примеры использования
- Аутентификация
- Rate limiting

## Поддерживаемые форматы

- OpenAPI/Swagger (JSON/YAML)
- HTML
- Markdown
- PDF
