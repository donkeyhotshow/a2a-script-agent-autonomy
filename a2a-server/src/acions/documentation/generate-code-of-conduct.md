# generate-code-of-conduct

| Параметр | Значение |
|----------|----------|
| actionId | generate-code-of-conduct |
| categoryId | documentation |
| executorSystemId | agent |
| title | Генерация CODE_OF_CONDUCT.md |
| canMigrateToScript | ✅ |

## Описание

Агент генерирует кодекс поведения (CODE_OF_CONDUCT.md) для проекта.

## Типичные разделы

- Наше обещание
- Открытый код / Сообщество
- Стандарты поведения
- Приемлемое поведение
- Неприемлемое поведение
- Ответственность сообщества
- Область применения
- Применение
- Модерация
- Контакты для жалоб

## Стандарты

### Contributor Covenant
Популярный шаблон с версиями:
- v1.0
- v1.4
- v2.0
- v2.1

### Другие стандарты
- GNOME Code of Conduct
- Django Code of Conduct
- Google Open Source Community Guidelines
- Microsoft Open Source Code of Conduct

## Рекомендации

- Использовать признанные шаблоны
- Адаптировать под проект
- Указать контакты для связи
- Определить процесс модерации

## Форматы

- Markdown
