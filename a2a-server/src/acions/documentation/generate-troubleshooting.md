# generate-troubleshooting

| Параметр | Значение |
|----------|----------|
| actionId | generate-troubleshooting |
| categoryId | documentation |
| executorSystemId | agent |
| title | Генерация troubleshooting guide |
| canMigrateToScript | ✅ |

## Описание

Агент генерирует руководство по устранению неполадок (troubleshooting guide) для проекта.

## Типы проблем

### Установка
- Ошибки зависимостей
- Проблемы с правами
- Версии Node/PHP/Python
- Конфликты пакетов

### Конфигурация
- Неправильные настройки
- Отсутствующие переменные
- Проблемы с путями
- Ошибки окружения

### Выполнение
- Ошибки времени выполнения
- Краши приложения
- Timeout ошибки
- Memory issues

### Сеть и API
- Connection refused
- SSL ошибки
- CORS проблемы
- Аутентификация

### База данных
- Connection errors
- Migration errors
- Query errors
- Lock issues

## Структура руководства

1. Описание проблемы
2. Симптомы
3. Причины
4. Решение
5. Профилактика

## Формат записи

```
markdown
## Проблема: [Название]

### Симптомы
- Список симптомов

### Причины
- Возможные причины

### Решение
1. Шаг 1
2. Шаг 2

### Профилактика
- Как избежать
```

## Процесс генерации

1. Анализ кода на потенциальные ошибки
2. Изучение существующих issues
3. Анализ логов
4. Проверка зависимостей
5. Генерация решений

## Инструменты

- error-prone
- SonarQube
- Snyk
- ESLint
- PHPStan

## Рекомендации

- Группировать по категориям
- Использовать понятный язык
- Добавлять примеры кода
- Включать скриншоты
- Обновлять регулярно
