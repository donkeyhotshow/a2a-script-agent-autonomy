# generate-readme

| Параметр | Значение |
|----------|----------|
| actionId | generate-readme |
| categoryId | documentation |
| executorSystemId | agent |
| title | Генерация README |
| canMigrateToScript | ✅ |

## Описание

Агент генерирует документацию README.md для проекта на основе анализа структуры и кода.

## Содержание README

- Название проекта
- Описание
- Установка
- Использование
- Конфигурация
- Примеры использования
- Технологический стек
- Требования
- Лицензия
- Контакты

## Источники информации

- Структура проекта
- package.json / composer.json
- Код файлов
- Существующая документация
- Комментарии в коде

## Форматы

- Markdown
- reStructuredText
- HTML
