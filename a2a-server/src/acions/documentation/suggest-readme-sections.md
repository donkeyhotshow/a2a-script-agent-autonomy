# suggest-readme-sections

| Параметр | Значение |
|----------|----------|
| actionId | suggest-readme-sections |
| categoryId | documentation |
| executorSystemId | agent |
| title | Предложение разделов README |
| canMigrateToScript | ✅ |

## Описание

Агент анализирует проект и предлагает оптимальную структуру разделов для README.md.

## Анализируемые факторы

- Тип проекта (библиотека, приложение, API)
- Технологический стек
- Сложность проекта
- Целевая аудитория
- Наличие документации

## Предлагаемые разделы

- Название и описание
- Быстрый старт
- Установка
- Использование / Примеры
- API документация
- Конфигурация
- Требования
- Технологический стек
- Contributing
- Лицензия
- Контакты
- FAQ
- Changelog

## Формат вывода

Агент предоставляет:
- Список рекомендуемых разделов
- Описание каждого раздела
- Приоритет разделов
- Примеры структуры
