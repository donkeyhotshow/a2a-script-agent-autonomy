# update-api-docs

| Параметр | Значение |
|----------|----------|
| actionId | update-api-docs |
| categoryId | documentation |
| executorSystemId | agent |
| title | Обновление API документации |
| canMigrateToScript | ⏳ |

## Описание

Агент обновляет существующую API документацию на основе изменений в коде.

## Триггеры для обновления

- Добавление новых эндпоинтов
- Изменение параметров запросов
- Изменение формата ответов
- Изменение аутентификации
- Добавление новых кодов ошибок
- Изменение версии API

## Процесс обновления

1. Чтение текущей документации
2. Анализ изменений в API коде
3. Сравнение спецификаций
4. Обновление описаний эндпоинтов
5. Обновление схем данных
6. Обновление примеров
7. Генерация diff changelog

## Инструменты

- Swagger Editor
