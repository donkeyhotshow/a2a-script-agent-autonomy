# apply-refactoring

| Параметр | Значение |
|----------|----------|
| actionId | apply-refactoring |
| categoryId | code-quality |
| executorSystemId | agent |
| title | Применение рефакторинга |
| canMigrateToScript | ⏳ |

## Описание

Агент применяет рекомендованные изменения кода для улучшения его качества.

## Типичные операции

- Переименование файлов, классов, функций, переменных
- Извлечение методов
- Встраивание методов
- Перемещение методов между классами
- Разделение/объединение классов
- Замена условной логики полиморфизмом
- Удаление мертвого кода

## Требования

- Наличие тестов
- Понимание контекста изменений
- Сохранение функциональности
- Инкрементальные изменения

## Риски

- Возможное нарушение функциональности
- Необходимость обновления тестов
- Влияние на зависимые компоненты
