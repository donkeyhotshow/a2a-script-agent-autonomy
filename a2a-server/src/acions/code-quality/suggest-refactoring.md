## Описание

Агент анализирует код и предлагает варианты рефакторинга для улучшения качества и поддерживаемости кода.

## Типичные предложения

- Извлечение методов
- Переименование переменных/функций
- Применение паттернов проектирования
- Упрощение условий
- Реструктуризация классов
- Удаление дублирования

## Критерии качества

- Читаемость кода
- Простота понимания
- Уменьшение сложности
- Соблюдение принципов SOLID
