# generate-test-data

| Параметр | Значение |
|----------|----------|
| actionId | generate-test-data |
| categoryId | code-gen |
| executorSystemId | script |
| title | Генерация тестовых данных |
| canMigrateToScript | ✅ |

## Описание

Автоматическая генерация тестовых данных для различных сценариев тестирования.

## Типы данных

- Unit test fixtures
- Integration test data
- E2E test scenarios
- Performance test data
- Mock data
- Seed data для БД
- Boundary values
- Edge cases

## Инструменты

- Faker.js
- Factory Boy
- Mockaroo
- Benerator
- Database seeder
- Custom generators

## Стратегии генерации

- Random generation (случайные)
- Fixed values (фиксированные)
- Edge cases (граничные значения)
- Boundary values (предельные значения)
- Equivalence classes (классы эквивалентности)
- Pairwise testing

## Требования

- Реалистичность данных
- Соответствие схеме
- Разнообразие сценариев
- Контролируемость
- Повторяемость
