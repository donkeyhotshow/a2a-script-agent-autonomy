# generate-diagrams

| Параметр | Значение |
|----------|----------|
| actionId | generate-diagrams |
| categoryId | architecture |
| executorSystemId | agent |
| title | Генерация диаграмм |
| canMigrateToScript | ✅ |

## Описание

Агент генерирует различные типы диаграмм для визуализации архитектуры и структуры проекта.

## Типы диаграмм

### Структурные диаграммы
- Component Diagram
- Class Diagram
- Object Diagram
- Package Diagram
- Deployment Diagram
- Entity-Relationship Diagram

### Поведенческие диаграммы
- Sequence Diagram
- Activity Diagram
- State Diagram
- Use Case Diagram
- Flowchart

### Архитектурные диаграммы
- System Context Diagram
- Container Diagram
- Infrastructure Diagram
- Data Flow Diagram

## Инструменты

### PlantUML
- Диаграммы в текстовом формате
- Поддержка UML
- Mermaid совместимость

### Mermaid
- Встроенная поддержка в Markdown
- Простой синтаксис
- Интерактивные диаграммы

### Graphviz
- Визуализация графов
- Автоматическая раскладка
- DOT язык

### Draw.io / Lucidchart
- Визуальные редакторы
- Экспорт в различные форматы

## Форматы вывода

- PNG
- SVG
- PDF
- Mermaid.js
- PlantUML
- DOT

## Процесс

1. Анализ кода и структуры
2. Определение компонентов
3. Выбор типа диаграммы
4. Генерация кода диаграммы
5. Рендеринг изображения

## Примеры применения

- Архитектура приложения
- Структура базы данных
- API потоки
- Workflow процессы
- Системные интеграции
