# generate-architecture-docs

| Параметр | Значение |
|----------|----------|
| actionId | generate-architecture-docs |
| categoryId | architecture |
| executorSystemId | agent |
| title | Генерация архитектурной документации |
| canMigrateToScript | ✅ |

## Описание

Агент генерирует архитектурную документацию проекта на основе анализа кода и структуры.

## Разделы документации

### Обзор архитектуры
- Высокоуровневая диаграмма
- Компоненты системы
- Связи между компонентами

### Компоненты
- Frontend
- Backend
- Database
- API Layer
- Services
- Utilities

### Технологический стек
- Языки программирования
- Фреймворки
- Базы данных
- Кэширование
- Очереди
- Инфраструктура

### Паттерны
- Architectural patterns
- Design patterns
- Anti-patterns
- Best practices

## Типы документации

- Architecture Decision Records (ADR)
- System Design Docs
- Component Docs
- API Architecture
- Data Architecture
- Security Architecture

## Форматы

- Markdown
- AsciiDoc
- UML
- Mermaid диаграммы

## Источники информации

- Анализ кода
- Структура проекта
- Конфигурационные файлы
- Существующая документация

## Инструменты

- Archi
- PlantUML
- Mermaid
- Draw.io
- Structurizr
