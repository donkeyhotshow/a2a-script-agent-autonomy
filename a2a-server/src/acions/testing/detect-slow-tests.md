# detect-slow-tests

| Параметр | Значение |
|----------|----------|
| actionId | detect-slow-tests |
| categoryId | performance |
| executorSystemId | script |
| title | Детекция медленных тестов |
| framework | all |
| canMigrateToScript | ✅ |

## Описание

Скрипт автоматически определяет медленные тесты, которые замедляют CI/CD пайплайн.

## Метрики

- Время выполнения теста
- Процент от общего времени
- Тренд времени выполнения

## Результат

- Список медленных тестов (> 1 сек)
- Время выполнения каждого
- Процент от общего времени
- Рекомендации по оптимизации

## Thresholds

- Slow: > 1s
- Very Slow: > 5s
- Critical: > 10s
