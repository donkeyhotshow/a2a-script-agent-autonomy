# detect-flaky-tests

| Параметр | Значение |
|----------|----------|
| actionId | detect-flaky-tests |
| categoryId | quality |
| executorSystemId | script |
| title | Детекция flaky тестов |
| framework | all |
| canMigrateToScript | ✅ |

## Описание

Скрипт автоматически определяет flaky тесты (тесты, которые периодически падают без изменения кода).

## Детекция

### Признаки flaky тестов
- Непоследовательные результаты
- Timing dependencies
- Race conditions
- Shared state между тестами

### Методы

1. **Ретроспективный анализ**
   - История CI запусков
   - Логи тестов

2. **Статистический анализ**
   - Процент успешных запусков
   - Время выполнения

## Результат

- Список flaky тестов
- Частота падений
- Предполагаемые причины
- Рекомендации по исправлению
