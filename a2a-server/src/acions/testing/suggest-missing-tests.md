# suggest-missing-tests

| Параметр | Значение |
|----------|----------|
| actionId | suggest-missing-tests |
| categoryId | testing |
| executorSystemId | agent |
| title | Предложение недостающих тестов |
| framework | all |
| canMigrateToScript | ✅ |

## Описание

Агент анализирует код и предлагает недостающие тесты на основе покрытия и анализа кода.

## Анализ

- Покрытие тестами
- Критические функции
- Edge cases
- Граничные условия

## Типы тестов

### Unit тесты
- Функции и методы
- Валидация
- Обработка ошибок

### Integration тесты
- Взаимодействие модулей
- API endpoints
- База данных

### E2E тесты
- User flows
- Критические пути

## Приоритизация

1. Критические функции (высокий приоритет)
2. Сложная логика (средний приоритет)
3. Утилиты (низкий приоритет)

## Рекомендации

- Начать с критических путей
- Покрыть граничные случаи
- Добавить negative tests
- Использовать parameterized tests
