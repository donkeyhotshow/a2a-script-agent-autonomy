# Сравнение: Видение vs Реальность

## Цель

Сравнить описание в [README.md](README.md) с текущей реализацией и определить что нужно исправить.

---

## 1. Web → Server прямая связь

### Видение (README.md)
> главное в новом протоколе , ето что web не знает адрес сервера , а только клиент .

### Реальность (web-api-client.js)
```javascript
// a2a-client/web/js/web-api-client.js:7
serverUrl: 'http://localhost:8080/api/v1'
```

### Проблема
✅ **Web напрямую обращается к Server** - это нарушает архитектуру!

### Что нужно исправить
1. Web должен обращаться к Client API (порт 3001)
2. Client API уже есть в проекте? Проверить `a2a-client/server/`

## 2. Web → Client API эндпоинты

### Видение (SESSION-FLOW.md)
| Endpoint | Описание |
|----------|----------|
| `POST /api/sessions` | Создать сессию |
| `GET /api/sessions` | Список сессий |
| `GET /api/sessions/:id` | Состояние сессии |
| `POST /api/sessions/:id/action` | Выбрать действие |
| `POST /api/sessions/:id/next` | Следующий шаг |
| `POST /api/sessions/:id/cancel` | Отмена |

### Реальность
Посмотреть какие эндпоинты есть в Client API.

## 3. Хранение сессий

### Видение (README.md)
> все данные хранятся на клиенте . запрос и state окошка на вебе .

### Где должны храниться
- ✅ В памяти - активные сессии
- ✅ В файловой системе: `~/.a2a-client/sessions/`
- ❌ На Server - НЕТ (Server STATELESS)

## 4. UI: Панели сессий

### Видение (README.md)
> каждая сессия в отдельной панели , а панели могут быть в какомто состоянии отображения . 
> в етом состоянии , панель нельзя закрыть , пока задача не будет отменена .
> в етом состоянии можно свернуть в дропзону , а крестик превращает панель в квадрат .

### Реализация
- Проверить `a2a-client/web/js/sessions.js` - управление сессиями
- Проверить UI компоненты панелей

## 5. Кнопки управления

### Видение (README.md)
> нужны кнопочки далее (пропадает при авто) и авто (меняется на стоп) .
> на применить , мы должны отправить запрос на апи клиента .

### Ожидаемый UI
| Кнопка | Состояние | Действие |
|--------|-----------|----------|
| Далее | Активно | Ручной режим |
| Авто | Активно | Автоматический режим |
| Стоп | Во время авто | Остановить |
| Отменить | Всегда | Отменить сессию |
| Применить | После выбора действия | Запустить выполнение |

## 6. Первый запрос

### Видение (README.md)
> по сути , мы делаем поисковый запрос сервисов сервера .

### Реальность (fix-vue-imports/1/request.json)
```json
{
  "task": "виправити імпорти у vue компонентах"
}
```

### Проблема
> в C:\workspace\org-carrier\a2a-script-agent\simulations\fix-vue-imports\1\request.json 
> отображено запрос , там точно чегото нехватает . поля номерок сессии и номерок проекта.

### Нужно добавить
```json
{
  "sessionId": "sess_xxx",
  "projectId": "proj_xxx", 
  "task": "виправити імпорти..."
}
```
