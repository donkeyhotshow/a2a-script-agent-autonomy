# Поток сессий (Session Flow)

> **ВАЖНО:** Сервер (a2a-server) STATELESS - не хранит сессии!
> Все сессии хранятся на Client API. Сервер только обрабатывает запросы через `/invoke`.

## Обзор

Сессия представляет собой контекст выполнения задачи пользователя. Сессия проходит через несколько состояний от создания до завершения.

## Состояния сессии

```
┌──────────┐     ┌─────────┐     ┌──────────────┐     ┌────────────────────┐
│ PENDING  │────▶│  READY  │────▶│ IN_PROGRESS  │────▶│ COMPLETED          │
└──────────┘     └─────────┘     └──────────────┘     └────────────────────┘
     │                │                  │                         ▲
     │                │                  │                         │
     │                │                  ├────────────┐            │
     │                │                  ▼            ▼            │
     │                │           ┌──────────────┐ ┌─────────┐       │
     │                │           │ WAITING_      │ │  ERROR  │───────┘
     │                │           │ CONFIRMATION  │ └─────────┘
     │                │           └──────────────┘
     │                │
     │                │     ┌─────────┐
     └───────────────▶│ CANCELLED │
                       └─────────┘
```

| Состояние | Описание |
|-----------|----------|
| `PENDING` | Сессия создана, ожидает выбора действия из `proposedActions` |
| `READY` | Пользователь выбрал действие, готова к выполнению |
| `IN_PROGRESS` | Выполняются поддействия (subActions) |
| `WAITING_CONFIRMATION` | Ожидает подтверждения от пользователя |
| `COMPLETED` | Все поддействия выполнены успешно |
| `ERROR` | Ошибка при выполнении |
| `CANCELLED` | Отменена пользователем |

## Панель сессии (Session Panel)

Каждая сессия отображается в отдельной панели (SessionPanel).

### Состояния панели

| Состояние | Внешний вид | Ограничения |
|-----------|-------------|-------------|
| `inactive` | Серый бордер | Нельзя закрыть, пока есть активные задачи |
| `active` | Цветной бордер | Можно взаимодействовать |
| `minimized` | Иконка в доке | Клик для восстановления |

### Элементы панели

```
┌──────────────────────────────────────────────────────────────┐
│  ═══════════════════════════════════════════════════════════  │
│  │ [─] [_] [□] [✕]                    │ Задача: fix-vue...  │
│  ═══════════════════════════════════════════════════════════  │
│                                                              │
│  Статус: ● Выполняется                                       │
│                                                              │
│  ┌─────────────────────────────────────────────────────────┐ │
│  │ ✓ vue-import-detect     [Выполнено]                     │ │
│  │ ● vue-import-resolve    [Выполняется...]                │ │
│  │ ○ vue-import-apply      [Ожидает]                        │ │
```

### Перемещение панелей

- Панели можно перетаскивать (drag & drop)
- Можно менять размер
- Можно сворачивать в док (drop zone)
- Крестик превращает панель в квадратную иконку

## Сохранение сессий

Сессии хранятся локально на Client:

1. **В памяти** - для активных сессий
2. **В файловой системе** - для персистентности
   - `~/.a2a-client/sessions/` - JSON файлы
3. **В БД** - для масштабирования (опционально)

### Структура файла сессии

```json
{
  "id": "sess_abc123",
  "projectId": "proj_xyz789",
  "task": "виправити імпорти у vue компонентах",
  "status": "IN_PROGRESS",
  "selectedActionId": "fix-vue-imports",
  "selectedAction": {
    "actionId": "fix-vue-imports",
    "title": "...",
    "subActions": [...]
  },
  "currentSubActionIndex": 1,
  "results": [
    {
      "actionId": "vue-import-detect",
      "status": "success",
      "output": { "broken_imports": [...] },
      "timestamp": "2024-01-15T10:30:00Z"
    }
  ],
  "logs": [
    "Starting vue-import-detect...",
    "Found 5 broken imports"
  ],
  "createdAt": "2024-01-15T10:00:00Z",
  "updatedAt": "2024-01-15T10:30:00Z"
}
```

## API эндпоинты для сессий

### Web → Client API

| Метод | Путь | Описание |
|-------|------|----------|
| `POST` | `/api/sessions` | Создать сессию |
| `GET` | `/api/sessions` | Список сессий |
| `GET` | `/api/sessions/:id` | Получить сессию |
| `POST` | `/api/sessions/:id/action` | Выбрать действие |
| `POST` | `/api/sessions/:id/next` | Следующий шаг |
| `POST` | `/api/sessions/:id/cancel` | Отменить |
| `DELETE` | `/api/sessions/:id` | Удалить сессию |
