
╔══════════════════════════════════════════════════════════════════════╗
║              @a2a-client/storage — КАК УСТРОЕНО                     ║
╚══════════════════════════════════════════════════════════════════════╝

  Пакет отвечает за хранение и управление сессиями на диске.
  Всё взаимодействие идёт через index.ts — единую точку входа.

┌─────────────────────────────────────────────────────────────────────┐
│                        СЛОИ ХРАНИЛИЩА                               │
│                                                                     │
│   ┌──────────────┐                                                  │
│   │  index.ts    │  ← единая точка экспорта всего пакета            │
│   └──────┬───────┘                                                  │
│          │                                                          │
│   ┌──────▼──────────────────────────────────────────────────────┐   │
│   │                   УПРАВЛЕНИЕ ПРОЕКТАМИ                      │   │
│   │                                                             │   │
│   │  projects.ts ──► projectSessions.ts ──► newSessions.ts      │   │
│   │  (проект)        (сессии проекта)        (создание сессий)  │   │
│   └──────────────────────────┬──────────────────────────────────┘   │
│                              │                                      │
│   ┌──────────────────────────▼──────────────────────────────────┐   │
│   │                   ЯДРО СЕССИЙ                               │   │
│   │                                                             │   │
│   │  session-store.ts   ←──► adrComplianceState.ts             │   │
│   │  (запись/чтение)          (ADR-статус сессии)               │   │
│   │        │                                                    │   │
│   │        ▼                                                    │   │
│   │  session-index-store.ts   ← быстрый поиск по сессиям        │   │
│   │  session-step-io.ts       ← ввод/вывод по шагам             │   │
│   │  session-promise-read.ts  ← чтение промисов                 │   │
│   └──────────────────────────┬──────────────────────────────────┘   │
│                              │                                      │
│   ┌──────────────────────────▼──────────────────────────────────┐   │
│   │                   УТИЛИТЫ И ПРИМИТИВЫ                       │   │
│   │                                                             │   │
│   │  session-paths.ts / .mjs  ← пути к файлам сессий на диске   │   │
│   │  session-id.ts            ← генерация и парсинг ID          │   │
│   │  session-sort.mjs         ← сортировка сессий               │   │
│   │  session-stage-derive.mjs ← вычисление стадии сессии        │   │
│   │  promise-status.ts        ← статус промиса (pending/done)   │   │
│   │  kv.ts                    ← key-value хранилище             │   │
│   │  root.ts                  ← корневой путь на диске          │   │
│   └─────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│                    КАК РАБОТАЕТ СЕССИЯ                              │
│                                                                     │
│  1. Создание:  newSessions.ts генерирует ID → session-id.ts         │
│  2. Путь:      session-paths.ts строит путь на диске                │
│  3. Запись:    session-store.ts сохраняет JSON-файлы                │
│  4. Индекс:    session-index-store.ts обновляет индекс поиска       │
│  5. Шаги:      session-step-io.ts пишет input/output каждого шага   │
│  6. Статус:    promise-status.ts + adrComplianceState.ts            │
│                                                                     │
│  Структура на диске:                                                │
│                                                                     │
│  tests/sessions/                                                    │
│  └── sess_<timestamp>/                                              │
│      ├── request-to-server.json   ← входящий запрос                 │
│      └── client-result.json       ← результат выполнения            │
└─────────────────────────────────────────────────────────────────────┘
