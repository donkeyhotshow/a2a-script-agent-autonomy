
╔══════════════════════════════════════════════════════════════════════╗
║              proxy_logs — КАК УСТРОЕНО                              ║
╚══════════════════════════════════════════════════════════════════════╝

  Директория хранит кэш ответов LLM и отладочные запросы.
  Цель — не дёргать LLM повторно при одинаковых запросах.

┌─────────────────────────────────────────────────────────────────────┐
│                        СТРУКТУРА                                    │
│                                                                     │
│  proxy_logs/                                                        │
│  ├── debug-request-latest.json   ← последний отладочный запрос      │
│  └── cache/                      ← 200+ закэшированных ответов LLM  │
│      ├── 01/ ── <hash>.json                                         │
│      ├── 0f/ ── <hash>.json                                         │
│      ├── ff/ ── <hash>.json                                         │
│      └── ...  (папки по первым 2 символам хэша)                     │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│                    КАК РАБОТАЕТ КЭШ                                 │
│                                                                     │
│                                                                     │
│   Клиент / тест                                                     │
│       │                                                             │
│       │  запрос к LLM (model + messages)                            │
│       ▼                                                             │
│   ┌──────────────────────────────────────────┐                      │
│   │            LLM Proxy                    │                      │
│   │                                          │                      │
│   │  1. Вычислить SHA-256 от запроса         │                      │
│   │  2. Проверить cache/<prefix>/<hash>.json │                      │
│   │                                          │                      │
│   │   Есть в кэше? ──► вернуть сохранённый  │                      │
│   │   Нет?         ──► запросить LLM API    │                      │
│   │                    └─► сохранить ответ  │                      │
│   └──────────────────────────────────────────┘                      │
│                                                                     │
│   Именование файла:                                                 │
│   cache / <первые 2 символа хэша> / <полный SHA-256>.json           │
│   Пример: cache/ff/ffcc678f8866...abc.json                          │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│                    ФОРМАТ ФАЙЛА КЭША                                │
│                                                                     │
│  {                                                                  │
│    "model":    "gpt-4o / claude / ...",  ← какая модель             │
│    "messages": [ ... ],                  ← входящие сообщения       │
│    "created":  1234567890,               ← timestamp                │
│    "cache_key": "sha256..."              ← ключ кэша                │
│  }                                                                  │
└─────────────────────────────────────────────────────────────────────┘
