# Вариант 8: Граф = сборка промпта

**Суть:** Граф — структура для сборки промпта в ChatGPT: какие блоки, в каком порядке, с какими весами.

**Источник данных:** Ручной конфиг. Узлы = блоки контекста (system, project structure, file content, hints). Рёбра = порядок/зависимости.

**Роль в системе:**
- Файлы + new_task → обход графа → сборка финального промпта
- Не про структуру проекта, а про структуру промпта
- Обход несемантики: некоторые блоки не включаются
