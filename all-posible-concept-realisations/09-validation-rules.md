# Вариант 9: Граф = правила валидации

**Суть:** Граф — правила: что должно быть (controller → request, model → migrations). Ручные, не извлечённые.

**Источник данных:** Ручной конфиг. Пример: "если есть Controller, должен быть FormRequest".

**Роль в системе:**
- Проверка полноты контекста перед вызовом ChatGPT
- request_files = недостающее по правилам
- Не dependency extraction — ожидания/требования
