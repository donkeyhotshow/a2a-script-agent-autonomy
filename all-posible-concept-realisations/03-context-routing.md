# Вариант 3: Граф = маршрутизация контекста

**Суть:** Граф — правила: какие context blocks, neurons, подсказки применять к каким путям/типам файлов.

**Источник данных:** Ручной конфиг. Пример: `app/Models/* → neuron-eloquent, neuron-context-laravel-11`.

**Роль в системе:**
- Клиент шлёт файлы → сервер по путям выбирает релевантный контекст
- Сборка промпта для ChatGPT: только нужные блоки
- Обход несемантики: не все файлы попадают в контекст

**Не делает:** Не хранит entities. Не dependency graph.
