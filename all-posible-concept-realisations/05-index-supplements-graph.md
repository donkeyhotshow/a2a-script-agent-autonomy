# Вариант 5: Индекс дополняет граф

**Суть:** Индекс (ML) — поиск по коду. Граф — ручная карта ключевых точек проекта (контроллеры, сервисы, модели). Граф не извлекается, а задаётся вручную на проект.

**Источник данных:** 
- Граф: ручной YAML/JSON на проект (entities + relations)
- Индекс: автоматический по файлам

**Роль в системе:**
- Граф = "карта" для навигации, индекс = поиск внутри
- ChatGPT получает: граф (структура) + результаты поиска по индексу
- Граф помогает сфокусировать контекст
