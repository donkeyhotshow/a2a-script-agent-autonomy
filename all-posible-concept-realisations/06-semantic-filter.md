# Вариант 6: Граф = семантический фильтр

**Суть:** Граф — правила, что считать семантикой (текст, указания) и что отфильтровывать (несемантика из кода).

**Источник данных:** Ручные правила. Пример: комментарии, docblocks, имена переменных/классов — семантика; реализация методов — шум (или наоборот).

**Роль в системе:**
- Обработка контента перед отправкой в ChatGPT
- Извлечение текста/указаний, обход кодовой несемантики
- Граф = конфиг фильтрации, не структура проекта
