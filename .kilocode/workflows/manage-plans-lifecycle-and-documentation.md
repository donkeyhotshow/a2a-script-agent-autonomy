# Workflow: Управление жизненным циклом планов и документирование

## Обзор

Данный ворклоу описывает процесс управления завершёнными планами и их интеграцию в архив документации проекта.

## Основные этапы

### Этап 1: Миграция завершённых планов в документационный архив

Когда план считается полностью выполненным (все пункты чеклиста отмечены как выполненные):

1. Перенести файл плана из директории `plans/` в `docs/archive/`
2. При необходимости актуализировать ссылки в основной документации проекта

### Этап 2: Аудит оставшихся планов

После миграции завершённых планов необходимо:

1. Просканировать директорию `plans/` на предмет оставшихся планов
2. Для каждого плана проверить статус выполнения задач:
   - Открыть файл плана
   - Проанализировать чеклист задач (отметки `- [ ]` и `- [x]`)
   - Определить степень завершённости

### Этап 3: Актуализация статуса задач

В процессе аудита плана:

1. Найти секцию с чеклистом в документе плана
2. Выявить задачи, которые были выполнены, но не отмечены
3. Обновить статус: `- [ ]` → `- [x]`
4. Если все задачи выполнены → план готов к миграции (Этап 1)

## Структура чеклиста в плане

```markdown
## Чеклист задач

- [x] Задача 1 выполнена
- [x] Задача 2 выполнена
- [ ] Задача 3 ещё не выполнена
```

## Ключевые принципы

- **Приоритетность**: Сначала выполняем миграцию завершённых планов, затем проводим аудит
- **Актуальность**: Регулярно обновляем статусы в чеклистах документов планов
- **Полнота**: Все выполненные задачи должны быть отмечены в чеклисте

## Автоматизация

Для упрощения процесса можно использовать скрипты автоматизации:
- Проверка статуса выполнения задач в markdown-файлах
- Автоматическое перемещение завершённых планов
- Генерация отчётов о прогрессе
