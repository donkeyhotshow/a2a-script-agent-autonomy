### Описание пакета

Пакет `@a2a/execution` отвечает за выполнение скриптов и команд в изолированной среде. Включает terminal handler, script runner и file scanner.

### Основные модули

| Модуль | Описание |
|--------|----------|
| terminal | Выполнение shell команд |
| script-runner | Запуск JavaScript кода в sandbox |
| file-scanner | Сканирование файловой системы |
| glob-matcher | Паттерны для поиска файлов |
| ignore-detector | Игнорирование файлов (.gitignore) |

## Возможные проблемы

### 1. Проблемы безопасности

| Проблема | Описание | Решение |
|----------|----------|---------|
| RCE уязвимость | Возможность выполнения произвольного кода | Sandboxing, whitelist |
| Path traversal | Доступ к неразрешённым файлам | Path validation |
| Command injection | Инъекция команд в shell | Escaping, parameterized commands |

### 2. Проблемы выполнения

| Проблема | Описание | Решение |
|----------|----------|---------|
| Зависание | Скрипт/команда зависает |зм |
| Утечка Timeout механи ресурсов | Не освобождаются ресурсы | Cleanup on exit |
| Ошибки в скриптах | Скрипты выбрасывают ошибки | Error boundaries |

### 3. Проблемы с файловой системой

| Проблема | Описание | Решение |
|----------|----------|---------|
| Большие файлы | Сканирование занимает много времени | Лимиты размера |
| Permission denied | Нет доступа к файлам | Graceful error handling |
| Symlinks | Циклические ссылки | Detection, skip |
