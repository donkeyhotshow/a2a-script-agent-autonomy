### Описание пакета

Пакет `@a2a/json` предоставляет инструменты для валидации JSON структур и работы с JSON данными в A2A протоколе.

### Основные функции

| Функция | Описание |
|---------|----------|
| JSON Validation | Валидация JSON структур |
| Schema validation | Проверка по схеме |
| Type guards | TypeScript guards для типов |
| Serialization | Сериализация/десериализация |
