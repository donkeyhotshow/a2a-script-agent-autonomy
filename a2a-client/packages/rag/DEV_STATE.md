### Описание пакета

Пакет `@a2a/rag` реализует RAG (Retrieval-Augmented Generation) функциональность для A2A системы. Включает индексацию, поиск и реранжирование результатов.

### Основные модули

| Модуль | Описание |
|--------|----------|
| indexer | Индексация документов |
| searcher | Поиск по индексу |
| chunk-manager | Управление чанками |
| semantic-search | Семантический поиск |
| bm25 | BM25 алгоритм поиска |
| hybrid-search | Гибридный поиск |
| reranker | Переранжирование результатов |
| meilisearch-client | Клиент для Meilisearch |

### Тестирование

Пакет имеет обширное тестирование:
- Functional tests
- Performance tests
- Accuracy tests
- Edge cases tests
- Integration tests

Тесты расположены в `tests/` директории.

## Возможные проблемы

### 1. Проблемы с индексацией

| Проблема | Описание | Решение |
|----------|----------|---------|
| Большие файлы | Файлы не помещаются в контекст | Chunking стратегии |
| Неподдерживаемые типы | Файлы не индексируются | Расширение supported types |
| Дублирование | Дубли в индексе | Deduplication |
| Устаревание | Индекс не обновляется | Incremental indexing, watch |

### 2. Проблемы с поиском

| Проблема | Описание | Решение |
|----------|----------|---------|
| Низкая релевантность | Результаты нерелевантны | Reranking, hybrid search |
| Медленный поиск | Поиск занимает много времени | Кэширование, оптимизация |
| Пустые результаты | Нет результатов | Fallback strategies |

### 3. Проблемы с Meilisearch

| Проблема | Описание | Решение |
|----------|----------|---------|
| Недоступен | Meilisearch не запущен | Fallback на встроенный поиск |
| Индекс повреждён | Индекс в плохом состоянии | Пересоздание индекса |
| Memory usage | Высокое потребление памяти | Настройка лимитов |
