### Описание пакета

Пакет `@a2a/embedding` отвечает за генерацию эмбеддингов (векторных представлений текста) для системы RAG (Retrieval-Augmented Generation).

### Основные функции

| Функция | Описание |
|---------|----------|
| Text embedding | Преобразование текста в векторы |
| Sentence embeddings | Эмбеддинги предложений |
| Code embeddings | Специализированные эмбеддинги для кода |

## Возможные проблемы

### 1. Проблемы с моделями

| Проблема | Описание | Решение |
|----------|----------|---------|
| Модель недоступна | Модель эмбеддингов не загружена | Fallback на локальную модель |
| Размер модели | Слишком большая модель | Выбор более легкой модели |
| Качество | Низкое качество эмбеддингов | A/B тестирование моделей |

### 2. Проблемы производительности

| Проблема | Описание | Решение |
|----------|----------|---------|
| Медленная генерация | Генерация занимает много времени | Batch processing, кэширование |
| Высокое потребление памяти | Большое потребление RAM | Оптимизация, pooling |
| Rate limiting | Ограничение API | Retry с backoff |
