### Описание пакета

Пакет `@a2a/sdk` предоставляет клиентский и серверный SDK для работы с A2A протоколом. Включает async client, action handlers, session manager.

### Основные модули

| Модуль | Описание |
|--------|----------|
| async-client | Асинхронный клиент для A2A |
| session-manager | Управление сессиями |
| action-handler | Обработчик действий |
| protocol | Протокол связи |
| polling | Механизм опроса |
| simulation-helpers | Помощники для симуляций |

### Подмодули

| Подмодуль | Описание |
|-----------|----------|
| action-handlers/command-handler | Обработка команд |
| action-handlers/file-handlers | Обработка файлов |
| action-handlers/rag-handler | Обработка RAG запросов |
| action-handlers/script-handler | Обработка скриптов |
| action-handlers/ui-handlers | Обработка UI событий |
| server | Серверная часть SDK |

## Возможные проблемы

### 1. Проблемы соединения

| Проблема | Описание | Решение |
|----------|----------|---------|
| Timeout | Превышение времени ожидания | Retry с backoff |
| Разрыв соединения | Соединение разрывается | Auto-reconnect |
| SSL errors | Ошибки SSL сертификатов | Certificate handling |

### 2. Проблемы с клиентом

| Проблема | Описание | Решение |
|----------|----------|---------|
| Memory leak | Утечки памяти при длительной работе | Cleanup handlers |
| Blocking | Блокировка event loop | Async/await |
| Queue overflow | Переполнение очереди запросов | Rate limiting |

### 3. Проблемы с сервером

| Проблема | Описание | Решение |
|----------|----------|---------|
| High load | Высокая нагрузка на сервер | Connection limits |
| Slow responses | Медленные ответы | Performance monitoring |
| Sessions | Управление множеством сессий | Session pooling |
