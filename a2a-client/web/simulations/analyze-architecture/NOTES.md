# Заметки: analyze-architecture

## Тестирование
- Проверка обнаружения различных архитектурных паттернов (MVC, MVVM, Clean Architecture)
- Валидация анализа компонентной структуры

## Зависимости
- Требует AST-парсинга для определения паттернов
- Использует анализ импортов для построения графа зависимостей

## Примечание
Это симуляция gold standard - используется для тестирования парсера и валидации ответов сервера.
