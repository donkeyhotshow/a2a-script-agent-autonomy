# Заметки: analyze-full

## Тестирование
- Этот экшен является точкой входа для всех аналитических операций
- При получении запроса "проанализировать кодовую базу" сервер должен вернуть все доступные analyze-* экшены

## Зависимости
- Требует доступа к файловой системе для сканирования
- Может использовать RAG для семантического поиска по коду

## Примечание
Это симуляция gold standard - используется для тестирования парсера и валидации ответов сервера.
