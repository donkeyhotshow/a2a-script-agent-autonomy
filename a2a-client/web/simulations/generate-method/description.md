# Симуляция: generate-method

## Описание
Генерация нового метода для существующего класса (модели, контролера, сервиса). Добавление scope-метода или обычного метода.

## Тип экшена
`action_proposal`

## Входные данные
- action: `task_request`
- task: "добавить метод getActiveUsers до модели User"

## Ожидаемое поведение
Сервер должен предложить экшен generate-method с набором subActions:
- analyze-class - анализ существующего класса
- generate-method - генерация нового метода

## Sub-actions
1. **analyze-class** - анализ существующего класса User
2. **generate-method** - создание метода getActiveUsers

## Контекст выполнения
- При анализе класса сервер должен определить структуру, свойства и существующие методы
- Генерируемый метод должен соответствовать стилю и паттернам существующего класса
- Метод может быть scope (для моделей) или обычным методом
