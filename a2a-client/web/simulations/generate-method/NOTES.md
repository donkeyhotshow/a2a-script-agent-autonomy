# Заметки: generate-method

## Тестирование
- Экшен тестирует добавление метода к существующей модели
- Используется подход: анализ → генерация

## Зависимости
- Требует доступа к исходному коду класса для анализа
- Использует шаблоны для генерации методов разных типов (scope, accessor, mutator, обычный метод)

## Примечание
- Это симуляция генерации метода для Laravel Eloquent модели
- Метод scopeGetActiveUsers позволяет использовать User::getActiveUsers()
