# Симуляция: generate-controller

## Описание
Генерация контроллера для управления товарами (Product). Контроллер должен содержать полный набор CRUD методов.

## Тип экшена
`action_proposal`

## Входные данные
- action: `task_request`
- task: "создать контроллер для управления товарами"

## Ожидаемое поведение
Сервер должен предложить экшен generate-controller с subActions:
- inspect-model - проверка модели
- create-controller - создание контроллера
- add-category-methods - добавление методов для категорий
- generate-routes - создание маршрутов

Также может быть предложен альтернативный вариант - API контроллер.

## Sub-actions
1. inspect-model - анализ модели Product
2. create-controller - создание ProductController
3. add-category-methods - добавление методов категоризации
4. generate-routes - создание RESTful маршрутов

## Контекст выполнения
- Контроллер должен содержать стандартные RESTful методы
- При наличии связанных моделей должны быть методы для работы с ними
- Может быть выбран обычный или API-ориентированный контроллер
