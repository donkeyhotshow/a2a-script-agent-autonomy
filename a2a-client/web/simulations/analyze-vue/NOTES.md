# Заметки: analyze-vue

## Тестирование
- Проверка анализа Composition API (Vue 3)
- Валидация обнаружения props и emits

## Зависимости
- Требует vue-eslint-parser или аналогичный парсер для анализа .vue файлов
- Использует AST для анализа script и template секций

## Примечание
Это симуляция gold standard - используется для тестирования парсера и валидации ответов сервера.
