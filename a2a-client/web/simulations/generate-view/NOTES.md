# Заметки: generate-view

## Тестирование
- Экшен является составным - включает анализ модели и генерацию представления
- При получении запроса на создание формы сервер должен вернуть subActions: analyze-model, generate-view

## Зависимости
- Требует шаблоны для генерации компонентов (Vue, Blade, React)
- Может использовать различные фреймворки UI (Tailwind, Bootstrap и т.д.)
- Компонент должен соответствовать model_spec из analyze-model

## Примечание
- Это симуляция gold standard - используется для тестирования парсера и валидации ответов сервера
- generate-view зависит от результатов analyze-model
- Поддерживает различные типы представлений: form, table, card, list и т.д.
