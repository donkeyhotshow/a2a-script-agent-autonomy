# Симуляция: generate-view

## Описание
Генерация представления (Vue/Blade/React компонента) для отображения или редактирования данных сущности.

## Тип экшена
`action_proposal`

## Входные данные
- action: `task_request`
- task: "создать форму редактирования профиля пользователя"

## Ожидаемое поведение
Сервер должен предложить экшен generate-view с набором subActions:
- analyze-model - анализ модели для определения полей
- generate-view - генерация представления

## Sub-actions
1. analyze-model - анализ структуры модели для определения полей
2. generate-view - генерация компонента представления (Vue/Blade/React)

## Контекст выполнения
- При выполнении subActions сервер должен анализировать модель и генерировать компонент
- Компонент должен соответствовать указанному типу (form, table, card и т.д.)
- Должны быть учтены типы полей и валидации из model_spec
