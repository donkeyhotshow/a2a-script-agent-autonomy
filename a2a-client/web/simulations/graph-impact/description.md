# Симуляция: graph-impact

## Описание

Симуляция анализа влияния изменения конкретного файла (в данном случае — контроллера OrderController). Позволяет определить все файлы, которые могут быть затронуты при изменении, и оценить риск.

## Тип экшена

`action_proposal` — сервер предлагает действия на основе задачи пользователя.

## Входные данные (request.json)

- **action**: `task_request`
- **task**: "проанализировать влияние изменения контроллера OrderController"
- **options**:
  - `targetFile`: "src/controllers/OrderController.ts" (целевой файл)
  - `analysisType`: "full_impact" (тип анализа)
  - `includeTransitive`: true (включить транзитивные зависимости)
  - `maxDepth`: 10 (максимальная глубина)

## Ожидаемый ответ (response.json)

Сервер предлагает набор действий для анализа влияния:

1. **graph-impact** (приоритет 10) — полный анализ
   - find-controller: поиск контроллера в графе
   - analyze-dependencies: построение дерева зависимостей
   - classify-dependencies: классификация на прямые/транзитивные
   - assess-risk: оценка риска каждой зависимости
   - generate-report: формирование отчёта

2. **graph-impact-downstream** (приоритет 8) — анализ только нисходящих

3. **graph-impact-upstream** (приоритет 7) — анализ только восходящих

## Тестовые сценарии

1. Полный анализ влияния OrderController
2. Анализ только нисходящих зависимостей
3. Анализ только восходящих зависимостей
4. Оценка риска при изменении интерфейса
5. Глубокий анализ с ограничением глубины
6. Проверка циклических зависимостей
