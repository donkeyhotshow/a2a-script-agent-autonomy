# Заметки: graph-build

## Реализация

- **Статус**: ✅ Реализовано
- **Дата**: 2026-02-25

## Особенности реализации

1. **Сканирование файлов**: Использует glob паттерны для определения файлов
2. **Извлечение сущностей**: Парсит AST для выделения классов, интерфейсов, функций
3. **Построение связей**: Анализирует import/export statements для создания рёбер графа

## Зависимости

- Требует предварительного сканирования структуры проекта (analyze-full)
- Генерирует данные для graph-query и graph-impact

## Ожидаемые результаты

- Граф содержит узлы (сущности) и рёбра (зависимости)
- Поддерживает различные типы связей: imports, extends, implements, calls
- Может быть сериализован в JSON для хранения

## Тестирование

- Юнит-тесты для парсинга отдельных файлов
- Интеграционные тесты для полного цикла построения графа
- E2E тесты для проверки взаимодействия с клиентом
