🧪 Plasticine UI - Edge Cases Test

Test page for verifying edge case handling in floating panels and cubes.

1. Множественные кубы - позиционирование без перекрытия

Test: Multiple Cubes Pending

Создайте несколько панелей и закройте их в кубы. Кубы должны позиционироваться без перекрытия.

2. Drag за пределы экрана - ограничение границами

Test: Drag Boundaries Pending

Попробуйте перетащить панель или куб за пределы экрана. Они должны оставаться в пределах viewport.

3. Перекрытие кубов - z-index при drag

Test: Z-Index on Drag Pending

При drag куба он должен подниматься выше других кубов.

4. Потеря фокуса

Test: Focus Loss Pending

Клик вне куба НЕ должен закрывать его. Состояние панели должно сохраняться.

5. Resize панели - ограничения размера

Test: Resize Limits Pending

Минимальный размер: 180x120. Максимальный: не выходит за экран.

6. Docked зоны - несколько панелей

Test: Multiple Panels in Dock Pending

Перетащите панели в docked зоны. Bottom зона поддерживает 2 панели.

7. Состояния ошибок - SSE disconnect / API error

Test: Error States Pending

Визуальные индикаторы для SSE disconnect и API errors.
