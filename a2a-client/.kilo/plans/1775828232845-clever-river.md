# Plan: Fix Imports in @a2a-client/execution Package

## Overview
The @a2a-client/execution package has multiple import/export issues preventing proper module resolution:
- Circular export in index.ts
- Incorrect fs-utils.ts implementation using CommonJS in ES module
- Naming mismatches between exported functions and expected imports
- Missing PathSandbox class
- Package not built, causing export path issues

## Goals
- Fix all export/import issues in the execution package
- Ensure all dependencies (kernel, rag, vite-plugin) can import correctly
- Build the package to generate proper .js files
- Update package.json exports to point to built files

## Steps

### 1. Fix index.ts Circular Export
- Remove the invalid `export * from './index.ts';`
- Add proper re-exports from all relevant source files:
  - file-scanner.ts: FileScanner, ScannedFile, ScanResult
  - ignore-detector.ts: IgnoreDetector
  - glob-matcher.ts: GlobMatcher
  - path-sandbox.ts: PathSandbox
  - run-agent-command.ts: runClientExecuteCommand (as runAgentCommand for kernel compatibility)
  - run-agent-registered-script.ts: runClientRegisteredScript (as runAgentRegisteredScript)
  - run-agent-edit-patch.ts: runClientEditPatch (as runAgentEditPatch)
  - types.ts: All types

### 2. Fix fs-utils.ts Implementation
- Remove CommonJS `module.exports = require('@a2a/fs-utils');`
- Add proper ES module exports:
  - export { FileScanner, ScannedFile } from './file-scanner';
  - export { GlobMatcher } from './glob-matcher';
  - export { IgnoreDetector } from './ignore-detector';

### 3. Create PathSandbox Class
- Modify path-sandbox.ts to export both the function and a class wrapper
- Add: `export class PathSandbox { static resolveUnderProjectRoot = resolveUnderProjectRoot; }`
- Keep the original function export for vite-plugin compatibility

### 4. Handle Function Naming
- Export functions with both names to maintain backward compatibility:
  - export { runClientExecuteCommand as runAgentCommand } from './run-agent-command';
  - export { runClientRegisteredScript as runAgentRegisteredScript } from './run-agent-registered-script';
  - export { runClientEditPatch as runAgentEditPatch } from './run-agent-edit-patch';

### 5. Build the Package
- Run `npm run build` in packages/execution to compile TypeScript to dist/
- Verify dist/ directory is created with .js files

### 6. Update package.json Exports
- Change exports to point to dist/ files:
  - ".": "./dist/index.js"
  - "./fs-utils": "./dist/fs-utils.js"
  - etc.

### 7. Verify Imports Work
- Check that kernel/features/execution.ts can import all expected exports
- Verify rag package imports work
- Confirm vite-plugin imports still function

## Risks
- Breaking changes if vite-plugin expects specific function names
- TypeScript compilation errors during build
- Path resolution issues if dist/ structure differs from src/

## Testing
- Run build and check for compilation errors
- Attempt imports in dependent packages
- Run any existing tests to ensure functionality</content>
