     - Описать процесс миграции данных и сценариев между версиями.
  2. Документировать интеграционные сценарии с другими модулями (landing, contact-form, QTU).
     - Привести примеры использования primary-form в других модулях.
     - Описать типовые точки интеграции (actions, include, meta).
     - Добавить раздел "Интеграция" в README.
  3. Вынести генератор форм в отдельный переиспользуемый компонент.
     - Оформить генератор как самостоятельный блок с API.
     - Описать способы подключения и настройки.
     - Добавить тесты на корректность генерации форм.
  4. Добавить тесты на обработку сложных вложенных структур.
     - Подготовить набор edge-case JSON-структур.
     - Проверить корректность генерации UI и итоговых данных.
  5. Описать типовые сценарии использования в README.
     - Составить разделы "Быстрый старт", "Расширенные сценарии", "FAQ".
  6. Продумать экспорт/импорт схем и пользовательских шаблонов.
     - Реализовать функции сохранения/загрузки схем.
