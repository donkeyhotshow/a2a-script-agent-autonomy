# Модуль Login Form (v1)

## Обзор

**Версия:** 1.0 (Базовая, с проблемами)

> **Примечание по верификации модуля:** Для проверки соответствия модуля стандартам проекта
> используйте [Чек-лист верификации модуля](../../../checklists/module-verification.md)
> и [Чек-лист стандартов UI компонентов](../../../checklists/component-standards.md).

Модуль Login Form v1 предоставляет базовый функционал для аутентификации пользователей в приложении, включая стандартный
вход по логину/паролю и (частично) социальную авторизацию.

**Статус:** **Нестабилен и не рекомендуется к использованию в production.** Основная проблема — нестабильная работа с
сессиями и моделями данных (`session:`, `model:`). Содержит устаревший код и нефункциональные части (социальная
авторизация). Требует значительной доработки или замены на v2.

## Структура модуля (v1)

- **`templates/`**: Содержит JSON-шаблоны для различных представлений формы (карточка, вкладки).
- **`actions/`**: Определения действий для логина, логаута, регистрации, запроса восстановления пароля.
- **`commands/`**: PHP-классы для серверной логики (аутентификация, проверка пароля, работа с пользователем).
- **`docs/`** :
    - `known-issues.md`: Подробный список проблем, включая нестабильность `session:` и `model:`.
    - `migration-plan-to-v2.md`: Заготовка для плана миграции.

## Ключевые особенности (v1)

- Базовая форма входа (логин/пароль).
- Чекбокс "Запомнить меня".
- Ссылки на регистрацию и восстановление пароля.
- Попытка реализации социальной авторизации (не работает).

## Основные проблемы и ограничения (v1)

- **Нестабильная работа с сессиями и моделями:** Ключевая проблема, делающая модуль ненадежным. Используются обходные
  пути с `localStorage`, что небезопасно и не решает проблему полностью.
- **Неработающая социальная авторизация:** Код устарел и несовместим с современными API.
- **Ограниченная валидация:** Отсутствует проверка сложности пароля, асинхронная валидация и т.д.
- **Проблемы с восстановлением пароля:** Требует настройки почты и шаблонов.
- **Ограниченная кастомизация UI.**

> Подробное описание см. в [Известные проблемы v1](./known-issues.md).

## Миграция на v2

Настоятельно рекомендуется использовать или мигрировать на **Login Form v2**, который должен решить основные проблемы с
сессиями, моделями и предоставить более надежный и современный функционал аутентификации.

- Подробные планы и задачи для v2 см. в директории [
  `docs/_planning/login-form-v2-upgrade-tasks/`](../../_planning/login-form-v2-upgrade-tasks/).
- Общие процессы версионирования и миграции описаны в [`docs/processes/versioning/`](../../processes/versioning/).
- [Обзор Login Form v2](../login-form-v2/README.md)
