# Исходный код модуля Login Form

Модуль Login Form существует в двух версиях:

- **Установленная версия:** `storage/ai/login-form/`
- **Версия инсталлятора:** `storage/aiInstaller/login-form/`

Этот документ предоставляет обзор структуры исходного кода обеих версий.

## Обзор структуры

Обе версии модуля (`storage/ai/login-form/` и `storage/aiInstaller/login-form/`) имеют схожую базовую структуру
каталогов, содержащую основные компоненты, необходимые для аутентификации:

- `page.json`: Точка входа для интеграции модуля.
- `code/`: Содержит PHP-класс модуля (`LoginForm.php`).
- `actions/`: Определяет клиентские действия (например, обработка отправки формы).
- `commands/`: Содержит серверную логику (например, проверка учетных данных).
- `templates/`: UI-шаблоны (макеты `card-layout` и `tabs-layout`).
- `validations/`: Правила валидации форм.

### Отличия версии инсталлятора (`storage/aiInstaller/login-form/`)

Версия инсталлятора содержит дополнительную директорию `_i/` с метаданными, необходимыми для процесса установки:

- `meta.json`: Основная информация о модуле (название, версия, зависимости).
- `meta-admin.json`: Административные метаданные (могут отсутствовать или быть пустыми).
- `common.json`: Общие настройки установки (могут отсутствовать или быть пустыми).
- `files-by-block.json`: Структура файлов для процесса установки.
- `useAnyway.json`: Настройки принудительного использования (могут отсутствовать или быть пустыми).

## Структура директорий (Детально)

### Установленная версия (`storage/ai/login-form/`)

```
storage/ai/login-form/
├── page.json                # Основной контейнер страницы
├── code/                    # PHP-классы модуля
│   └── LoginForm.php        # Основной класс модуля
├── actions/                 # Обработчики действий
│   ├── login-form/          # Действия для формы логина
│   │   └── login.json       # Обработка отправки формы логина
│   ├── login-and-password/  # Дополнительные действия для входа (может быть устаревшим)
│   ├── logout.json          # Завершение сессии
│   ├── register.json        # Регистрация нового пользователя
│   └── social-auth.json     # Обработчики социального входа
├── commands/                # Серверная обработка
│   ├── api-request.json     # Общие запросы к API (может быть неиспользуемым)
│   ├── authenticate.json    # Проверка учетных данных
│   ├── forgot-password.json # Восстановление пароля
│   ├── oauth-callback.json  # Обработка OAuth-ответов
│   ├── process-social-login.json # Обработка соц. логина
│   └── reset-password.json  # Сброс пароля
├── data/                    # Структуры данных (может быть пустым или неиспользуемым)
├── templates/               # UI-компоненты
│   ├── layouts/             # Варианты макетов
│   │   ├── card-layout.json # Макет в виде карточки
│   │   └── tabs-layout.json # Интерфейс с вкладками
└── validations/             # Валидация ввода
    ├── login-validation.json # Валидация полей логина
    └── registration-validation.json # Валидация регистрации
```

### Версия инсталлятора (`storage/aiInstaller/login-form/`)

Структура аналогична установленной версии, но с добавлением директории `_i/`:

```
storage/aiInstaller/login-form/
├── ... (все каталоги и файлы как в установленной версии)
└── _i/
    ├── meta.json
    ├── meta-admin.json
    ├── common.json
    ├── files-by-block.json
    └── useAnyway.json
```

## Ключевые файлы и их назначение

- **`LoginForm.php`**: Основной PHP-класс, расширяющий `App\AiRudeDepot\App\App`. Определяет папку модуля.
  ```php
  <?php
  namespace App\AiRudeDepot\Modules;
  use App\AiRudeDepot\App\App;

  class LoginForm extends App
  {
      public $folder = 'login-form';
  }
  ```
- **`page.json`**: Определяет доступные макеты (`card` и `tabs`) и пути к их файлам.
- **`templates/layouts/*.json`**: Определяют JSON-структуру UI для макетов карточки и вкладок.
- **`actions/login-form/login.json`**: Обрабатывает событие отправки формы логина, передает данные команде
  `authenticate`.
- **`commands/authenticate.json`**: Выполняет серверную логику проверки учетных данных, валидации, взаимодействия с
  моделью `User` и обновления сессии.
- **`validations/*.json`**: Содержат правила валидации для форм логина и регистрации.
- **`_i/meta.json`**: Определяет метаданные модуля для инсталлятора (имя, версия, зависимости).
