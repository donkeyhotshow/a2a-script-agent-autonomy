# Документация модуля Login Form

Добро пожаловать в документацию модуля Login Form. Данный раздел содержит полную информацию о модуле аутентификации, его
структуре, компонентах и использовании.

> **Важно:** При работе с модулем Login Form рекомендуется ознакомиться
> с [чек-листом верификации модуля](../../../../checklists/module-verification.md)
> и [чек-листом стандартов UI компонентов](../../../../checklists/component-standards.md).

## Доступные версии модуля

Модуль доступен в двух версиях:

- ~~**Установленная версия**: `storage/ai/login-form/` - используется в приложении~~ > **Коррекция:** Эта директория не
  найдена при верификации. Фактически используется версия из `storage/aiInstaller/`.
- **Версия инсталлятора**: `storage/aiInstaller/login-form/` - используется для установки модуля (и, вероятно, для
  работы).

## Процесс установки

> **Коррекция:** Установка описана как копирование из инсталлятора в `storage/ai/`. Так как `storage/ai/` не
> используется, процесс установки, скорее всего, отличается или не требуется (система работает с
`storage/aiInstaller/`).

Для установки модуля из версии инсталлятора:

1. Убедитесь, что у вас есть доступ к директории `storage/aiInstaller/login-form/`
2. ~~Используйте процесс установки, который копирует файлы из директории инсталлятора в директорию установленных
   модулей~~ (Уточнить реальный процесс установки/использования)
3. Настройте необходимые зависимости, указанные в `meta.json`
4. Интегрируйте модуль в ваше приложение, используя компонент включения (см. "Быстрый старт")

Подробнее о [структуре модулей в JSON UI](/docs/ui/json-ui - гдето здесь - переделать ссылку )
и [формате установочных файлов](/docs/ui/json-ui - гдето здесь - переделать ссылку ).

## Особенности реализации

Модуль Login Form использует следующие концепции и технологии:

- **Глобальные менеджеры**: Модуль интегрируется с [
  `hub.formManager`](mdc:../../../../resources/common/managers/FormManager.js) для управления состоянием форм и
  ~~[`hub.notifyManager`](mdc:../../../../ui/json-ui/core-concepts/managers.md)~~ (Вероятно, не используется или назван
  иначе) для обработки событий.
- **Валидация**: Формы входа, регистрации и восстановления пароля
  используют [серверную валидацию](/docs/ui/json-ui - гдето здесь - переделать ссылку ) через Laravel.
- **Компоненты UI**: Модуль использует стандартные компоненты, такие
  как [Form](mdc:../../../../ui/json-ui/components/form.md), [Card](mdc:../../../../ui/json-ui/components/card.md), [Tab](mdc:../../../../ui/json-ui/components/tab.md)
  и различные элементы ввода.
- **Обработка действий**: Модуль
  реализует [серверные действия](/docs/ui/json-ui - гдето здесь - переделать ссылку ) для аутентификации,
  регистрации и сброса пароля.

## Компоненты модуля

Модуль Login Form включает в себя следующие компоненты:

- Компоненты пользовательского интерфейса для форм входа, регистрации и восстановления пароля
- Серверные действия и команды для обработки аутентификации
- Валидацию ввода для всех форм
- Социальную авторизацию (при соответствующей настройке)

Дополнительные сведения о модуле и способах его использования можно найти в
основной [документации модуля](mdc:./login-module.md).
