# Оглавление Документации: Модуль `question-to-user` (QTU) v5

Этот документ предоставляет ссылки на ключевые разделы документации модуля QTU v5.

## Основные Документы

- **[README.md](./README.md)**: Общая информация о модуле – назначение, основные сценарии, структура, ограничения и
  вопросы миграции.
- **[Основная Документация QTU v5](./question-to-user-v5-documentation.md)**: Наиболее полное описание архитектуры,
  потоков данных, ключевых `actions`, структур данных и принципов работы модуля. **Это главный технический документ по
  модулю.**
- **[Схемы Данных](./data-schema.md)**: Подробное описание форматов JSON для наборов вопросов, ответов пользователя и
  других структур данных, используемых модулем.
- **[Интеграция с Задачами и Сценариями](./task-scenario-integration.md)**: Подробное руководство по интеграции модуля с системой управления задачами и сценариями, включая компоненты интерфейса, действия и потоки данных.
- **[Известные Проблемы и Ограничения](./known-issues.md)**: Список текущих известных проблем, ошибок валидации и
  ограничений функциональности.
- **[Описание Кода (PHP)](./code.md)**: Информация о структуре и компонентах PHP-кода в директории `code/`, если таковой
  присутствует и используется модулем.
- **[История Изменений (Changelog)](./changelog.md)**: Хронологический список изменений, внесенных в модуль.

## Вспомогательная Документация и Ресурсы

- **[Чек-лист Финализации](./finalization-checklist.md)**: Внутренний чек-лист для проверки готовности модуля.
- **[Состояние после рефакторинга (архивное)](./question-to-user-v5-refactored-state.md)**: Документ, описывающий
  состояние модуля на определенном этапе рефакторинга (может быть полезен для понимания истории изменений).
