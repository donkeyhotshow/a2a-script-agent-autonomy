# Техническое задание: Интеграция QTU v5 с системой сценариев

## 1. Общие требования

### 1.1 Цель
Интеграция модуля Question-to-User (QTU) v5 с системой сценариев для автоматической синхронизации вопросов и их использования в сценариях.

### 1.2 Область применения
- Модуль QTU v5
- Система сценариев
- Интеграционный слой между системами

## 2. Формат вопросов

### 2.1 Структура JSON
```json
{
  "id": "question-001",
  "text": "Какой ваш любимый цвет?",
  "type": "single-choice",
  "options": ["Красный", "Синий", "Зелёный"],
  "tags": ["preferences", "color"],
  "conditions": {
    "showIf": "user.age > 18"
  },
  "metadata": {
    "created": "2024-03-20T10:00:00Z",
    "updated": "2024-03-20T10:00:00Z",
    "author": "system",
    "version": "1.0"
  }
}
```

### 2.2 Обязательные поля
- `id`: Уникальный идентификатор вопроса
- `text`: Текст вопроса
- `type`: Тип вопроса (single-choice, multiple-choice, text, etc.)
- `metadata`: Метаданные вопроса

### 2.3 Опциональные поля
- `options`: Массив вариантов ответов
- `tags`: Массив тегов для категоризации
- `conditions`: Условия отображения вопроса
- `validation`: Правила валидации ответа

## 3. Механизм синхронизации

### 3.1 Источник вопросов
- ИИ сохраняет вопросы в JSON-файлы
- Файлы хранятся в директории `data/questions/`
- Поддерживается версионирование файлов

### 3.2 Процесс синхронизации
1. Скрипт мониторит директорию с вопросами
2. При появлении новых/измененных файлов:
   - Проверяет валидность JSON
   - Проверяет уникальность ID
   - Копирует в рабочую директорию модуля
3. Модуль QTU обрабатывает новые вопросы:
   - Преобразует в нужный формат
   - Сохраняет как часть шаблона
   - Обновляет индексы

### 3.3 Обработка конфликтов
- При конфликте версий сохраняется последняя
- Ведется лог изменений
- Уведомление администратора при ошибках

## 4. Интеграция с системой сценариев

### 4.1 API для сценариев
```php
// Получение списка вопросов
GET /api/questions
Parameters:
  - tags: string[] (optional)
  - type: string (optional)
  - limit: int (optional)
  - offset: int (optional)

// Получение конкретного вопроса
GET /api/questions/{id}

// Сохранение ответа
POST /api/questions/{id}/answer
Body:
{
  "answer": "string|string[]",
  "metadata": {
    "timestamp": "ISO8601",
    "session_id": "string"
  }
}
```

### 4.2 Формат ответов
```json
{
  "question_id": "question-001",
  "answer": "Красный",
  "metadata": {
    "timestamp": "2024-03-20T10:30:00Z",
    "session_id": "session-123",
    "user_id": "user-456"
  }
}
```
