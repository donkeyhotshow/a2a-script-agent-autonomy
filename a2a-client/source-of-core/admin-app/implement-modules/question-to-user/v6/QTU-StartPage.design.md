# QTU-StartPage: Проектирование

## Назначение
Стартовая страница QTU-сценариев, выбор сценария или действия, быстрый переход к нужному процессу.

---

## Best Practices
- Для быстрого выбора сценария — отдельная секция с lastScenario (см. playground).
- Для динамических секций использовать operation: include (см. page/sections, playground/sections).

### Пример секции с dynamic include
```json
{
  "type": "section",
  "props": { "title": "Выберите сценарий" },
  "children": [
    { "operation": "include", "source": "file!qtu/sections/scenario-list.json" }
  ]
}
```

---

## Пример структуры данных (view-only)
```json
{
  "type": "Page",
  "props": {
    "title": "Старт QTU",
    "user": "{input:userName}",
    "lastScenario": "{file!qtu/data/last-scenario.json}"
  },
  "content": [
    {
      "type": "section",
      "props": { "title": "Выберите сценарий" },
      "children": [
        { "operation": "include", "source": "file!qtu/sections/scenario-list.json" }
      ]
    }
  ]
}
```

---

## Расширяемость
- Для добавления новых приветствий/стартовых сценариев — добавить шаблон в sections и использовать operation: include.
- Для динамических секций — использовать только operation: include.

## Вопросы для сбора требований (да/нет)
1. Должна ли страница отображать приветствие пользователю?
2. Нужен ли быстрый выбор последнего использованного сценария?
3. Должен ли быть поиск по сценариям?
4. Требуется ли фильтрация сценариев по категориям?
5. Должна ли страница показывать описание каждого сценария?
6. Нужно ли отображать статус (новый/в процессе/завершен) для сценариев?
7. Должна ли быть кнопка "Создать новый сценарий"?
8. Требуется ли отображение избранных сценариев?
9. Должна ли быть поддержка мультиязычности?
10. Нужно ли отображать количество шагов в каждом сценарии?
11. Должна ли быть интеграция с системой уведомлений?
12. Требуется ли отображение подсказок/FAQ?
13. Должна ли быть возможность быстрого перехода к админ-панели?
14. Нужно ли отображать дату последнего запуска сценария?
15. Должна ли быть поддержка темной/светлой темы?
16. Требуется ли отображение прогресса по всем сценариям?
17. Должна ли быть возможность закреплять сценарии вверху списка?
18. Нужно ли отображать аватар пользователя?
19. Должна ли быть поддержка мобильной версии?
20. Требуется ли отображение глобального поиска по всей системе?
