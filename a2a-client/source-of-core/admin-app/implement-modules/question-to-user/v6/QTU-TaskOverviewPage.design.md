# QTU-TaskOverviewPage: Проектирование

## Назначение
Страница для обзора всех задач, связанных вопросов, статусов, истории и действий пользователя в рамках QTU-модуля. Используется как основной интерфейс для управления задачами и их вопросами.

## Итоговые проектные выводы
- Страница работает только с группами задач и вопросов, определенными входящими файлами (нет ручного создания/редактирования).
- Краткая информация о задачах, файлы, инициатор, комментарии, прогресс — только если есть во входящих данных.
- Мобильная версия обязательна. Ошибки и ручное обновление поддерживаются.
- Нет поиска, сортировки, экспорта, drag-and-drop, истории изменений.

## Best Practices (факты, только page, playground, landing-main-page)
- Для динамических секций использовать operation: include (см. page/sections, playground/sections).
- Для статусов и тегов использовать массивы, а не строки (см. playground, landing-main-page).
- Для bulk-операций использовать отдельные секции и шаблоны (см. playground/templates).

### Пример секции с dynamic include (page/playground)
```json
{
  "type": "section",
  "props": { "title": "Динамический блок" },
  "children": [
    { "operation": "include", "source": "file!qtu/sections/dynamic-block.json" }
  ]
}
```

### Пример массива статусов (playground)
```json
{
  "status": ["active", "urgent"]
}
```

```json
{

  "content": [
    {
      "type": "table",
      "props": {
        "columns": [
          { "label": "Задача", "field": "title" },
          { "label": "Статус", "field": "status" },
          { "label": "Вопросы", "field": "questionsCount" }
        ],
        "data": "file!qtu/data/task-list.json"
      }
    },
    {
      "type": "section",
      "props": { "title": "Динамический блок" },
      "children": [
        { "operation": "include", "source": "file!qtu/sections/dynamic-block.json" }
      ]
    }
  ]
}
```

---

## Расширяемость
- Для добавления новых типов задач или bulk-операций — добавить шаблон в sections и использовать operation: include.
- Для расширения статусов — использовать массивы для гибкости фильтрации (см. playground).
- Для динамических секций — использовать только operation: include (см. page, playground).
