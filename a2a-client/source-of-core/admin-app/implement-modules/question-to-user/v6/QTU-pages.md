## [Плейсхолдер] Для новых страниц/сценариев
- Здесь будут добавляться новые страницы и сценарии QTU по мере развития модуля.
- Пример: QTU-NotificationsPage, QTU-AnalyticsPage, QTU-SettingsPage и др.

---

## Как добавлять новые страницы/сценарии
- Создать новый .design.md файл по шаблону (см. ниже).
- Добавить краткое назначение, вопросы/ответы, итоговые выводы, view-only JSON, плейсхолдеры для расширения.
- Внести новую страницу в этот список.

# Инструкция по проектированию
- Для каждой страницы создается отдельный файл проектирования (например, QTU-StartPage.design.md).
- В каждом файле: краткое назначение, 20 вопросов (да/нет) для сбора требований, ответы пользователя, итоговые проектные выводы.
- После получения ответов — анализ, нужно ли добавить еще вопросы.
- Все вопросы и ответы остаются в файле для прозрачности требований.
