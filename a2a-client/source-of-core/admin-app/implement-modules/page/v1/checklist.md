# Чеклист: Модуль page (шаблоны и статические страницы)

## 1. Существующие элементы (по категориям)

### Страницы (pages/)
- about-us.json — О компании
- booking.json — Бронирование
- contact.json — Контакты
- services.json — Услуги
- errors/404.json — Страница не найдена
- errors/403.json — Доступ запрещён
- errors/500.json — Внутренняя ошибка
- tests/validation-test-max-errors.json, validation-test-valid-example.json — тестовые страницы

### Секции (sections/)
- landing-header.json, landing-footer.json — секции для лендинга
- services/* — секции для услуг (barber, tattoo, booking-cta и др.)
- contact/* — секции для контактов (контент, инфо, карта, FAQ)
- about-us/* — секции для about-us (hero, история, команда, ценности)

### Шаблоны (templates/)
- category-button.json, product-card.json — карточки, кнопки
- header/ — brand-logo, navigation-links, login-signup-button
- dialogs/info-dialog.json — инфо-диалог

### Вспомогательные файлы (_i/)
- links.json, filesByBlock.json, common.json, assets.json, meta-admin.json, meta.json, useAnyway.json

### Логика (logic.json)
- Описаны действия update/print_r для работы с permalinks и страницами.

### Примерные/пустые (examples/, code/)
- examples/ — пусто
- code/Page.php — заготовка класса

- [ ] Проверить тестовые страницы — вынести их в отдельную категорию, если используются для разработки.

### Секции (sections/)
- [ ] Проверить и доработать все секции (landing-header, landing-footer, services/*, contact/*, about-us/*) — добавить недостающие поля, привести к единому стилю.
- [ ] Для каждой секции — добавить описание, где и как используется.

### Шаблоны (templates/)
- [ ] Проверить и доработать все шаблоны (category-button, product-card, header/*, dialogs/*) — привести к стандарту, добавить описание.

### Админ-страницы (запланировать и создать)
- [ ] admin-dashboard.json — главная админки

- [ ] admin-landing.json — landing для админки (если требуется)
- [ ] Для каждой админ-страницы — добавить описание, статус, ограничения доступа.

### Прочее
- [ ] Проверить и доработать вспомогательные файлы (_i/) — актуализировать meta, links, assets.
- [ ] Проверить и доработать логику (logic.json) — добавить описание, если требуется расширить обработку страниц.
