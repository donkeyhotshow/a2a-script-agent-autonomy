# Чеклист и план развития: модуль landing-main-page (v1)

## 1. Назначение и структура

Модуль предназначен для демонстрации UI-возможностей фреймворка AiRudeDepot. Включает showcase-страницы, интеграцию с page и contact-form, примеры layout, секций, адаптивности, динамики.

---

## 2. Существующие страницы и секции

- pages/: page.json, shop.json, about-us.json, booking.json, contact.json, services.json
- sections/: header, footer, hero, features, map, services, booking, about-us, contact и др.
- actions/: (нетиповые действия для лендинга)
- MARKETPLACE-LANDING-PAGE.md — описание концепции

---

## 3. План развития и интеграции

- [ ] Для каждой страницы — meta-блок (описание, статус, категория: landing, demo, integration)
- [ ] Showcase-страницы для разных layout-решений, тем, адаптивности
- [ ] Использование секций и шаблонов из page (header, footer, hero, features и др.)
- [ ] Интеграция с contact-form:
    - Вставка формы из contact-form на страницу contact
    - Использование секций contact-content-section, contact-info-section
    - Отображение статуса отправки, ошибок, обратной связи
- [ ] Визуализация типовых сценариев: лендинг, промо, CTA, отзывы, карта, блоки преимуществ
- [ ] Для каждой страницы — предусмотреть интеграцию с page и contact-form (relatedModules в meta)
- [ ] README или index.json с оглавлением и аннотациями

## 4. Рекомендации
- Для всех новых и дорабатываемых страниц — meta с описанием, статусом, категорией, relatedModules
- Для интеграционных страниц — явно указывать, какие модули и шаблоны используются
- README или index.json с оглавлением, аннотациями и связями между модулями
- Для сложных сценариев — визуальные схемы, тестовые данные, автоматические тесты
