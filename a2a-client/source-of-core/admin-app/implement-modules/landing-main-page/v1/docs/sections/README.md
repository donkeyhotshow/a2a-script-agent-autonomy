# Секции Landing Page

## Обзор

Модуль Landing Page, такой как `landing-main-page`, построен из отдельных секций. Каждая секция представляет собой
отдельный `JSON`-файл, который включается в основной шаблон страницы (например, `page.json`) с помощью операции
`include`. Реже может использоваться операция `add` для добавления содержимого секции в массив `children` родительского
элемента.

## Структура директории секций (Пример `landing-main-page`)

<!-- ```bash
landing-main-page/sections/
├── header-section.json # Верхняя навигационная панель
├── hero-section.json # Основной баннер (первый экран)
├── features-section.json # Секция преимуществ (карточки)
├── highlights-section.json # Секция ключевых особенностей (карточки с картинками)
├── pricing-section.json # Цены на услуги (карточки планов)
├── map-section.json # Карта с расположением и информацией
├── values-section.json # Секция ценностей (карточки)
└── footer-section.json # Нижняя часть сайта
``` -->

*Примечание: В других модулях Landing Page набор секций может отличаться.*

## Взаимосвязи секций

Секции связаны между собой через:

1. **Навигационные элементы:** `Header` и `Footer` содержат ссылки/действия для перехода на другие страницы модуля.
2. **Кнопки действий (CTA):** Кнопки в секциях (например, `Hero`) инициируют переходы на другие страницы (например,
   бронирования или услуг).

## Основные типы секций (На примере `barber-and-tattoo`)

### Навигационные секции

- **`Header`:** Верхняя панель с лого, меню, CTA, переключателем мобильного меню.
- **`Footer`:** Нижняя часть с лого, навигацией, контактами, соцсетями, копирайтом.

### Информационные/Презентационные секции

- **`Hero`:** Главный баннер с основным предложением, CTA, соц. доказательствами.
- **`Features`:** Преимущества в виде карточек с иконками.
- **`Highlights`:** Ключевые особенности в виде карточек с изображениями.
- **`Pricing`:** Тарифные планы в виде карточек (кнопки **неактивны** в текущей реализации).
- **`Map`:** Карта (плейсхолдер), адрес, информация о транспорте.
- **`Values`:** Основные ценности в виде карточек с иконками.

### Интерактивные секции

- Интерактивность ограничена:
    - **Навигацией:** Переходы между страницами (`navigateTo`).
    - **Локальными UI эффектами:** Переключение видимости (`toggleClass`).
- Сложные формы (контакты, бронирование) и серверные действия отсутствуют в самих секциях (они могут быть реализованы
  как отдельные *страницы*, например, `booking.json`, `contact.json`).

## Включение секций в основной файл страницы (`page.json`)

Секции обычно включаются с помощью операции `include`, которая заменяет элемент `operation` содержимым файла секции.

<!-- ```json
{
  "type": "div", // Или Panel, etc.
  "children": [
    {
      "type": "operation",
      "action": "include",
      "source": "landing-main-page/sections/header-section" // Путь к файлу секции (без .json)
    },
    {
      "type": "operation",
      "action": "include",
      "source": "landing-main-page/sections/hero-section"
    },
    // ... другие include для features, highlights, etc. ...
    {
      "type": "operation",
      "action": "include",
      "source": "landing-main-page/sections/footer-section"
    }
  ]
}
``` -->

Операция `add` может использоваться, если нужно добавить несколько секций или других элементов из файлов в один массив
`children`.

## Навигация и Интерактивность в секциях

В модуле `landing-main-page` используются следующие подходы:

1. **`customHooks` с `navigateTo` (`route`):**
    * Используется в **`Header`** (меню, лого, CTA) и **`Hero`** (CTA) для перехода на *внутренние страницы модуля*.
   <!-- ```json
   // Пример в Header или Hero Button/Link
   "customHooks": {
     "click": [
       {
         "action": "navigateTo",
         "data": { "route": "/landing-main-page/booking" }
       }
     ]
   }
   ``` -->

2. **`customHooks` с `navigateTo` (`url`):**
    * Используется в **`Map`** секции для ссылки на внешний ресурс (Google Maps), открываемой в новой вкладке.
   <!-- ```json
   // Пример в Map Button
   "customHooks": {
     "click": [
       {
         "action": "navigateTo",
         "data": { "url": "https://maps.google.com", "target": "_blank" }
       }
     ]
   }
   ``` -->

3. **`customHooks` с `toggleClass`:**
    * Используется в **`Header`** для переключения видимости мобильного меню.
   <!-- ```json
   // Пример в Header Mobile Toggle Button
   "customHooks": {
     "click": [
       {
         "action": "toggleClass",
         "data": { "selector": ".mobile-menu", "class": "hidden" }
       }
     ]
   }
   ``` -->

4. **Компонент `Link` с `href`:**
    * Используется в **`Footer`** для стандартной навигации по страницам модуля и для внешних ссылок (например,
      соцсети).
   <!-- ```json
   // Пример в Footer
   {
     "type": "Link",
     "props": {
       "href": "/landing-main-page/services", // Внутренний роут
       "label": "Послуги",
       "class": "text-gray-300 hover:text-white ..."
     }
   }
   // Или для внешней ссылки
   {
     "type": "Link",
     "props": {
       "href": "https://facebook.com", // Внешний URL
       "target": "_blank",
       // ... props for icon or label
     }
   }
   ``` -->

## Лучшие практики

- **Модульность:** Создавайте переиспользуемые секции.
- **Единообразие:** Используйте консистентные стили и структуру.
- **Адаптивность:** Проверяйте отображение на разных устройствах.
- **Интерактивность:** Используйте `navigateTo` (`route`/`url`) для переходов и `toggleClass` для локальных UI-эффектов
  через `customHooks`. Используйте `Link` с `href` для стандартной навигации (например, в футере).
- **Доступность:** Обеспечивайте правильную структуру заголовков и атрибуты `ARIA`.
