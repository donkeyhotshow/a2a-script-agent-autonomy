# Структура Данных Модуля Landing Page

## Обзор

Этот документ описывает типичную структуру данных для модуля Landing Page, фокусируясь на директориях `data/` и
`assets/`.

## Директория `data/`

- **Назначение:** Хранение **статических данных** в формате `JSON`, которые могут быть подгружены и использованы в
  `JSON`-шаблонах страниц и секций.
- **Примеры данных:**
    - Списки (например, услуги, члены команды, вопросы FAQ).
    - Текстовые блоки (например, описания, цитаты).
    - Конфигурационные параметры, не связанные с внешним видом (например, ID для интеграций).
- **Использование:**
    - Позволяет отделить контент от структуры `UI`.
    - Упрощает обновление данных без модификации основных `JSON`-файлов секций.
    - Данные из `data/*.json` обычно включаются в основной `JSON` на серверной стороне с помощью операций `include` или
      `add`.
- **Текущий статус в `landing-main-page`:** В примере `landing-main-page` эта директория **не используется** активно;
  контент в основном встроен в файлы секций. Наличие `data/` рекомендуется для более сложных или часто обновляемых
  лендингов.

## Директория `assets/`

- **Назначение:** Хранение **статических ресурсов** модуля, таких как изображения, иконки, шрифты, которые используются
  непосредственно в `UI`.
- **Примеры ресурсов:**
    - Логотипы (`logo.png`).
    - Фоновые изображения (`background.jpg`).
    - Иконки для преимуществ (`feature-icon.svg`).
    - Фотографии команды (`team-member.jpg`).
- **Использование:**
    - Пути к ресурсам указываются в `JSON`-шаблонах, обычно в `props.src` для компонента `Image` или в `props.style` (
      например, `background-image`).
    - **⚠️ Важно:** На текущий момент, механизм **автоматического копирования** содержимого папки `assets/` из
      `storage/aiInstaller/your-module/assets/` в публичную директорию (например,
      `storage/app/public/module-assets/your-module/`) во время установки модуля **еще не реализован** или находится в
      стадии разработки в `ModuleInstaller`. Необходимо убедиться, что пути к ресурсам, указанные в `JSON`, будут
      корректно разрешаться после установки модуля (возможно, потребуется ручное копирование или доработка
      инсталлятора).
