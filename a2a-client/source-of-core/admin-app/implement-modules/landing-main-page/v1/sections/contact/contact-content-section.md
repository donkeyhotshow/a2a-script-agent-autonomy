# Детализация секции: contact-content-section

---

## Назначение
- Основная секция для страницы контактов на лендинге.
- Включает:
  - Блоки с контактной информацией (телефоны, email, адрес, часы работы)
  - Кнопки соцсетей
  - Форму обратной связи (интеграция с contact-form)
  - Адаптивную сетку для desktop/mobile

---

## Структура (основные элементы)

1. **Заголовок и подзаголовок**
   - h2: "Зв'яжіться з нами"
   - p: "Ми завжди раді відповісти на ваші запитання..."

2. **Контактные карточки (Grid 2x2)**
   - Телефон (иконка, список номеров, кнопки для звонка)
   - Email (иконка, email, кнопка для отправки)
   - Адрес (иконка, адрес, карта/ссылка)
   - Часы работы (иконка, расписание по дням)

3. **Кнопки соцсетей**
   - Facebook, Instagram, Telegram (иконки, стилизация)

4. **Форма обратной связи**
   - Заголовок: "Надіслати повідомлення"
   - Поля:
     - Имя (InputText)
     - Email (InputText, type=email)
     - Тема (Dropdown: варианты вопросов)
     - Сообщение (Textarea)
   - Кнопка "Надіслати" (отправка формы)
   - **Интеграция:**
     - Данные формы должны отправляться через action из contact-form (receive-submission)
     - Валидация и обработка ошибок — через contact-form/validations
     - После отправки — отображение статуса (успех/ошибка), очистка формы

---

## Интеграция и сценарии использования

- **На странице contact лендинга:**
  - Секция вставляется как основной блок.
  - Использует данные и actions из contact-form для отправки и обработки формы.
  - Может использовать секции/шаблоны из page для унификации стиля.

- **Возможные расширения:**
  - Поддержка мультиязычности (через meta/props)
  - Динамическая подгрузка контактных данных из page или config
  - Встраивание карты (например, через отдельную секцию map-section)
  - Визуализация статуса отправки (анимированная иконка, snackbar и т.д.)

## Рекомендации по развитию
- Вынести форму в отдельный шаблон (если потребуется переиспользование)
- Для интеграции с contact-form — использовать include или operation:include
- Для CRUD-интерфейса заявок — предусмотреть отдельные секции/страницы (admin-view)
- Для showcase — добавить вариант с кастомизацией темы, полей, вариантов dropdown
