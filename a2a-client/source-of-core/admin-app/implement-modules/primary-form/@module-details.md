# Детализация модуля primary-form

## Назначение
- Универсальный инструмент для генерации, хранения и применения серий промтов (prompt series) и сценариев.
- Позволяет динамически строить формы на основе входящих JSON-структур, выбирать параметры для итоговой структуры, управлять шагами сценария.
- Используется как самостоятельный модуль и как интеграционный компонент для других модулей (например, генерация форм, сценариев, быстрая настройка).

---

## Ключевые зоны и содержимое

### 1. Корень
- @scratchpad.md, @memories.md — заметки, временные и вспомогательные материалы.
- storage-code-structure.md — описание структуры кода и хранения.
- linked-library/ — место для внешних или общих библиотек (пока пусто).
- v1/, v2/ — две параллельные версии модуля, обе актуальны для анализа.

### 2. v1
- code/PrimaryForm.php — основная логика работы с формами, сценариями, обработкой JSON.
- data/program.json — базовые данные или схема для программ/сценариев.
- pages/page.json — описание UI-страницы для работы с формой/сценарием.
- programs/ — набор программных сценариев (StoryWriter, FilesWalker, Indexer и др.), а также подпапка story для расширения.
- templates/forms/program-control.json — шаблон управления программой/формой.
- templates/parts/program/ — части интерфейса для работы с окнами (создание, удаление).
- assets/ — зарезервировано для ассетов (пока пусто).

### 3. v2
- code/PrimaryForm.php — актуализированная логика, поддержка новых сценариев и форм.
- data/ — схемы, состояния, логи, секции, модели данных (windows, programs), заготовки.
- pages/page.json — UI-страница для работы с формой/сценарием.
- commands/ — команды для управления окнами, сброса шагов, работы с секциями.
- validations/ — схемы валидации для различных сценариев.
- actions/ — экшены для работы с секциями.
- templates/forms/ — шаблоны для форм (checkbox-section, program-control, result-section).
- templates/parts/program/ — части интерфейса: навигация, запросы, диалоги создания/удаления окон.
- assets/ — зарезервировано для ассетов (пока пусто).

---

## Функциональные зоны
- Генерация и хранение промтов/сценариев — управление сериями, быстрый доступ, навигация по шагам.
- Динамическая генерация форм — построение UI по входящему JSON, выбор параметров, отображение результата.
- Валидация и обработка — схемы валидации, экшены для обработки данных.
- Интеграция — возможность встраивания в другие модули, расширяемость через шаблоны и actions.
- UI-компоненты — страницы, шаблоны, части интерфейса для управления окнами, навигации, отображения статусов.

---

## Краткое резюме
Модуль primary-form — это мощный инструмент для работы с динамическими сценариями и формами, поддерживающий хранение, генерацию, валидацию и интеграцию. Структура разделена на две версии, каждая из которых содержит полный набор компонентов: код, данные, шаблоны, валидации, экшены и UI-описания.
