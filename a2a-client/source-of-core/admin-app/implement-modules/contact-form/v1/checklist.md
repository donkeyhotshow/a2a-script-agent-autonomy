# Чеклист и план развития: модуль contact-form (v1)

## 1. Назначение и структура

Модуль предназначен для обработки запросов с контактных форм, а также CRUD по сохранённым данным. Включает интеграцию с landing-main-page и page, шаблоны форм, actions для приёма и удаления заявок.

---

## 2. Существующие страницы, actions и шаблоны

- pages/: page.json (основная страница формы)
- actions/: receive-submission.json, delete-submission.json (приём и удаление заявок)
- templates/forms/: contact.json (шаблон формы)
- templates/dialogs/: contact-dialog.json (диалог подтверждения)
- data/: submissions.json (хранилище заявок)
- _i/: meta, links, filesByBlock (навигация, служебные данные)

---
