# Component Syntax Standards

## Actions Reference

### Доступные действия
1. `update` - обновление данных
   - Поддерживает batch операции
   - Имеет четкую структуру с `from` и `to`
   - Позволяет сохранять данные в разные места (buffer, output, file)
   - Соответствует общему паттерну работы с данными в системе
   - Используется для манипуляции данными (копирование, перемещение, трансформация)

2. `comment` - добавление комментария
   - Используется для документации
   - Не влияет на выполнение
   - Может содержать TODO и пояснения

3. `for` - цикл по массиву
   - `from` должен быть массивом
   - `to` определяет имя переменной для текущего элемента
   - Вложенные инструкции имеют доступ к:
     - `buffer:for.currentItem` - текущий элемент
     - `buffer:for.parentItem` - элемент родительского цикла

4. `print_r` - вывод данных
   - Используется для отладки
   - Выводит структуру данных
   - Не влияет на выполнение

5. `add` - добавление данных
   - Добавляет элемент в массив
   - Добавляет поле в объект
   - Требует указания `to`

6. `remove` - удаление данных
   - Удаляет элемент из массива
   - Удаляет поле из объекта
   - Требует указания `from`

7. `call` - вызов функции
   - Вызывает указанную функцию
   - Передает параметры
   - Получает результат

8. `return` - возврат значения
   - Прерывает выполнение
   - Возвращает указанное значение
   - Используется в функциях

9. `save` - сохранение данных модуля
   - Вызывает метод `save()` у связанного модуля (`$this->module->save()`)
   - Предназначено для сохранения состояния или данных, которыми управляет модуль (например, в базу данных)
   - Может иметь параметры `from` (источник данных для сохранения, если модуль этого требует) и `to` (куда сохранить результат операции модуля, если есть)
   - Внутренняя логика метода `save()` в `InstructionProcessor` определяет, вызывать ли `insert` или `update` у модуля на основе его параметров (например, наличия `id`)

### Когда использовать `save` vs `update`:
- Используйте `update` для манипуляций с данными в буфере, выходных данных или файлах.
- Используйте `save` для запуска логики сохранения данных внутри самого модуля (например, персистентность в БД).
