# Тесты преобразований разметки

## Тест 1: Документация
### Вход:
```markdown
# Документация API
## Методы
### GET /users
- Получение списка пользователей
- Поддержка пагинации
  - page: номер страницы
  - limit: размер страницы
```

## Критерии проверки

1. Сохранение структуры:
   - [ ] Иерархия заголовков
   - [ ] Вложенность списков
   - [ ] Отступы
   - [ ] Форматирование

2. Преобразование формата:
   - [ ] # -> 1.
   - [ ] ## -> 1.1.
   - [ ] ### -> 1.1.1.
   - [ ] - -> 1.

3. Контекстная зависимость:
   - [ ] Документация: сохранение
   - [ ] Инструкции: преобразование
   - [ ] Валидация: смешанное
   - [ ] Код: строгое сохранение
   - [ ] Комментарии: гибкое

4. Качество ответов:
   - [ ] Структурированность
   - [ ] Детальность
   - [ ] Читаемость
   - [ ] Консистентность

## Метрики оценки

1. Точность преобразований:
   - 100%: полное соответствие
   - 80%: незначительные отклонения
   - 60%: существенные отклонения
   - 40%: частичное соответствие
   - 20%: минимальное соответствие

2. Качество ответов:
   - 5: отличное
   - 4: хорошее
   - 3: удовлетворительное
   - 2: плохое
   - 1: неудовлетворительное

3. Контекстная адаптация:
   - 5: идеальная
   - 4: хорошая
   - 3: средняя
   - 2: слабая
   - 1: отсутствует
