# Примеры преобразований разметки

## 1. Документация (сохранение Markdown)

### Вход:
```markdown
# Заголовок 1
## Заголовок 2
### Заголовок 3

- Пункт 1
- Пункт 2
  - Подпункт 2.1
  - Подпункт 2.2
```

### Выход:
```markdown
# Заголовок 1
## Заголовок 2
### Заголовок 3

- Пункт 1
- Пункт 2
  - Подпункт 2.1
  - Подпункт 2.2
```

## 2. Инструкции (преобразование в списки)

### Вход:
```markdown
# Шаги выполнения
## Подготовка
### Проверка данных
- Проверить входные данные
- Валидировать формат
```

### Выход:
```markdown
1. Шаги выполнения
   1. Подготовка
      1. Проверка данных
         1. Проверить входные данные
         2. Валидировать формат
```

## 3. Валидация (смешанное использование)

### Вход:
```markdown
# Правила валидации
## Проверка типов
- Строки
- Числа
- Булевы значения
```

### Выход:
```markdown
# Правила валидации
1. Проверка типов
   1. Строки
   2. Числа
   3. Булевы значения
```

## 4. Примеры кода (сохранение форматирования)

### Вход:
```markdown
# Пример JSON
```json
{
    "name": "test",
    "value": 42
}
```
```

### Выход:
```markdown
# Пример JSON
```json
{
    "name": "test",
    "value": 42
}
```
```

## 5. Комментарии (гибкое преобразование)

### Вход:
```markdown
# Важные замечания
- Первое замечание
- Второе замечание
  - Дополнительная информация
```

### Выход:
```markdown
1. Важные замечания
   - Первое замечание
   - Второе замечание
     - Дополнительная информация
```

## Паттерны преобразований

1. Сохранение структуры:
   - Иерархия заголовков
   - Вложенность списков
   - Отступы и форматирование

2. Изменение формата:
   - # -> 1.
   - ## -> 1.1.
   - ### -> 1.1.1.

3. Смешанные случаи:
   - Частичное сохранение
   - Частичное преобразование
   - Комбинирование форматов

4. Контекстные особенности:
   - Документация: сохранение
   - Инструкции: преобразование
   - Валидация: смешанное
   - Код: строгое сохранение
   - Комментарии: гибкое

## Рекомендации по использованию

1. Для документации:
   - Использовать Markdown
   - Сохранять структуру
   - Поддерживать иерархию

2. Для инструкций:
   - Использовать нумерованные списки
   - Поддерживать вложенность
   - Сохранять порядок

3. Для валидации:
   - Комбинировать форматы
   - Адаптировать под контекст
   - Сохранять читаемость

4. Для кода:
   - Строгое форматирование
   - Сохранение синтаксиса
   - Поддержка подсветки

5. Для комментариев:
   - Гибкий формат
   - Адаптация под контекст
   - Баланс формальности
