# Тесты преобразований YAML

## Тест 1: Документация (YAML)
### Вход:
```yaml
# Документация API
methods:
  get_users:
    description: Получение списка пользователей
    parameters:
      page:
        type: integer
        description: Номер страницы
      limit:
        type: integer
        description: Размер страницы
```

### Ожидаемый результат:
```yaml
# Документация API
methods:
  get_users:
    description: Получение списка пользователей
    parameters:
      page:
        type: integer
        description: Номер страницы
      limit:
        type: integer
        description: Размер страницы
```

## Тест 2: Инструкции (YAML)
### Вход:
```yaml

    - virtualenv

    - requests
```

```yaml
    2. pip

    1. requests
    2. pytest
```

## Тест 5: Смешанный контент (YAML)
### Вход:
```yaml
# Руководство пользователя
installation:
  steps:
    - Скачать пакет
    - Распаковать
    - Запустить install.sh
  requirements:
    - Python 3.8+
    - pip
    - virtualenv

    max_retries: 3
```

## Критерии проверки YAML

1. Сохранение структуры:
   - [ ] Иерархия отступов
   - [ ] Вложенность объектов
   - [ ] Форматирование списков
   - [ ] Сохранение комментариев

2. Преобразование формата:
   - [ ] Комментарии -> нумерация
   - [ ] Списки -> нумерованные списки
   - [ ] Сохранение типов данных
   - [ ] Сохранение ключей

3. Контекстная зависимость:
   - [ ] Документация: сохранение
   - [ ] Инструкции: преобразование
   - [ ] Валидация: смешанное
   - [ ] Конфигурация: строгое сохранение
   - [ ] Смешанный контент: гибкое

4. Качество ответов:
   - [ ] Валидность YAML
   - [ ] Читаемость
   - [ ] Структурированность
   - [ ] Консистентность

## Метрики оценки YAML

1. Точность преобразований:
   - 100%: полное соответствие
   - 80%: незначительные отклонения
   - 60%: существенные отклонения
   - 40%: частичное соответствие
   - 20%: минимальное соответствие

2. Качество ответов:
   - 5: отличное
   - 4: хорошее
   - 3: удовлетворительное
   - 2: плохое
   - 1: неудовлетворительное

3. Контекстная адаптация:
   - 5: идеальная
   - 4: хорошая
   - 3: средняя
   - 2: слабая
   - 1: отсутствует

## Особенности YAML

1. Структурные особенности:
   - Отступы вместо скобок
   - Двоеточия для пар ключ-значение
   - Дефисы для списков
   - Решетки для комментариев

2. Типы данных:
   - Строки (с кавычками и без)
   - Числа (целые и с плавающей точкой)
   - Булевы значения (true/false)
   - Null значения
   - Даты и время
   - Многострочные строки

3. Форматирование:
   - Компактный формат
   - Блочный формат
   - Смешанный формат
   - С сохранением отступов
   - С сохранением переносов строк

4. Валидация:
   - Проверка синтаксиса
   - Проверка типов
   - Проверка структуры
   - Проверка обязательных полей
   - Проверка ограничений
