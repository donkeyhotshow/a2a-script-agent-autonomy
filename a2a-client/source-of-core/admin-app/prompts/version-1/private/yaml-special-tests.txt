# Тесты специальных случаев YAML

## Тест 1: Многострочные строки
### Вход:
```yaml
# Документация с многострочным текстом
description: |
  Это многострочное описание
  с сохранением переносов строк
  и отступов.

  Пустые строки тоже сохраняются.

  И даже отступы в начале строк:
    - Первый уровень
      - Второй уровень
```

### Ожидаемый результат:
```yaml
# Документация с многострочным текстом
description: |
  Это многострочное описание
  с сохранением переносов строк
  и отступов.

  Пустые строки тоже сохраняются.

  И даже отступы в начале строк:
    - Первый уровень
      - Второй уровень
```

## Тест 2: Специальные типы данных
### Вход:
```yaml
# Тест специальных типов
types:
  string: "Обычная строка"
  number: 42
  float: 3.14159
  boolean: true
  null: null
  date: 2024-03-20
  datetime: 2024-03-20T15:30:00Z
  binary: !!binary |
    SGVsbG8gV29ybGQ=
  complex:
    real: 1.0
    imag: 2.0
```

### Ожидаемый результат:
```yaml

## Тест 3: Якоря и ссылки
### Вход:
```yaml
# Тест якорей и ссылок
defaults: &defaults
  host: localhost
  port: 8080
  debug: false

development:
  <<: *defaults
  debug: true

production:
  <<: *defaults
  host: prod.example.com
```

### Ожидаемый результат:
```yaml
# Тест якорей и ссылок
defaults: &defaults
  host: localhost
  port: 8080
  debug: false

development:
  <<: *defaults
  debug: true

production:
  <<: *defaults
  host: prod.example.com
```

## Тест 4: Теги и типы
### Вход:
```yaml
# Тест тегов и типов
values:
  string: !!str "123"
  integer: !!int "123"
  float: !!float "123.45"
  boolean: !!bool "true"
  null: !!null "null"
  timestamp: !!timestamp "2024-03-20T15:30:00Z"
  binary: !!binary "SGVsbG8gV29ybGQ="
  map: !!map
    key: value
  set: !!set
    ? item1
    ? item2
```

### Ожидаемый результат:
```yaml

## Тест 5: Смешанный контент
### Вход:
```yaml
# Тест смешанного контента
documentation:
  title: "Руководство пользователя"
  content: |
    # Заголовок
    ## Подзаголовок
    
    - Пункт 1
    - Пункт 2
      - Подпункт 2.1
      - Подпункт 2.2
    
    ```python
    def hello():
        print("Hello, World!")
    ```
  
  metadata:
    author: &author
      name: "John Doe"
      email: "john@example.com"
    
    reviewers:
      - <<: *author
        role: "lead"
      - <<: *author
        role: "tester"
    
    tags: !!set
      ? documentation
      ? guide
      ? tutorial
```

### Ожидаемый результат:
```yaml
# Тест смешанного контента
documentation:

## Критерии проверки специальных случаев

1. Многострочные строки:
   - [ ] Сохранение переносов строк
   - [ ] Сохранение отступов
   - [ ] Сохранение пустых строк
   - [ ] Обработка специальных символов

2. Специальные типы:
   - [ ] Строки (с кавычками и без)
   - [ ] Числа (целые и с плавающей точкой)
   - [ ] Булевы значения
   - [ ] Null значения
   - [ ] Даты и время
   - [ ] Бинарные данные
   - [ ] Комплексные числа

3. Якоря и ссылки:
   - [ ] Определение якорей
   - [ ] Использование ссылок
   - [ ] Слияние объектов
   - [ ] Циклические ссылки

4. Теги и типы:
   - [ ] Явное указание типов
   - [ ] Преобразование типов
   - [ ] Специальные теги
   - [ ] Пользовательские типы

5. Смешанный контент:
   - [ ] Markdown в YAML
   - [ ] Код в YAML
   - [ ] Ссылки в контенте
   - [ ] Метаданные
