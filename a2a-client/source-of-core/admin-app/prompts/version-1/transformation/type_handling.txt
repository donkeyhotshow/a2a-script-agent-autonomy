# Type Handling Instructions

## Core Type System

1. Primitive Types:
   ```json
   {
       "string": "text",
       "number": 42,
       "boolean": true,
       "null": null
   }
   ```

2. Complex Types:
   ```json
   {
       "object": {
           "field": "value"
       },
       "array": [1, 2, 3],
       "mixed": {
           "items": [1, "text", true]
       }
   }
   ```
