# Structure Validation Instructions

## Core Structure Rules

1. Basic Structure:
   ```json
   {
       "type": "Instructions",
       "instructions": [
           {
               "action": "update",
               "batch": [
                   {
                       "value": <value>,
                       "to": "buffer:<field>"
                   }
               ]
           }
       ]
   }
   ```

2. Required Fields:
   - type: must be "Instructions"
   - instructions: must be array
   - action: must be "update"
   - batch: must be array
   - value: any valid value
   - to: must start with "buffer:"

## Structure Validation

1. Top-Level Validation:
   - Check type field
   - Verify instructions array
   - Validate structure
   - Test completeness

2. Instruction Validation:
   - Check action field
   - Verify batch array

   - Test completeness

3. Batch Validation:
