# PROMPT-V3: JSON Format Validation

## Цель
Проверьте следующий JSON на соответствие формату: структура, типы данных, вложенность, edge-cases (многострочные строки, пустые значения, неверные типы).

## Инструкция
1. Проанализируйте JSON ниже на предмет ошибок формата.
2. Укажите все найденные ошибки с пояснениями.
3. Проверьте edge-cases: многострочные строки, пустые значения, неверные типы.
4. Оцените полноту анализа (quality_score: 1-5) и дайте краткий feedback.

## Пример (JSON)
```json
{
  "id": 1,
  "name": "item",
  "description": "Многострочная\nстрока",
  "active": "yes"
}
```

## Ожидаемый формат ответа
```json
{
  "result": "invalid",
  "errors": [
    {"line": 5, "type": "type", "description": "Поле 'active' должно быть boolean, а не string"}
  ],
  "quality_score": 4,
  "feedback": "Обнаружена ошибка типа, многострочная строка обработана корректно."
}
```
