# PROMPT-V3: Standards Compliance

## Цель
Проверьте, соответствует ли следующий JSON/конфиг внутренним стандартам: именование, структура, типы данных, обязательные поля. Проверьте edge-cases (неверные имена, пропущенные поля, лишние параметры).

## Инструкция
1. Проанализируйте JSON ниже на соответствие стандартам (например, snake_case, обязательные поля, структура).
2. Укажите все найденные нарушения с пояснениями.
3. Проверьте edge-cases: неверные имена, пропущенные поля, лишние параметры.
4. Оцените полноту проверки (quality_score: 1-5) и дайте краткий feedback.

## Пример (JSON)
```json
{
  "UserId": 1,
  "user_name": "test",
  "isActive": true,
  "extra": "value"
}
```

## Ожидаемый формат ответа
```json
{
  "result": "invalid",
  "issues": [
    {"field": "UserId", "type": "naming", "description": "Имя поля должно быть в snake_case"},
    {"field": "isActive", "type": "naming", "description": "Имя поля должно быть в snake_case"},
    {"field": "extra", "type": "extra", "description": "Лишний параметр"}
  ],
  "quality_score": 3,
  "feedback": "Обнаружены нарушения стандартов именования и лишний параметр."
}
```
