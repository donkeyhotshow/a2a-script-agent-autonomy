# PROMPT-V3: Optimization Check

## Цель
Проверьте, оптимизирован ли следующий JSON/конфиг: нет ли дублирующихся, неиспользуемых или избыточных параметров. Проверьте edge-cases (пустые объекты, повторяющиеся ключи, вложенные параметры).

## Инструкция
1. Проанализируйте JSON ниже на предмет оптимизации структуры и параметров.
2. Укажите все найденные дубли, избыточные или неиспользуемые параметры.
3. Проверьте edge-cases: пустые объекты, повторяющиеся ключи, вложенные параметры.
4. Оцените качество оптимизации (quality_score: 1-5) и дайте краткий feedback.

## Пример (JSON)
```json
{
  "id": 1,
  "name": "item",
  "options": {
    "debug": true,
    "debug": false,
    "extra": null
  },
  "meta": {}
}
```

## Ожидаемый формат ответа
```json
{
  "result": "not_optimized",
  "issues": [
    {"field": "options.debug", "type": "duplicate", "description": "Повторяющийся ключ debug"},
    {"field": "options.extra", "type": "unused", "description": "Параметр не используется"},
    {"field": "meta", "type": "empty", "description": "Пустой объект meta"}
  ],
  "quality_score": 3,
  "feedback": "Обнаружены дубли и пустые объекты, требуется оптимизация."
}
```
