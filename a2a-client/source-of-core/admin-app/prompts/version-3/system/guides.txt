# PROMPT-V3: Guide Validation

## Цель
Проверьте, соответствует ли следующее руководство (guide) внутренним стандартам: структура, полнота, наличие обязательных разделов, edge-cases (пропущенные разделы, дубли, некорректные формулировки).

## Инструкция
1. Проанализируйте текст руководства ниже на соответствие стандартам (структура, обязательные разделы, логика).
2. Укажите все найденные нарушения: пропущенные разделы, дубли, некорректные формулировки.
3. Проверьте edge-cases: отсутствие обязательного раздела, повторяющийся раздел, неясная инструкция.
4. Оцените полноту и качество руководства (quality_score: 1-5) и дайте краткий feedback.

## Пример (guide)
```
# Руководство пользователя

## Введение
...

## Установка
...

## Использование
...

## Установка
...
```

## Ожидаемый формат ответа
```json
{
  "result": "invalid",
  "issues": [
    {"section": "Установка", "type": "duplicate", "description": "Раздел 'Установка' встречается дважды"},
    {"section": "Завершение", "type": "missing", "description": "Отсутствует обязательный раздел 'Завершение'"}
  ],
  "quality_score": 3,
  "feedback": "Обнаружены дубли и пропущенный раздел."
}
```
