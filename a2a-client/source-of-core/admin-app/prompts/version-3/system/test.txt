# PROMPT-V3: System Test

## Цель
Проверьте работу системы на следующем тестовом сценарии, включая edge-cases (неверные параметры, пустые значения, неожиданные типы).

## Инструкция
1. Выполните тестовый сценарий, используя входные данные ниже.
2. Проверьте корректность обработки всех параметров, включая edge-cases.
3. Укажите все найденные ошибки или некорректные обработки.
4. Оцените полноту теста (quality_score: 1-5) и дайте краткий feedback.

## Пример (входные данные)
```json
{
  "action": "create",
  "params": {
    "id": null,
    "name": "",
    "enabled": "yes"
  }
}
```

## Ожидаемый формат ответа
```json
{
  "result": "invalid",
  "errors": [
    {"field": "id", "type": "null", "description": "id не может быть null"},
    {"field": "name", "type": "empty", "description": "name не может быть пустым"},
    {"field": "enabled", "type": "type", "description": "enabled должен быть boolean"}
  ],
  "quality_score": 4,
  "feedback": "Покрыты edge-cases, найдены все ошибки."
}
```
