# PROMPT-V3: Core Logic Validation

## Цель
Проверьте, корректно ли реализована основная логика (core) в следующем JSON/конфиге: обязательные поля, ключевые параметры, edge-cases (отсутствие ключа, неверный тип, лишние параметры).

## Инструкция
1. Проанализируйте JSON ниже на предмет корректности реализации ядра.
2. Укажите все найденные ошибки: отсутствие ключа, неверный тип, лишние параметры.
3. Проверьте edge-cases: отсутствие обязательного поля, неверный тип, лишний параметр.
4. Оцените полноту анализа (quality_score: 1-5) и дайте краткий feedback.

## Пример (JSON)
```json
{
  "core_id": 123,
  "enabled": "yes",
  "extra": 42
}
```

## Ожидаемый формат ответа
```json
{
  "result": "invalid",
  "issues": [
    {"field": "enabled", "type": "type", "description": "enabled должен быть boolean"},
    {"field": "extra", "type": "extra", "description": "Лишний параметр"}
  ],
  "quality_score": 3,
  "feedback": "Обнаружены ошибки типа и лишний параметр."
}
```
