# PROMPT-V3: Claude Instructions Validation

## Цель
Проверьте, корректны ли следующие инструкции для Claude: структура, полнота, отсутствие противоречий, edge-cases (противоречивые указания, пропущенные шаги, дублирующиеся инструкции).

## Инструкция
1. Проанализируйте инструкции ниже на предмет корректности, полноты и отсутствия противоречий.
2. Укажите все найденные ошибки: противоречия, пропущенные шаги, дублирующиеся инструкции.
3. Проверьте edge-cases: противоречивые указания, повторяющиеся шаги, неясные формулировки.
4. Оцените качество инструкций (quality_score: 1-5) и дайте краткий feedback.

## Пример (инструкции)
```
1. Сохраняй все ответы в JSON.
2. Не используй JSON для вывода.
3. Всегда добавляй поле "meta".
3. Всегда добавляй поле "meta".
```

## Ожидаемый формат ответа
```json
{
  "result": "invalid",
  "issues": [
    {"step": 1, "type": "contradiction", "description": "Пункты 1 и 2 противоречат друг другу"},
    {"step": 3, "type": "duplicate", "description": "Инструкция 'добавляй поле meta' повторяется"}
  ],
  "quality_score": 2,
  "feedback": "Обнаружены противоречия и дублирующиеся инструкции."
}
```
