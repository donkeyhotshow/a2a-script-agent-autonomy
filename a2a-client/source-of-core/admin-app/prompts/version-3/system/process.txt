# PROMPT-V3: Process Validation

## Цель
Проверьте корректность следующего процесса (workflow) в формате JSON: порядок шагов, обязательные и необязательные этапы, edge-cases (пропущенные шаги, циклы, лишние этапы).

## Инструкция
1. Проанализируйте процесс ниже на предмет корректности и логики.
2. Укажите все найденные ошибки: пропущенные шаги, циклы, лишние этапы.
3. Проверьте edge-cases: необязательные шаги, повторяющиеся этапы, некорректные переходы.
4. Оцените полноту анализа (quality_score: 1-5) и дайте краткий feedback.

## Пример (JSON)
```json
{
  "steps": [
    {"name": "start"},
    {"name": "validate"},
    {"name": "process"},
    {"name": "end"},
    {"name": "validate"}
  ]
}
```

## Ожидаемый формат ответа
```json
{
  "result": "invalid",
  "issues": [
    {"step": "validate", "type": "duplicate", "description": "Шаг validate встречается дважды"}
  ],
  "quality_score": 4,
  "feedback": "Обнаружен повторяющийся шаг, требуется корректировка процесса."
}
```
