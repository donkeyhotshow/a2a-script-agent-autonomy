# PROMPT-V3: Simple Mutation

## Цель
Внесите простую мутацию в следующий JSON: измените одно из значений, не нарушая структуру. Проверьте edge-cases (изменение типа, пустые значения, вложенность).

## Инструкция
1. Измените одно значение в JSON ниже (например, число, строку, булево или null).
2. Не нарушайте структуру и типы данных.
3. Проверьте edge-cases: пустые строки, null, вложенные объекты.
4. Оцените корректность мутации (quality_score: 1-5) и дайте краткий feedback.

## Пример (JSON)
```json
{
  "user": "test",
  "active": true,
  "score": 10,
  "meta": {"info": "data"}
}
```

## Ожидаемый формат ответа
```json
{
  "user": "test",
  "active": false,
  "score": 10,
  "meta": {"info": "data"}
}
```

## Формат мета-отчёта
```json
{
  "quality_score": 5,
  "feedback": "Мутация выполнена корректно, структура и типы сохранены."
}
```
