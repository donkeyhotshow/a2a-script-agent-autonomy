# PROMPT-V3: Mutation Strategies

## Цель
Примените одну из стратегий мутации к следующему JSON: добавление, удаление или изменение значения. Проверьте edge-cases (удаление ключа, добавление вложенного объекта, изменение типа).

## Инструкция
1. Выберите стратегию: добавить новый ключ, удалить существующий или изменить значение.
2. Не нарушайте общую структуру и корректность JSON.
3. Проверьте edge-cases: удаление ключа, добавление вложенного объекта, изменение типа значения.
4. Оцените корректность мутации (quality_score: 1-5) и дайте краткий feedback.

## Пример (JSON)
```json
{
  "id": 1,
  "name": "item",
  "active": true
}
```

## Ожидаемый формат ответа (пример: добавление)
```json
{
  "id": 1,
  "name": "item",
  "active": true,
  "meta": {"created": "2024-06-01"}
}
```

## Формат мета-отчёта
```json
{
  "quality_score": 5,
  "feedback": "Добавлен вложенный объект, структура сохранена."
}
```
