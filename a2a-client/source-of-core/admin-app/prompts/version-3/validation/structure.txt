# PROMPT-V3: Structure Validation

## Цель
Проверьте следующий JSON на соответствие структуре и выявите любые ошибки, включая неочевидные и edge-case. Дайте подробный разбор даже если структура кажется валидной.

## Инструкция
1. Проанализируйте JSON ниже на предмет структурных ошибок, включая вложенность, типы данных, лишние/отсутствующие поля, неправильные кавычки, отступы, многострочные строки, якоря (если есть).
2. Если ошибок нет — объясните, почему структура валидна, и укажите, какие edge-cases были проверены.
3. Если ошибки есть — укажите их тип, строку (если возможно), и объясните, почему это ошибка.
4. Оцените глубину анализа (quality_score: 1-5) и дайте краткий feedback.

## Пример (валидный)
```json
{
  "name": "test",
  "config": {
    "enabled": true,
    "settings": {
      "timeout": 30,
      "retries": 3
    }
  },
  "dependencies": [
    {"id": "1", "version": "1.0"}
  ]
}
```

## Пример (невалидный, edge-case)
```json
{
  'name': "test",
  "config": {
    "enabled": true,
    "settings": {
      "timeout": 30,
      "retries": 3,
    }
  },
  "dependencies": [
    {"id": "1", "version": "1.0"},
  ]
}
```

## Ожидаемый формат ответа
```json
{
  "result": "valid" | "invalid",
  "errors": [
    {"line": 3, "type": "syntax", "description": "Одинарные кавычки недопустимы в JSON"},
    ...
  ],
  "edge_cases_checked": ["quotes", "trailing comma", "nesting", ...],
  "quality_score": 4,
  "feedback": "Обнаружены неочевидные ошибки, анализ был глубоким."
}
```
