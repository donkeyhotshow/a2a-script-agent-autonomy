# PROMPT-V3: Simple Validation

## Цель
Проверьте следующий JSON на валидность и объясните, почему он валиден или невалиден. Обратите внимание на неочевидные ошибки и edge-cases.

## Инструкция
1. Проверьте структуру, типы данных, вложенность, кавычки, запятые, отступы.
2. Если ошибок нет — объясните, почему структура валидна.
3. Если ошибки есть — опишите их подробно.
4. Оцените глубину анализа (quality_score: 1-5) и дайте краткий feedback.

## Пример (валидный)
```json
{
  "user": "test",
  "active": true,
  "roles": ["admin", "user"]
}
```

## Пример (невалидный, edge-case)
```json
{
  "user": "test",
  "active": true,
  "roles": ["admin", "user",]
}
```

## Ожидаемый формат ответа
```json
{
  "result": "valid" | "invalid",
  "errors": [
    {"line": 4, "type": "syntax", "description": "Лишняя запятая в массиве"},
    ...
  ],
  "quality_score": 5,
  "feedback": "Проверены edge-cases, анализ был тщательным."
}
```
