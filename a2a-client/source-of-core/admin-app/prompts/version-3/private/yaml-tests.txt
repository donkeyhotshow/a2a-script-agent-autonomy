# PROMPT-V3: YAML Handling

## Цель
Проверьте, как модель обрабатывает и преобразует YAML: сохранение структуры, типы данных, edge-cases (многострочные строки, якоря, ссылки, пустые значения, специальные типы).

## Инструкция
1. Проанализируйте YAML ниже: сохранена ли структура, корректно ли обработаны типы данных, якоря, ссылки.
2. Преобразуйте YAML в другой формат (например, в JSON), если требуется.
3. Проверьте edge-cases: многострочные строки, якоря, ссылки, пустые значения, специальные типы.
4. Оцените качество обработки YAML (quality_score: 1-5) и дайте краткий feedback.

## Пример (YAML)
```yaml
id: 1
description: |
  Многострочная
  строка
meta: &meta_anchor
  active: true
refs:
  - *meta_anchor
  - null
```

## Ожидаемый формат ответа (JSON)
```json
{
  "id": 1,
  "description": "Многострочная\nстрока",
  "meta": {"active": true},
  "refs": [ {"active": true}, null ]
}
```

## Формат мета-отчёта
```json
{
  "quality_score": 5,
  "feedback": "Якоря, многострочные строки и null обработаны корректно."
}
