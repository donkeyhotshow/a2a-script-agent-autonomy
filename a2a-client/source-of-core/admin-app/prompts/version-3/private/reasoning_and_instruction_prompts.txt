# PROMPT-V3: Reasoning and Instruction Following

## Цель
Проверьте, как модель выполняет сложные инструкции и рассуждает по многошаговой задаче, включая edge-cases (неоднозначные условия, противоречия, пропущенные шаги).

## Инструкция
1. Выполните многошаговую задачу по инструкции ниже.
2. Укажите все шаги, промежуточные результаты и финальный ответ.
3. Проверьте edge-cases: неоднозначные условия, противоречия, пропущенные шаги.
4. Оцените полноту reasoning (quality_score: 1-5) и дайте краткий feedback.

## Пример (инструкция)
```
1. Сложи все числа в списке [1, 2, 3, 4].
2. Если сумма больше 5, умножь результат на 2.
3. Выведи итоговое значение и список исходных чисел.
```

## Ожидаемый формат ответа
```json
{
  "steps": [
    {"step": 1, "action": "Сложение", "result": 10},
    {"step": 2, "action": "Умножение", "result": 20},
    {"step": 3, "action": "Вывод", "result": {"final": 20, "input": [1,2,3,4]}}
  ],
  "quality_score": 5,
  "feedback": "Все шаги выполнены, reasoning прозрачен."
}
```
