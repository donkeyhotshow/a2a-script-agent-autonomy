# PROMPT-V3: Code Generation and Analysis

## Цель
Проверьте, как модель генерирует и анализирует код по заданию, включая edge-cases (неполные требования, неоднозначные условия, синтаксические ошибки).

## Инструкция
1. Сгенерируйте код по заданию ниже.
2. Проанализируйте получившийся код: есть ли синтаксические ошибки, соответствует ли он требованиям.
3. Проверьте edge-cases: неполные требования, неоднозначные условия, синтаксические ошибки.
4. Оцените качество кода (quality_score: 1-5) и дайте краткий feedback.

## Пример (задание)
```
Напишите функцию на Python, которая принимает список чисел и возвращает их сумму. Если список пустой, верните 0.
```

## Ожидаемый формат ответа
```python
def sum_list(numbers):
    return sum(numbers) if numbers else 0
```

## Формат мета-отчёта
```json
{
  "syntax_errors": [],
  "requirements_met": true,
  "quality_score": 5,
  "feedback": "Код корректен, все требования выполнены."
}
```
