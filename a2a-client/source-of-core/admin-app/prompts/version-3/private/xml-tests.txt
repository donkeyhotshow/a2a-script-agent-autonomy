# PROMPT-V3: XML Handling

## Цель
Проверьте, как модель обрабатывает и преобразует XML: сохранение структуры, атрибутов, типов данных, edge-cases (пространства имён, многоуровневая вложенность, пустые элементы, специальные символы).

## Инструкция
1. Проанализируйте XML ниже: сохранена ли структура, корректно ли обработаны атрибуты, типы данных, пространства имён.
2. Преобразуйте XML в другой формат (например, в JSON), если требуется.
3. Проверьте edge-cases: пространства имён, многоуровневая вложенность, пустые элементы, специальные символы.
4. Оцените качество обработки XML (quality_score: 1-5) и дайте краткий feedback.

## Пример (XML)
```xml
<root xmlns:ex="http://example.com">
  <item id="1" ex:type="special">Value</item>
  <empty/>
  <nested>
    <child>Text</child>
  </nested>
</root>
```

## Ожидаемый формат ответа (JSON)
```json
{
  "root": {
    "item": {"@id": "1", "@ex:type": "special", "#text": "Value"},
    "empty": null,
    "nested": {"child": "Text"}
  }
}
```

## Формат мета-отчёта
```json
{
  "quality_score": 5,
  "feedback": "Атрибуты, пространства имён и пустые элементы обработаны корректно."
}
```
