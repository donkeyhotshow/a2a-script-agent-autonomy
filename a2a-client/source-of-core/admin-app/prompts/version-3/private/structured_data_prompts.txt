# PROMPT-V3: Structured Data Handling

## Цель
Проверьте, как модель анализирует и преобразует структурированные данные (JSON, YAML, XML), включая edge-cases (неверные типы, вложенность, многострочные строки, якоря, пустые значения).

## Инструкция
1. Проанализируйте данные ниже на предмет структурных ошибок и соответствия формату.
2. Преобразуйте данные в другой формат (например, JSON → YAML), если требуется.
3. Проверьте edge-cases: неверные типы, вложенность, многострочные строки, якоря, пустые значения.
4. Оцените качество анализа/преобразования (quality_score: 1-5) и дайте краткий feedback.

## Пример (JSON)
```json
{
  "id": 1,
  "description": "Многострочная\nстрока",
  "meta": null,
  "refs": ["a", "b"]
}
```

## Ожидаемый формат ответа (YAML)
```yaml
id: 1
description: |
  Многострочная
  строка
meta: null
refs:
  - a
  - b
```

## Формат мета-отчёта
```json
{
  "quality_score": 5,
  "feedback": "Многострочные строки и null обработаны корректно."
}
```
