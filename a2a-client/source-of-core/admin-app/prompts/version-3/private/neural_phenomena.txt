# PROMPT-V3: Neural Phenomena Checklist

## Цель
Проверьте, как модель реагирует на различные феномены работы с форматами данных: сонный JSON, скорость ответа, большие структуры, языковое переключение, структурная чувствительность, edge-cases (многострочные строки, якоря, смешанный контент).

## Инструкция
1. Проведите серию тестов по феноменам ниже (каждый феномен — отдельный кейс).
2. Для каждого кейса опишите реакцию модели, найденные ошибки, особенности поведения.
3. Проверьте edge-cases: большие структуры, смешанные языки, многострочные строки, якоря.
4. Оцените устойчивость и качество реакции (quality_score: 1-5) и дайте краткий feedback.

## Пример (феномен)
- Сонный JSON: модель быстро отвечает "всё ок" на валидный JSON, но требует явных ошибок для глубокого анализа.
- Языковое переключение: на английском — строже, на русском — гибче.

## Ожидаемый формат ответа
```json
[
  {
    "phenomenon": "Сонный JSON",
    "reaction": "Быстрый поверхностный ответ на валидный JSON, глубокий анализ только при явных ошибках.",
    "quality_score": 3,
    "feedback": "Требуется больше edge-cases для глубокого анализа."
  },
  {
    "phenomenon": "Языковое переключение",
    "reaction": "На английском — строже, на русском — гибче.",
    "quality_score": 4,
    "feedback": "Модель адаптируется к языку, но возможны нестабильные ответы."
  }
]
```
