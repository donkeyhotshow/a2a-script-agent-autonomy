# PROMPT-V3: Markdown Handling

## Цель
Проверьте, как модель обрабатывает и преобразует Markdown: сохранение структуры, преобразование в списки, edge-cases (многоуровневые списки, смешанная разметка, пустые разделы).

## Инструкция
1. Проанализируйте Markdown ниже: сохранена ли структура, корректно ли преобразованы списки и заголовки.
2. Преобразуйте Markdown в другой формат (например, в нумерованный список), если требуется.
3. Проверьте edge-cases: многоуровневые списки, смешанная разметка, пустые разделы.
4. Оцените качество обработки Markdown (quality_score: 1-5) и дайте краткий feedback.

## Пример (Markdown)
```
# Заголовок

- Пункт 1
  - Подпункт 1.1
- Пункт 2

## Пустой раздел

```

## Ожидаемый формат ответа (нумерованный список)
```
1. Пункт 1
   1. Подпункт 1.1
2. Пункт 2

Пустой раздел: (нет содержимого)
```

## Формат мета-отчёта
```json
{
  "quality_score": 5,
  "feedback": "Многоуровневые списки и пустые разделы обработаны корректно."
}
```
