# PROMPT-V3: Type Handling

## Цель
Преобразуйте следующий JSON в YAML, уделяя особое внимание сохранению типов данных (строки, числа, булевы, null, массивы, объекты). Проверьте edge-cases: null, пустые строки, числа с плавающей точкой, булевы значения.

## Инструкция
1. Преобразуйте JSON ниже в YAML.
2. Убедитесь, что все типы данных сохранены корректно.
3. Проверьте edge-cases: null, пустые строки, числа с плавающей точкой, булевы значения.
4. Оцените качество преобразования (quality_score: 1-5) и дайте краткий feedback.

## Пример (JSON)
```json
{
  "name": "Test",
  "value": null,
  "active": false,
  "score": 3.14,
  "tags": ["a", "b", ""],
  "meta": {}
}
```

## Ожидаемый формат ответа
```yaml
name: Test
value: null
active: false
score: 3.14
tags:
  - a
  - b
  - ""
meta: {}
```

## Формат мета-отчёта
```json
{
  "quality_score": 5,
  "feedback": "Все типы данных сохранены корректно, edge-cases обработаны."
}
```
