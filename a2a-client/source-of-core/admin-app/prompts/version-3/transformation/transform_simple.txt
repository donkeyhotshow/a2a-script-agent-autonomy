# PROMPT-V3: Simple Transformation

## Цель
Преобразуйте следующий JSON в YAML, сохраняя структуру, типы данных и все значения. Проверьте edge-cases (многострочные строки, вложенность, пустые значения).

## Инструкция
1. Преобразуйте JSON ниже в YAML.
2. Убедитесь, что все данные, структура и типы сохранены.
3. Проверьте edge-cases: пустые массивы, многострочные строки, вложенные объекты.
4. Оцените качество преобразования (quality_score: 1-5) и дайте краткий feedback.

## Пример (JSON)
```json
{
  "title": "Example",
  "description": "Многострочная\nстрока",
  "items": [],
  "config": {
    "enabled": true
  }
}
```

## Ожидаемый формат ответа
```yaml
title: Example
description: |
  Многострочная
  строка
items: []
config:
  enabled: true
```

## Формат мета-отчёта
```json
{
  "quality_score": 5,
  "feedback": "Многострочные строки и пустые массивы преобразованы корректно."
}
```
