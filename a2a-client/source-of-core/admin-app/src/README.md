## 🚀 Frontend - Admin App (`src/`)

### Описание:
Данная директория содержит исходный код клиентской части приложения `Admin App`, построенного с использованием React/Next.js и Tailwind CSS. Здесь реализованы пользовательские интерфейсы, взаимодействие с API и основные компоненты приложения.

### Структура Директории:
- `Providers/`: Контекстные провайдеры для глобального состояния или функциональности.
- `Helpers/`: Вспомогательные функции и утилиты, используемые в компонентах.
- `Facades/`: Фасады для упрощения взаимодействия с внешними API или сервисами.
- `icon.png`: Иконка приложения.

### Ключевые Технологии:
- **React:** Основная библиотека для построения пользовательских интерфейсов.
- **Next.js:** Фреймворк для React, обеспечивающий серверный рендеринг (SSR), маршрутизацию и оптимизацию.
- **Tailwind CSS:** Утилитарный CSS-фреймворк для быстрого и гибкого стилизования.
- **Shadcn/UI & Radix UI:** Библиотека компонентов UI, построенная на Radix UI.
- **Zustand:** Легковесная библиотека для управления состоянием приложения.

### Запуск и Разработка:
Для запуска фронтенд-части, используйте основные скрипты проекта, определенные в `package.json` корневого проекта (например, `npm run dev`).
