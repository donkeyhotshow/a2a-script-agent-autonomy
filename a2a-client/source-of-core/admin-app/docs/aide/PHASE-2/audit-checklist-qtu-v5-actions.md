# Audit Checklist: question-to-user/v5 - Actions Directory

**Date:** 2024-07-26
**Module:** `question-to-user/v5`
**Focus:** `actions/` directory - Ensure action files conform to `Instructions.json` schema and other validation rules.
**Phase:** 2 - Action Audit & Fix

**Overall Strategy for Actions:**
1.  Refer to `schemas/Instructions.json` for the correct structure of instruction sets.
2.  Ensure `operation` and `instructions` children are correctly placed according to the schema (e.g., `instructions` is an array of action objects, not nested `instructions` or `operation` objects directly).
3.  Validate keys like `default` and `input` against the `Instructions.json` schema to ensure they are in allowed locations (e.g., `input` is typically part of an action call, not a top-level key in `root.instructions`).
