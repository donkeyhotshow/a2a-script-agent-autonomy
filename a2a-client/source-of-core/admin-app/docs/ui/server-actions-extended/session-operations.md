# Документация операций с сессией в JSON UI

## Обзор

Модуль Session в JSON UI предоставляет интерфейс для взаимодействия с сессией Laravel. Это позволяет читать, записывать
и удалять данные, хранящиеся в сессии пользователя, используя унифицированный синтаксис адресов.

Основной класс, отвечающий за эти операции, расположен в `app/AiRudeDepot/StorageDataModules/Session.php`. Как и другие
модули хранения, он редко используется напрямую, а доступ к нему осуществляется через классы `DataHub` и `Data`,
используя адреса с префиксом `session:`.

## Особенности модуля Session

- Доступ к данным сессии Laravel через стандартные адреса `DataHub`.
- Поддержка чтения, записи и удаления данных.
- Работа с вложенными данными в сессии с использованием точечной нотации.
- Автоматическое сохранение сессии после операций записи/удаления.
- Использует стандартный драйвер сессии, настроенный в Laravel (например, `file`, `database`, `redis`, `array` для
  тестов).

## Формат адресов модуля Session

Адреса для модуля Session используют префикс `session:` за которым следует ключ сессии. Для доступа к вложенным данным
используется **точечная нотация**.

```
session:ключ.вложенный_ключ.еще_глубже
```

где:

- `ключ.вложенный_ключ...` - ключ или путь к данным внутри сессии.

### Примеры адресов

* `session:userId`: Доступ к значению с ключом `userId`.
* `session:user.profile.theme`: Доступ к ключу `theme` внутри вложенного массива `profile` в ключе `user`.
* `session:cart.items.0.productId`: Доступ к `productId` первого элемента в массиве `items` внутри `cart`.

## Примеры использования в инструкциях `actions`

### Запись данных в сессию

```json
[
  {
    "action": "update",
    "to": "session:user.id", // Указываем ключ сессии
    "value": 123 // Значение для записи
  },
  {
    "action": "update",
    "to": "session:user.preferences.theme",
    "value": "dark"
  }
]
```

### Чтение данных из сессии

```json
[
  {
    "action": "update",
    "from": "session:user.id", // Указываем ключ для чтения
    "to": "buffer:currentUserId" // Куда поместить результат
  },
  {
    "action": "update",
    "from": "session:user.preferences", // Чтение вложенного массива
    "to": "buffer:userPrefs"
  }
]
```

### Удаление данных из сессии

Используется `action: "remove"`.

```json
[
  {
    "action": "remove", 
    "to": "session:temporaryData" // Ключ для удаления
  },
  {
    "action": "remove",
    "to": "session:user.profile.tempSetting" // Удаление вложенного ключа
  }
]
```

## Важные моменты

* **Авто-сохранение:** Модуль `Session.php` обычно вызывает `session()->save()` после операций `set` или `remove`,
  поэтому изменения сразу фиксируются в хранилище сессии.
* **Драйвер сессии:** Поведение может незначительно отличаться в зависимости от используемого драйвера сессии (`file`,
  `database`, `array` и т.д.).
* **Безопасность:** Не храните чрезмерно большие объемы данных или критически важную информацию непосредственно в
  сессии, особенно если используется файловый драйвер.

## Взаимосвязь с Laravel Session

Модуль Session является оберткой над фасадом `Illuminate\Support\Facades\Session` (или соответствующим экземпляром
`Illuminate\Session\Store`).

| Операция (через `Session.php`) | Примерный вызов Laravel Session (`session()->...`) |
|--------------------------------|----------------------------------------------------|
| `get('key.path')`              | `session()->get('key.path')`                       |
| `set('key.path', $value)`      | `session()->put('key.path', $value)`               |
| `remove('key.path')`           | `session()->forget('key.path')`                    |
