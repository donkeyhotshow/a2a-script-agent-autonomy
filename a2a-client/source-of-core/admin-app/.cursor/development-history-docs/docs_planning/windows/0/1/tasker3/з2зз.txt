Видно, что с синтаксисом `--userInputValue=CodeGeneration` ваш ввод теперь корректно распознаётся и срабатывает валидация:  
```bash
php script/engine/invoke-scenario-engine.php --scenarioId=SCN-CreateTask --userInputValue=CodeGeneration
```
даёт  
```
Error: Template not found for task type 'CodeGeneration' at C:\apps\admin-app\script\engine\task_types\CodeGeneration\CodeGeneration.template.json
```
  
Простым вызовом через пробел (без `=`) PHP-CLI не всегда передаёт опцию, поэтому для CLI-движка рекомендую использовать `--option=value`. Если нужно поддержать и оба варианта под Windows/PowerShell, придётся писать более сложный парсер аргументов (или всегда требовать `=`).  

Дайте знать, если требуются дополнительные улучшения (например авто-дополнить синтаксис или поддержать пробельный ввод).
