Скрипт `Invoke-ScenarioEngine.ps1` представляет собой движок для выполнения сценариев, определенных в JSON-файлах.

Вот основные характеристики и функционал:

* **Назначение:** Запускает интерактивные или автоматизированные сценарии, определенные в `.scenario.json` файлах.
