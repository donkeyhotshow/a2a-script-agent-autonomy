• эмулировать ответы, добавив в `script/engine/QandA/answers.json` запись с текущим `generatedQuestionId` и `answerValue`;

Ниже демонстрация “живого” теста первого шага сценария — выбора типа задачи и обработки ответа PHP-скриптом:

1) Очистка маркеров и старого тестового файла:
```
pwsh -Command "Remove-Item 'engine/markers/SCN-CreateTask*' -Force -ErrorAction SilentlyContinue; Remove-Item 'script/engine/task_definitions/TestTask001.json' -Force -ErrorAction SilentlyContinue"
```

2) Запуск сценария с полным сбросом прогресса:
```
pwsh -File script/engine/invoke-scenario-engine.php -ScenarioId SCN-CreateTask -ResetProgress:$true
```
Вывод:
…  
`currentStepId: "WAIT_FOR_TASK_TYPE_ANSWER"`  
`context.generatedQuestionId: "QID-DYNAMIC-ad3895b0"`

3) Добавляем тестовый ответ (`Generic`) в `answers.json` для полученного `generatedQuestionId`:
```
pwsh -Command '$answers = Get-Content script/engine/QandA/answers.json | ConvertFrom-Json; 
$answers.answers += @{ 
    answerId="ans-test-type"; 
    questionId="QID-DYNAMIC-ad3895b0"; 
    answerValue="Generic"; 
    status="new"; 
    receivedTimestamp=(Get-Date).ToString("o") 
}; 
$answers | ConvertTo-Json -Depth 10 | Set-Content script/engine/QandA/answers.json'
```

4) Проверяем, что запись добавилась:
```
pwsh -Command "(Get-Content script/engine/QandA/answers.json | ConvertFrom-Json).answers | Select-Object -Last 1 | ConvertTo-Json -Depth 5"
```
Результат:
```json
{
  "status": "new",
  "answerValue": "Generic",
  "receivedTimestamp": "2025-05-11T07:43:53.4298976+03:00",
  "questionId": "QID-DYNAMIC-ad3895b0",
  "answerId": "ans-test-type"
}
```

5) Запускаем сценарий заново — теперь PHP-скрипт подхватывает ответ и возвращает данные движку:
```
pwsh -File script/engine/invoke-scenario-engine.php -ScenarioId SCN-CreateTask
```
Ключевая часть вывода:
```
"finalOutput": {
  "needsUserInput": false,
  "aiTaskType": "Generic",
  "retrievedAnswerId": "ans-test-type",
  "pendingQuestionId": "QID-DYNAMIC-ad3895b0"
},
"currentStepId": "WAIT_FOR_TASK_TYPE_ANSWER"
```

Видно, что:
- PHP-скрипт успешно прочитал `answers.json` и слил в контекст ключ `aiTaskType: "Generic"`.
- Движок получил `retrievedAnswerId` и подтвердил, что ввода больше не требуется.
