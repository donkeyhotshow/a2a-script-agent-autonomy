Создайте PHP-версию алгоритма семантического поиска в кодовой базе, используя библиотеку PHP-ML. 

Требования к реализации:

1. Основной класс CodeIndexer:
   - Использовать PHP-ML для TF-IDF векторизации
   - Реализовать косинусную схожесть
   - Поддержка индексации PHP файлов
   - Сохранение/загрузка индексов

2. Функциональность:
   - Извлечение ключевых слов из кода (функции, классы, комментарии)
   - Поиск по ключевым словам
   - Семантический поиск с использованием TF-IDF
   - Комбинированный поиск
   - Фильтрация результатов

3. Технические детали:
   - Использовать PHP-ML для:
     * TF-IDF векторизации (Phpml\FeatureExtraction\TfIdfTransformer)
     * Косинусной схожести (Phpml\Math\Statistic\Mean, Phpml\Math\Statistic\StandardDeviation)
   - Анализ PHP кода через:
     * PHP Parser для AST
     * Регулярные выражения для комментариев
   - Сохранение индексов в JSON

4. Пример использования:
```php
$indexer = new CodeIndexer();
$indexer->indexDirectory('./codebase');

// Поиск
$results = $indexer->search("обработка данных");
```

5. Дополнительные требования:
   - Поддержка русского и английского языков
   - Игнорирование коротких слов
   - Кэширование результатов
   - Логирование процесса индексации

6. Тестирование:
   - Создать тестовые PHP файлы
   - Проверить точность поиска
   - Измерить производительность

7. Документация:
   - Описание API
   - Примеры использования
   - Требования к системе

Используйте следующий стек технологий:
- PHP 8.0+
- PHP-ML
- PHP Parser
- Composer для управления зависимостями

Начните с создания базовой структуры проекта и постепенно добавляйте функциональность, начиная с индексации файлов и заканчивая продвинутым поиском.
