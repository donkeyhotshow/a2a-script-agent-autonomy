в этой папке хранятся md файлы которые описывают конкретные файлы исходников используемые в проекте.

файловая структура документов копирует файловое положения файла исходника , например, для файла
app/Console/Commands/Config/FtpConfig.php ложен быть создан файл docs-mirrors/app/Console/Commands/Config/FtpConfig.md

список папок учасников системы зеркальной документации.
