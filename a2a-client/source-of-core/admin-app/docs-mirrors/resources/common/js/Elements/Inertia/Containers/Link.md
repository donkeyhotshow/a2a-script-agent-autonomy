# Компонент Link для лендинг-страниц

> **Примечание:** Документация актуальна для v2. Компонент `Link` используется для навигации в v1 и v2.

## Обзор

Компонент `Link` предназначен для создания навигационных ссылок в лендинг-страницах. Он основан на компоненте из
`resources/common/js/Elements/Inertia/Containers/Link.vue` и обеспечивает единообразное поведение ссылок во всем
приложении.

## Свойства (Props)

| Свойство          | Тип           | По умолчанию | Описание                                                           |
|:------------------|:--------------|:-------------|:-------------------------------------------------------------------|
| `href`            | String        | `null`       | URL для перехода                                                   |
| `target`          | String        | `'_self'`    | HTML-атрибут target (_self, _blank, _parent, _top)                 |
| `preserve-scroll` | Boolean       | `false`      | Сохранять позицию скролла после перехода                           |
| `preserve-state`  | Boolean       | `false`      | Сохранять состояние компонента после перехода                      |
| `replace`         | Boolean       | `false`      | Заменять текущую запись в истории браузера вместо добавления новой |
| `only`            | Array         | `[]`         | Массив свойств, которые нужно обновить без перезагрузки страницы   |
| `class`           | String/Object | `''`         | CSS классы для ссылки                                              |
| `active-class`    | String        | `'active'`   | CSS класс для активной ссылки                                      |
| `disabled`        | Boolean       | `false`      | Отключение ссылки                                                  |
| `data`            | Object        | `{}`         | Дополнительные данные для передачи                                 |

## Использование в JSON-структуре

```json
{
  "type": "Link",
  "props": {
    "href": "#services",
    "class": "nav-link",
    "activeClass": "active"
  },
  "content": "Наши услуги"
}
```

## Преимущества использования Link

1. **Семантическая корректность** - использование HTML-элемента `<a>` для навигации
2. **Доступность** - корректное восприятие экранными читалками
3. **SEO-оптимизация** - поисковые системы лучше индексируют обычные ссылки
4. **Единообразие** - консистентное поведение всех ссылок в приложении
5. **Расширенные возможности** - предварительная загрузка, кэширование и другие оптимизации

## Примеры использования

### Внутренняя навигация

```json
{
  "type": "Link",
  "props": {
    "href": "#contact-us",
    "class": "nav-link"
  },
  "content": "Связаться с нами"
}
```

### Внешняя ссылка

```json
{
  "type": "Link",
  "props": {
    "href": "https://example.com",
    "target": "_blank",
    "class": "external-link"
  },
  "children": [
    {
      "type": "Span",
      "content": "Перейти на сайт"
    },
    {
      "type": "i",
      "props": {
        "class": "pi pi-external-link ml-2"
      }
    }
  ]
}
```

### Стилизация как кнопка

```json
{
  "type": "Link",
  "props": {
    "href": "/services",
    "class": "p-button p-component p-button-primary"
  },
  "content": "Узнать больше об услугах"
}
```

## Интеграция с действиями

Компонент `Link` можно комбинировать с другими действиями через `customHooks`:

```json
{
  "type": "Link",
  "props": {
    "href": "#services",
    "class": "nav-link"
  },
  "customHooks": {
    "click": [
      {
        "action": "toggleClass",
        "data": {
          "class": "highlight",
          "selector": "#services"
        }
      }
    ]
  },
  "content": "Наши услуги"
}
```

## Рекомендации по использованию

1. **Всегда используйте `Link` вместо обычных HTML-ссылок** для обеспечения единообразного поведения
3. **Указывайте атрибут `target="_blank"` для внешних ссылок** и добавляйте иконки для обозначения внешних ссылок
4. **Используйте правильные CSS-классы** для стилизации в соответствии с дизайном
5. **Обеспечивайте доступность** с помощью атрибутов aria-* при необходимости
