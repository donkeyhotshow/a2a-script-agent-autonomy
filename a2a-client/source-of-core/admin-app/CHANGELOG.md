### Описание:
Данный документ отслеживает все значимые изменения, внесенные в проект `Admin App`, включая новые функции, исправления ошибок, улучшения производительности и рефакторинг. Цель — предоставить пользователям и разработчикам актуальную информацию о развитии приложения.

### Формат записей:
Каждая запись в журнале изменений должна включать:
- **Дата:** Дата внесения изменения (YYYY-MM-DD).
- **Версия:** Номер версии приложения (если применимо).
- **Категория:** Тип изменения (например, `Добавлено`, `Исправлено`, `Изменено`, `Удалено`, `Безопасность`, `Производительность`).
- **Описание:** Краткое и понятное описание изменения.
- **Ссылки:** Ссылки на соответствующие задачи, Pull Request или атомарные действия (опционально).
