# ADR-001: Архитектура A2A Script Agent (Client)

## Дата
2026-02-25

## Авторы
- Команда разработки

## Статус
Принято

## Контекст

A2A Script Agent Client — это клиентская часть системы Agent-to-Agent для интеллектуального анализа кодовой базы. Клиент взаимодействует с сервером через A2A протокол и выполняет команды, полученные от сервера.

### a2a-client компоненты

- **Runtime:** Node.js 20+ / Browser
- **Language:** TypeScript
- **Framework:** Vite, Vue.js (Web UI)
- **Packages:** `agent`, `api-client`, `fs-utils`, `rag`, `script-runner`
- **Testing:** Vitest (unit), Playwright (E2E)

## Ключевые архитектурные решения

### 1. Stateless Server Design
Сервер **не хранит данные клиента**. Graph передаётся в контексте и возвращается в ответе:
- Server получает контекст и **может модифицировать** его
- Client хранит индексы (RAG, file search, free-form search)
- Client отправляет контекст обратно серверу **без изменений** (только добавляет новые данные: `step_result`, `code_blocks`)

### 2. PhaseMachine
State machine на стороне сервера управляет потоком запросов:
```
idle → discovery → recognition → analysis → action → validation → completed
```

### 3. Client Responsibilities
- **Хранение индексов:** RAG, file search, free-form search
- **История:** Хранение истории взаимодействий
- **Выполнение команд:** Выполнение команд из ответов сервера
- **Контекст:** Отправка контекста без изменений

## API Клиент

### Подключение к серверу

```typescript
import { A2AClient } from '@a2a-client/api-client';

const client = new A2AClient({
  baseUrl: 'http://localhost:3000',
  auth: {
    token: 'jwt-token',
  },
});

// Отправка задачи
const result = await client.sendTask({
  task: { /* ... */ },
  context: { /* ... */ },
});
```

### Методы API

| Метод | Описание |
|-------|----------|
| `sendTask()` | Отправить задачу на сервер |
| `getTaskStatus()` | Получить статус задачи |
| `getTaskResult()` | Получить результат задачи |
| `cancelTask()` | Отменить задачу |
| `subscribe()` | Подписаться на обновления (WebSocket) |
