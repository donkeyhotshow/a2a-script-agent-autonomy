# ADR-002: Протокол коммуникации A2A (Client)

## Дата
2026-02-25

## Авторы
- Команда разработки

## Статус
Принято

## Контекст

Клиент A2A Script Agent использует JSON-RPC 2.0 протокол для коммуникации с сервером. Протокол определяет формат запросов, ответов и механизм взаимодействия.

### Требования к протоколу

- **Версия JSON-RPC:** 2.0
- **Транспорт:** HTTP и WebSocket
- **Кодировка:** UTF-8
- **Типы запросов:** JSON object (не массивы)

## Решение

### Формат запроса (Request)

```typescript
interface JSONRPCRequest {
  jsonrpc: "2.0";           // Версия протокола
  id: string;               // Уникальный идентификатор запроса
  method: string;           // Имя метода
  params?: object;          // Параметры метода (опционально)
}
```

### Формат ответа (Response)

```typescript
interface JSONRPCResponse {
  jsonrpc: "2.0";           // Версия протокола
  id: string;              // Идентификатор запроса
  result?: object;         // Результат (при успехе)
  error?: JSONRPCError;    // Ошибка (при неудаче)
}

interface JSONRPCError {
  code: number;             // Код ошибки
  message: string;         // Сообщение об ошибке
  data?: object;           // Дополнительные данные
}
```

### Коды ошибок JSON-RPC

| Код | Название | Описание |
|-----|----------|----------|
| -32700 | Parse error | Неверный JSON |
| -32600 | Invalid Request | Неверный формат запроса |
| -32601 | Method not found | Метод не найден |
| -32602 | Invalid params | Неверные параметры |
| -32603 | Internal error | Внутренняя ошибка сервера |
| -32000 | Server error | Ошибка на стороне сервера |
| -32001 | Unauthorized | Не авторизован |
| -32002 | Timeout | Таймаут выполнения |

## Реализация на клиенте

### HTTP Клиент

```typescript
import { JSONRPCClient } from '@a2a-client/api-client';

const client = new JSONRPCClient({
  baseUrl: 'http://localhost:3000',
  headers: {
    'Authorization': 'Bearer token',
  },
});

// Отправка запроса
const response = await client.request('tasks/send', {
  task: { /* ... */ },
  context: { /* ... */ },
});
```

### WebSocket Клиент

```typescript
import { WebSocketClient } from '@a2a-client/api-client';

const ws = new WebSocketClient({
  url: 'ws://localhost:3001',
  auth: { token: 'jwt-token' },
});

// Подписка на обновления
ws.subscribe('promise_123', (result) => {
  console.log('Result:', result);
});

// Отправка запроса
const response = await ws.request('tasks/send', {
  task: { /* ... */ },
  context: { /* ... */ },
});
```

### Генерация ID

```typescript
function generateRequestId(): string {
  const timestamp = Date.now().toString(36);
  const random = Math.random().toString(36).substring(2, 15);
  return `req_${timestamp}_${random}`;
}
```

### Message Flow

```
Client                                          Server
  |                                               |
  |  POST /api/v1/requests                       |
  |  {                                           |
  |    "jsonrpc": "2.0",                         |
  |    "id": "req_xxxxx",                        |
  |    "method": "tasks/send",                  |
  |    "params": {                               |
  |      "task": { ... },                        |
  |      "context": { ... }                     |
  |    }                                         |
  |  }                                           |
  |-------------------------------------------->|
  |                                               |
  |  Response: 202 Accepted                      |
  |  {                                           |
  |    "jsonrpc": "2.0",                         |
  |    "id": "req_xxxxx",                        |
  |    "result": {                               |
  |      "promiseId": "promise_xxxxx",          |
  |      "status": "pending"                     |
  |    }                                         |
  |  }                                           |
  |<--------------------------------------------|
  |                                               |
  |  Polling: GET /api/v1/requests/:promiseId/status |
  |-------------------------------------------->|
  |                                               |
  |  { status: "processing" }                   |
  |<--------------------------------------------|
  |                                               |
  |  ... polling ...                             |
  |                                               |
  |  GET /api/v1/requests/:promiseId/result      |
  |-------------------------------------------->|
  |                                               |
  |  { status: "completed", data: { ... } }      |
  |<--------------------------------------------|
```

## Методы API

| Метод | Описание | Параметры |
|-------|----------|-----------|
| `tasks/send` | Отправить задачу | task, context |
| `tasks/get` | Получить задачу | promiseId |
| `tasks/cancel` | Отменить задачу | promiseId |
| `tasks/subscribe` | Подписаться на обновления | promiseId |
| `session/create` | Создать сессию | sessionData |
| `session/update` | Обновить сессию | sessionId, updates |

## Обработка ошибок

```typescript
try {
  const result = await client.request('tasks/send', params);
} catch (error) {
  if (error.code === -32001) {
    // Unauthorized - перенаправление на логин
  } else if (error.code === -32002) {
    // Timeout - повторная попытка
  } else if (error.code === -32601) {
    // Method not found - логирование
  }
}
```

## Ограничения

- Максимальный размер payload: 10MB
- Таймаут ожидания результата: 300 секунд (настраивается)
- Rate limiting: 100 запросов в минуту
