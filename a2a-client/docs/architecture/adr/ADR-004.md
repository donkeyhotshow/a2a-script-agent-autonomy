# ADR-004: Аутентификация и авторизация (Client)

## Дата
2026-02-25

## Авторы
- Команда разработки

## Статус
Принято

## Контекст

Клиент A2A Script Agent взаимодействует с сервером, который выполняет аутентификацию и авторизацию. Клиент хранит и управляет токенами, передавая их в каждом запросе.

### Требования к безопасности

- **JWT токены:** Используются для аутентификации
- **Refresh токен:** Для продления сессии
- **Хранение:** Безопасное хранение токенов на клиенте

## Решение

### Типы токенов

#### Access Token

```typescript
interface JWTPayload {
  sub: string;           // User ID
  email: string;         // User email
  role: UserRole;        // User role
  iat: number;           // Issued at
  exp: number;           // Expiration
  iss: string;           // Issuer
}

interface AccessToken {
  token: string;         // JWT token
  expiresIn: number;     // Seconds until expiration
}
```

#### Refresh Token

```typescript
interface RefreshToken {
  token: string;
  userId: string;
  expiresIn: number;
}
```

## Клиентская реализация

### AuthClient

```typescript
import { AuthClient } from '@a2a-client/api-client';

const authClient = new AuthClient({
  baseUrl: 'http://localhost:3000',
});

// Вход
const tokens = await authClient.login('user@example.com', 'password');
// tokens: { accessToken, refreshToken, expiresIn }

// Обновление токена
const newTokens = await authClient.refresh(tokens.refreshToken);

// Выход
await authClient.logout(tokens.refreshToken);
```

### Интеграция с A2AClient

```typescript
import { A2AClient } from '@a2a-client/api-client';

const client = new A2AClient({
  baseUrl: 'http://localhost:3000',
  auth: {
    // Автоматическое добавление токена
    getToken: async () => {
      const tokens = await authClient.getTokens();
      return tokens.accessToken;
    },
    // Автоматическое обновление
    onUnauthorized: async () => {
      const newTokens = await authClient.refresh(currentRefreshToken);
      return newTokens.accessToken;
    },
  },
});
```

### Token Storage

```typescript
// Безопасное хранение токенов
class TokenStorage {
  static async saveTokens(tokens: { accessToken: string; refreshToken: string }): Promise<void> {
    // В браузере: httpOnly cookie (сервер устанавливает)
    // Или encrypted storage
    await SecureStore.setItemAsync('refreshToken', tokens.refreshToken);
    // Access token НЕ сохраняем - получаем при каждом входе
  }

  static async getRefreshToken(): Promise<string | null> {
    return SecureStore.getItemAsync('refreshToken');
  }

  static async clearTokens(): Promise<void> {
    await SecureStore.deleteItemAsync('refreshToken');
  }
}
```

### Перехватчик для fetch

```typescript
import { FetchInterceptor } from '@a2a-client/api-client';

const interceptor = new FetchInterceptor();

interceptor.addHandler(async (request) => {
  // Добавление токена
  const tokens = await TokenStorage.getTokens();
  if (tokens?.accessToken) {
    request.headers.set('Authorization', `Bearer ${tokens.accessToken}`);
  }
  return request;
});

interceptor.addErrorHandler(async (error) => {
  if (error.status === 401) {
    // Попытка обновить токен
    const newTokens = await authClient.refresh(refreshToken);
    await TokenStorage.saveTokens(newTokens);
    
    // Повтор запроса
    return fetch(request);
  }
  throw error;
});
```

### Auth Flow на клиенте

```
1. Пользователь вводит credentials
   POST /api/v1/auth/token
   { email, password }
   
   Response: { accessToken, refreshToken, expiresIn }

2. Сохранение refresh token
   SecureStorage.setItem('refreshToken', refreshToken)

3. Использование access token
   Authorization: Bearer <accessToken>

4. При 401 - обновление токена
   POST /api/v1/auth/refresh
   { refreshToken }
   
   Response: { accessToken, refreshToken, expiresIn }

5. При выходе
   POST /api/v1/auth/logout
   { refreshToken }
   
   SecureStorage.deleteItem('refreshToken')
```

## Обработка ошибок

```typescript
try {
  const result = await client.sendTask(taskData);
} catch (error) {
  if (error.code === -32001) {
    // Unauthorized - требуется логин
    navigateTo('/login');
  } else if (error.code === -32003) {
    // Forbidden - недостаточно прав
    showError('Доступ запрещён');
  }
}
```

## Ограничения

- Max failed login attempts: 5
- Lockout duration: 15 минут
- Token expiration: 24 часа (access), 7 дней (refresh)
