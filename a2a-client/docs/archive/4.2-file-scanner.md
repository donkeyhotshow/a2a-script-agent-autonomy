# План: 4.2 File Scanner

> **Относится к:** a2a-client

## Текущее состояние

### Существующий компонент

- **Пакет** `a2a-client/packages/fs-utils/src/file-scanner.js`
- **Класс** `FileScanner` - утилита для сканирования директорий с поддержкой include/exclude паттернов

### Функциональность

- Рекурсивное сканирование директорий
- Include паттерны (какие файлы включать)
- Exclude паттерны (какие файлы/директории исключать)
- Ограничение глубины сканирования (maxDepth)
- Лимит файлов (maxFiles)
- Callback для прогресса (onProgress)
- Статистика: totalFiles, totalDirs, skippedDirs, skippedFiles, errors

### Зависимости

- `glob-matcher.js` - для сопоставления паттернов
- `ignore-detector.js` - для игнорирования файлов (.gitignore и т.д.)
