# План: 4.4 Questions Handler

> **Относится к:** a2a-server (questions generated in request-processor)

## Текущее состояние

### Существующая функциональность
- **Генерация вопросов**: `request-processor.service.ts` → `generateQuestions()`
- **Хранение вопросов**: `context-manager.service.ts` → ключ `'questions'`
- **Типы вопросов**:
  - Controller: "Which controller handles this functionality?"
  - Model: "Which model represents the data?"
  - Request: "Is there a FormRequest for validation?"
  - Vue/Component: "Which Vue component should be modified?"
  - No entities: "Please provide the relevant code files"
  - Relationships: "Are there relationships between models?"

### Где используется
- Фаза `validation` в PhaseMachine
- Graph completeness проверка
- Контекстный блок в A2A сообщениях

## Критерии приёмки

1. Генерация вопросов покрывает все основные типы сущностей
2. Вопросы не дублируются (deduplication работает)
3. Контекстные вопросы учитывают предоставленные файлы
4. Все существующие тесты проходят
5. Обратная совместимость с текущим API
