# MCP Terminal Server

## ✅ СТАТУС: ПРОДАКШЕН ГОТОВ

**Версия: 2.0.0** | **Node.js: ≥18.0.0** | **Статус: PRODUCTION READY**

MCP сервер для безопасного выполнения команд терминала с модульной архитектурой, системой безопасности и автоматическими подсказками.

## 🚀 Быстрый старт

### Точки входа

Проект имеет две основные точки входа и связанную конфигурацию для Cursor:

1. **`mcp-server.cjs`** — основная точка входа MCP сервера
   - Прямой запуск MCP сервера без обёртки
   - Используется для разработки и тестирования
   - Запуск: `node mcp-server.cjs`

2. **`server-wrapper-simple.cjs`** — обёртка для продакшена (рекомендуется)
   - Отказоустойчивая обёртка с автоматическим перезапуском
   - Используется в конфигурации Cursor IDE (`.cursor/mcp.json`)
   - Запуск: `node server-wrapper-simple.cjs`
   - Расположена в корне проекта рядом с `mcp-server.cjs`

3. **Конфигурация Cursor IDE**
   - Файл конфигурации MCP: `C:\apps\root\mcp\node-terminal\.cursor\mcp.json`
     - **Важно:** если проект расположен в другом каталоге, **обязательно** обновите абсолютный путь в этом файле под вашу реальную директорию.
   - Обязательное правило MCP Terminal: `C:\apps\root\mcp\node-terminal\.cursor\rules\mcp-terminal-mandatory.mdc`
     - Рекомендуется убедиться, что путь актуален и файл реально существует в вашей копии репозитория.

**Рекомендация:** Для продакшена используйте wrapper, для разработки - прямой запуск `mcp-server.cjs`.

### Установка

```bash
npm install
```

### Запуск сервера

```bash
npm run server        # Запуск MCP сервера
npm run server:dev    # Запуск в dev режиме

# Фоновый запуск с логированием
npm run server:bg                 # Запуск в фоне (server.log)
npm run server:bg:timestamp       # Запуск в фоне (server_YYYYMMDD_HHMMSS.log)
npm run server:stop               # Остановка фонового сервера
npm run server:tail               # Мониторинг логов в реальном времени
```

### Установка рабочей директории

**Используйте модульную архитектуру для установки рабочей директории:**

```bash
# CLI команда
node cli.js terminal workspace set --path C:/apps/root/mcp/node-terminal

# Или через MCP JSON-RPC
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "terminal",
    "arguments": {
      "action": "workspace",
      "subAction": "set",
      "command": "C:/apps/root/mcp/node-terminal"
    }
  }
}
```

## 📋 Основные возможности

### 🚀 Терминал и команды

- Выполнение команд в терминале с таймаутами и фоновым режимом
- Модульная архитектура терминального инструмента — структурированные действия (`action: "workspace"`, `action: "mode"`, `action: "history"` и др.)
- Управление рабочими директориями и сессиями
- История команд с полным аудитом (через внутреннюю систему истории, без отдельного MCP‑инструмента `history`)

### 🛡️ Безопасность

- Анализ безопасности команд перед выполнением
- Валидация входных данных и путей
- Ограничения на опасные операции
- Полное логирование всех действий

### 💡 Система навязчивых хинтов

- **Автоматические подсказки** - анализ отсутствующих параметров
- **Детекция зацикливания** - предотвращение бесконечных циклов команд
- **Контекстные хинты** - специфичные предложения для каждого инструмента
- **Типы хинтов**: 🔴 "Напоминаю", 🟡 "Ты не забыл?", 🟢 "А ты знал?"

Подробнее: [Система навязчивых хинтов](./docs/HINT_SYSTEM.md)

### 🔍 Система обратной связи

- Фильтрация по вложенным ключам (снижение объема данных на 60-80%)
- Поддержка любых вложенных структур
- Эффективная работа с файлами до 100MB

Подробнее: [Фильтрация по вложенным ключам](./docs/NESTED_KEY_FILTERING.md)

## 🔧 Использование

### Инструмент Terminal

Упрощенный инструмент `terminal` принимает прямые команды:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "terminal",
    "arguments": {
      "command": "ваша команда здесь",
      "timeout": 120,
      "is_background": false,
      "cwd": "/path/to/workdir"
    }
  }
}
```

### Примеры использования

**Простая команда:**
```bash
echo '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"terminal","arguments":{"command":"echo Hello World"}}}' | npm run server
```

**Команда с таймаутом:**
```bash
echo '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"terminal","arguments":{"command":"sleep 5","timeout":10}}}' | npm run server
```

**Фоновая команда:**
```bash
echo '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"terminal","arguments":{"command":"npm install","is_background":true}}}' | npm run server
```

## 🎯 Исправленная версия сервера

Для решения проблем с зависанием команд активируйте исправленную версию через конфигурацию `.cursor/mcp.json`:

```json
{
  "terminal": {
    "debug": {
      "useFixedVersion": true
    }
  }
}
```

**Что исправляет:**
- ✅ Предотвращает смешивание отладочных сообщений с JSON ответами
- ✅ Блокирует утечку `[DEBUG]`, `Stats {` в stdout
- ✅ Обеспечивает чистые JSON-RPC ответы
- ✅ Решает проблемы с "зависанием" команд
