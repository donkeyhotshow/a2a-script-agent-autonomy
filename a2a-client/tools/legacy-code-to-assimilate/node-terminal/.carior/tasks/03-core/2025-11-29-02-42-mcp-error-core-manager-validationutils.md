## Контекст
Логи MCP terminal wrapper'а (`logs/wrapper-simple.log` и `logs/wrapper-simple-errors.log`) показывают множество повторяющихся ошибок при вызовах инструмента `terminal` и выполнении команд (`npm run dev`, `Get-Location`, `Get-Date` и др.).  
Ошибки не останавливают сервер (есть сообщения `Server continuing after unhandled rejection`), но приводят к постоянным `Unhandled Rejection` и созданию отчётов вида `C:\apps\system-run\work\mcp-server-rejection-*.json`, что снижает предсказуемость и устойчивость системы.

Ключевые фрагменты логов:
- [ ] `TypeError: this.errorCoreManager.registerError is not a function`  
      Например: в `logs/wrapper-simple.log` строка вида  
      `...[WRAPPER-ERROR] Server stderr: [MCP-SERVER-ERROR] Unhandled Rejection at: [object Promise], reason: TypeError: this.errorCoreManager.registerError is not a function`
- [ ] `ReferenceError: validationUtils is not defined`  
      Например: в `logs/wrapper-simple.log` и `logs/wrapper-simple-errors.log` строки вида  
      `[MCP-SERVER-ERROR] Unhandled Rejection at: [object Promise], reason: ReferenceError: validationUtils is not defined`

Эти ошибки указывают на:
- Некорректную инициализацию или передачу зависимостей `errorCoreManager` (объект не содержит метода `registerError` или передан не тот экземпляр).
- Использование `validationUtils` без корректного импорта/инициализации (глобальная ссылка или отсутствующий модуль).
