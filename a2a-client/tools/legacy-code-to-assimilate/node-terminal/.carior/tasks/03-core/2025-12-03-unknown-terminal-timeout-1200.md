## Контекст
Текущая реализация MCP Terminal Server ограничивает таймаут терминальных команд значением 600 секунд, что недостаточно для некоторых долгих операций (например, тяжелых сборок, миграций или интеграционных тестов), запускаемых через инструмент `terminal`. При этом ядро сервера (`mcp/server/Validation.cjs` и требования core) уже поддерживает максимальный таймаут до 3600 секунд, а в описании инструментов в `mcp-server.cjs` указано "до 10 мин", что соответствует 600 секундам. Необходимо увеличить верхний порог таймаута до 1200 секунд и устранить рассинхронизацию между валидацией и описаниями.
