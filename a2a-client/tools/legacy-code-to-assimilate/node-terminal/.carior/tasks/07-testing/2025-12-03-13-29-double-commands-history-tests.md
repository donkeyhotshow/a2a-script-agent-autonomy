## Улучшенная формулировка
Обновить и расширить тесты MCP Terminal для проверки корректной обработки двойных команд (с несколькими выражениями, например `cd ...; node ...` и `cd ... && node ...`) и их записи в глобальную историю `data/global-history/commands.jsonl`.

## Контекст
История глобальных команд хранится в файле `data/global-history/commands.jsonl`. В истории уже есть записи с двойными командами, например:
- `cd c:/apps/root/mcp/node-terminal; node test-global-history.cjs`
- `cd c:/apps/root/mcp/node-terminal && node test-global-history.cjs`

Нужно убедиться, что:
- такие команды корректно исполняются через MCP Terminal;
- корректно пишутся в историю;
- тесты явно покрывают эти случаи, чтобы избежать регрессий.

## Технические ограничения
- Использовать только MCP Terminal (`mcp_node-terminal_terminal`) для всех команд.
- Не изменять структуру `commands.jsonl` без отдельного ADR.
- Соблюдать существующие требования из `docs/requirements/terminal/requirements-terminal.md` для истории команд.

## Ожидаемый результат

- уверенно воспроизводит и проверяет выполнение двойных команд через MCP Terminal;

- легко запускается через существующие npm-скрипты.
