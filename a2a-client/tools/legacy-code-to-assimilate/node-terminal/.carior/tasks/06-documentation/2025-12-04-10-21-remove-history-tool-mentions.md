# Удаление упоминаний удалённого инструмента `@history` в MCP Terminal

## Дата создания
2025-12-04 10:21:00

## Исходный запрос пользователя
@history  - удаленный функционал - удалить упоминание

## Улучшенная формулировка
Проверить репозиторий MCP Node Terminal на наличие упоминаний удалённого MCP‑инструмента `@history` и удалить/уточнить такие упоминания в коде и документации, чтобы не вводить в заблуждение относительно доступных инструментов.

## Контекст
В текущей архитектуре MCP Terminal история команд обрабатывается:
- через внутренний модуль истории `@libs/system/history/index.cjs`;
- через структурированное действие `action: "history"` внутри терминального инструмента (`TerminalHandler.handleStructuredTerminalAction`).

Отдельного MCP‑инструмента `@history` (как самостоятельного tool) больше нет, поэтому любые его упоминания должны быть убраны или переформулированы.

## Ожидаемый результат
В репозитории нет упоминаний удалённого инструмента `@history`; документация и README описывают только актуальные способы работы с историей (через терминальный инструмент и его структурированные действия).

## Решение
- Поиск по репозиторию:
  - Глобальный поиск по строке `@history` не дал ни одного совпадения.
  - В `.cursor/rules/*` упоминаний `@history` нет.
  - В `README.md` слово `history` фигурирует только как часть описания модульной архитектуры (`workspace, mode, history`) и не оформлено как отдельный MCP‑инструмент.
- Кодовая база:
  - В `handlers/terminal-handler.cjs` история обрабатывается через `action: "history"` внутри структурированного действия `terminal`, отдельного `history`‑tool нет.
  - В `mcp/server/*` инициализация и список инструментов не содержат отдельного `history`‑инструмента.

Вывод: фактических упоминаний удалённого MCP‑инструмента `@history` в репозитории больше нет, изменения в файлах не требуются.
