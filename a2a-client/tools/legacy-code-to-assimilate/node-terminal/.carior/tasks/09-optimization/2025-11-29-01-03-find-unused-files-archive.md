## Контекст
Проект node-terminal содержит множество файлов, некоторые из которых могут быть устаревшими или неиспользуемыми. Необходимо провести аудит и очистить проект от неиспользуемых файлов.

## Требования
- [ ] Создать скрипт для анализа неиспользуемых файлов
- [ ] Выполнить анализ всех файлов проекта
- [ ] Исключить из анализа: node_modules, dist, coverage, .git, logs, tmp
- [ ] Проверить импорты через require() и import
- [ ] Проверить использование в package.json скриптах
- [ ] Создать архив и перенести неиспользуемые файлы
- [ ] Создать отчет о результатах

## Технические ограничения
- Не удалять файлы, которые могут быть точками входа
- Сохранять структуру директорий при архивации
- Не трогать конфигурационные файлы (package.json, tsconfig.json и т.д.)
- Не трогать документацию (docs/, README.md)

## Ожидаемый результат
- Скрипт для анализа неиспользуемых файлов
- Архив неиспользуемых файлов в `archive/unused-files/`
- Отчет о найденных и перенесенных файлах

## Решение
Создать Node.js скрипт, который:
1. Сканирует все файлы проекта
2. Анализирует импорты и зависимости
3. Определяет неиспользуемые файлы
4. Переносит их в архив с сохранением структуры
