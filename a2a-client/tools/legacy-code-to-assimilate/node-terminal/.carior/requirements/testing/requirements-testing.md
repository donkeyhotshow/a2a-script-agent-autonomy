**Требования:**
- [x] Тесты для всех основных модулей
- [x] Моки для внешних зависимостей
- [x] Тесты изоляции модулей

- [x] Покрытие кода ≥80% для критических зон

**Скрипты:**
- `npm run test:unit` - запуск unit тестов

- `npm run test:coverage` - покрытие кода
