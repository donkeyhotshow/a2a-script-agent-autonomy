# Требования безопасности

## Дата создания
2025-11-29 15:07:09

## Контекст
Система безопасности MCP Terminal Server обеспечивает защиту от опасных команд, валидацию входных данных и полное логирование всех операций.

## Фаза проекта
08-security

## Требования

### Анализ безопасности команд

#### ✅ Существующие файлы (РЕАЛИЗОВАНО)

- ✅ `@libs/system/security-mask/index.cjs` - модуль анализа безопасности (analyzeCommand)
- ✅ `docs/SECURITY_COMPLETE_GUIDE.md` - полное руководство по безопасности
- ✅ Система самопроверки безопасности

#### ❌ Будущие файлы (ОТСУТСТВУЕТ / планируется)

- ❌ Расширенная система правил безопасности

### Функциональность

#### Анализ команд

**Требования:**
- [x] Анализ команд перед выполнением (analyzeCommand)
- [x] Блокировка опасных команд (format, rm -rf, и т.д.)
- [x] Проверка паттернов опасных операций
- [x] Детекция попыток обхода безопасности
- [x] Логирование заблокированных команд

**Примеры блокируемых команд:**
- `format X:` - форматирование диска
- `rm -rf /` - удаление корневой директории
- Команды с опасными флагами

#### Валидация входных данных

**Требования:**
- [x] Валидация путей (validateAndResolveCwd)
- [x] Проверка параметров выполнения (validateExecRunParams)
- [x] Валидация файловых операций (validateFsParams)
- [x] Проверка категорий путей (validatePathWithCategories)
- [x] Защита от path traversal атак

**Валидация:**
- Проверка выхода за пределы рабочей директории
- Блокировка системных директорий
- Валидация относительных и абсолютных путей

#### Система самопроверки безопасности

**Требования:**
- [x] Быстрая проверка (quickCriticalTest) - ~1ms
- [x] Полная проверка (selfTest) - 16 тестовых случаев
- [x] Безопасное тестирование без реального выполнения
- [x] Тестирование на несуществующих дисках/путях

**Типы проверок:**
- Критические паттерны (format, rm -rf)
- Безопасные команды (echo, pwd)
- Запрещенные команды
- Граничные случаи (пустые команды, пробелы)

#### Логирование безопасности

**Требования:**
- [x] Логирование всех заблокированных команд
- [x] Запись причин блокировки
- [x] Метрики безопасности (recordSecurityMetric)
- [x] Аудит всех операций

**Логи:**
- `logs/mcp-server.log` - основные логи
- Метрики безопасности в analytics engine

#### Защита рабочей директории

**Требования:**
- [x] Обязательная установка рабочей директории проекта
- [x] Блокировка команд без установленной workspace
- [x] Исключение для эмулированных команд
- [x] Валидация workspace перед выполнением команд

**Правила:**
- Команды выполняются только в контексте проекта
- Защита от выполнения команд вне проекта
- Изоляция между проектами
