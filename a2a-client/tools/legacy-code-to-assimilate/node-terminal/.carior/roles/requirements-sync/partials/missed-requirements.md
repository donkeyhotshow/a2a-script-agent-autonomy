# Партиал: Невыполненные требования

**Границы ответственности:** Только статус реализации требований

## 📌 Ответственность этого партиала

Этот партиал содержит **только список невыполненных требований** - статус реализации, прогресс, критические проблемы.

### Что находится в этом партиале:
- ✅ Список всех невыполненных требований
- ✅ Статус реализации каждого компонента (✅ РЕАЛИЗОВАНО / ❌ ОТСУТСТВУЕТ)
- ✅ Прогресс реализации (процент выполненных требований)
- ✅ Критические недоработки
- ✅ Приоритеты исправления
- ✅ Статистика недоработок

### Что НЕ находится в этом партиале:
- ❌ Описание требований (находятся в соответствующих файлах требований)
- ❌ Детальные спецификации компонентов (находятся в соответствующих файлах)
- ❌ Требования к тестам (находятся в `docs\requirements\project-requirements-tests.md`)

## 🔗 Связанные файлы

- `docs\requirements\project-requirements-admin.md` - источник требований админки
- `docs\requirements\project-requirements-catalog.md` - источник требований каталога
- `docs\requirements\project-requirements-core-and-layout.md` - источник общих требований
- `docs\requirements\project-requirements-landing.md` - источник требований лендинга
- `docs\requirements\project-requirements-tests.md` - источник требований к тестам

## 📋 Правила синхронизации

### При добавлении нового компонента в файлах требований:
1. Автоматически добавить в этот файл как невыполненное (❌ ОТСУТСТВУЕТ)
2. Указать источник требования (из какого файла)
3. Указать приоритет (P0/P1/P2/P3)
4. Обновить статистику

### При реализации компонента:
1. Найти компонент в этом файле
2. Отметить как выполненное (✅ РЕАЛИЗОВАНО)
3. Обновить статистику
4. Удалить из списка невыполненных (или переместить в раздел "Реализовано")

### При обнаружении проблемы:
1. Добавить в раздел "Критические недоработки"
2. Указать причину проблемы
3. Указать решение
4. Обновить статистику

## 🔄 Правила обновления

1. **При добавлении нового невыполненного требования:**
   - Добавить в соответствующий раздел
   - Указать источник требования
   - Указать приоритет
   - Обновить статистику

2. **При реализации компонента:**
   - Найти в соответствующем разделе
   - Отметить как ✅ РЕАЛИЗОВАНО
   - Обновить статистику
   - Удалить из списка невыполненных

3. **При обнаружении проблемы:**
   - Добавить в раздел "Критические недоработки"
   - Указать причину и решение
   - Обновить статистику

4. **КРИТИЧНО:** Никогда не использовать "опционально" - компонент либо есть (✅), либо его нет (❌)
