# Работа с CWD (Current Working Directory) - Полное руководство

## Обзор

В MCP Terminal реализованы значительные улучшения работы с текущей рабочей директорией (CWD), включая правильную работу pwd в перехватчике, виртуальную CWD с поддержкой сессий, улучшенные подсказки и автоматическую установку CWD по умолчанию.

## Архитектура

### Уровни директорий

1. **Сессионная директория** - устанавливается командами `cd`, `pushd`, `popd`
2. **Рабочая директория проекта** - устанавливается через `workspace set`
3. **Системная директория** - директория процесса Node.js (fallback)

### Приоритет определения текущей директории

```
Сессионная CWD > Рабочая директория проекта > Системная CWD
```

## Улучшения

### 1. Правильная работа pwd в перехватчике

Перехватчик команд теперь корректно обрабатывает команду `pwd` и возвращает актуальную сессионную директорию.

### 2. Виртуальная CWD с поддержкой сессий

Каждая сессия имеет свою виртуальную CWD, которая сохраняется между командами.

### 3. Улучшенные подсказки с текущим CWD

Подсказки теперь показывают текущую рабочую директорию:

```
[C:\project\src] > 
```

### 4. Автоматическая установка CWD по умолчанию

Система автоматически устанавливает CWD при старте, если она не была установлена явно.

### 5. Показ подсказок о настройке CWD в конфиге

При отсутствии настроенной CWD система показывает подсказки о необходимости настройки.

## Миграция конфигурации

### ❌ СТАРАЯ СТРУКТУРА (УБРАНА)

```json
{
  "mcpServers": {
    "terminal": {
      "command": "node",
      "args": ["C:\\apps\\root\\mcp\\node-terminal\\mcp-server.cjs"],
      "cwd": "C:\\apps\\root\\mcp\\node-terminal\\"  // ❌ УБРАНО
    }
  }
}
```

### ✅ НОВАЯ СТРУКТУРА (АКТИВНА)

```json
{
  "mcpServers": {
    "terminal": {
      "command": "node",
      "args": ["C:\\apps\\root\\mcp\\node-terminal\\mcp-server.cjs"],
      "env": {
        "TERMINAL_CWD": "C:\\path\\to\\project"
      }
    },
    "terminal": {
      "command": "node",
      "args": ["C:\\apps\\root\\mcp\\node-terminal\\mcp-server.cjs"],
      "terminal": {
        "cwd": {
          "defaultCwd": "C:\\path\\to\\project"
        }
      }
    }
  }
}
```

## Тестирование

### Unit тесты

**Файл:** `tests/unit/cwd.test.cjs`

Покрывают базовую функциональность CWD:
- Установка и получение CWD
- Приоритет директорий
- Сессионная CWD
- Рабочая директория проекта

**Запуск:**

```bash
npm run test:cwd:unit
```

### Интеграционные тесты

**Файл:** `tests/integration/cwd-integration.test.cjs`

Проверяют работу CWD в реальных сценариях:
- Интеграция с MCP сервером
- Работа с командами cd, pwd
- Сессионная изоляция

**Запуск:**

```bash
npm run test:cwd:integration
```

## Использование

### Установка рабочей директории

```bash
# Через MCP
terminal {"action": "workspace", "set": "C:\\path\\to\\project"}

# Через CLI
node cli.js terminal workspace set "C:\\path\\to\\project"
```

### Получение текущей директории

```bash
# Через MCP
terminal {"action": "workspace", "get": true}

# Через CLI
node cli.js terminal workspace get
```

### Навигация

```bash
# Смена директории
terminal {"action": "exec", "command": "cd C:\\path\\to\\dir"}

# Просмотр текущей директории
terminal {"action": "exec", "command": "pwd"}
```
