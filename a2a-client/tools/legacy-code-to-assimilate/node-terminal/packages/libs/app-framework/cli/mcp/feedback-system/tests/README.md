# Feedback System Tests

Комплексная система тестирования для модуля обратной связи проектов.

## Структура тестов

### Unit Tests (`tests/unit/`)
Тесты отдельных компонентов и методов:

- **`feedback-plugin.test.ts`** - Тесты основного плагина FeedbackPlugin
- **`feedback-tools.test.ts`** - Тесты инструментов FeedbackTools
- **`suggestion-manager.test.ts`** - Тесты менеджера предложений SuggestionManager
- **`suggestion-datastore.test.ts`** - Тесты хранилища данных SuggestionDataStore
- **`suggestion-filter-utils.test.ts`** - Тесты утилит фильтрации SuggestionFilterUtils
- **`feedback-analytics.test.ts`** - Тесты аналитики FeedbackAnalytics
- **`index.test.ts`** - Тесты экспортов модуля

### Integration Tests (`tests/integration/`)
Тесты взаимодействия между компонентами:

- **`feedback-system-integration.test.ts`** - Полные сценарии использования системы

### Performance Tests (`tests/performance/`)
Тесты производительности и масштабируемости:

- **`feedback-system-performance.test.ts`** - Тесты производительности с большими объемами данных

### Edge Cases Tests (`tests/edge-cases/`)
Тесты граничных условий и обработки ошибок:

- **`feedback-system-edge-cases.test.ts`** - Тесты крайних случаев и обработки ошибок

## Запуск тестов

### Все тесты
```bash
npm test
```

### Отдельные категории тестов
```bash
# Unit тесты
npm test -- --selectProjects unit

# Integration тесты
npm test -- --selectProjects integration

# Performance тесты
npm test -- --selectProjects performance

# Edge cases тесты
npm test -- --selectProjects edge-cases
```

### С покрытием кода
```bash
npm test -- --coverage
```

### Отдельные файлы
```bash
npm test -- tests/unit/feedback-plugin.test.ts
npm test -- tests/integration/feedback-system-integration.test.ts
```

## Конфигурация

### Jest Configuration (`jest.config.js`)
- **Preset**: ts-jest для TypeScript поддержки
- **Test Environment**: node
- **Coverage**: Минимум 80% покрытия по всем метрикам
- **Timeout**: 30 секунд для обычных тестов, 60 секунд для performance тестов
- **Projects**: Организация тестов по категориям

### Test Setup (`tests/setup.ts`)
- Глобальные утилиты для тестов
- Кастомные Jest matchers
- Настройка окружения

## Моки и заглушки

### DebugSystem Mock (`tests/unit/mocks/DebugSystem.cjs.mock.js`)
Заглушка для системы отладки с категориями ошибок.

### File System Mocks
Моки для файловых операций:
- `fs.mkdirSync`
- `fs.writeFileSync`
- `fs.readFileSync`
- `fs.existsSync`

### Path Mocks
Моки для работы с путями:
- `path.resolve`
- `path.join`

## Кастомные Jest Matchers

### `toBeValidSuggestion()`
Проверяет, что объект является валидным предложением со всеми необходимыми полями.

### `toBeValidSuggestionResponse()`
Проверяет, что объект является валидным ответом API с правильной структурой.

## Утилиты для тестов

### `global.testUtils`
- `generateTestSuggestion(overrides)` - Генерация тестового предложения
- `generateTestSuggestions(count, overrides)` - Генерация множества предложений
- `waitFor(ms)` - Ожидание асинхронных операций
- `mockFileSystem(operations)` - Мокирование файловой системы

## Принципы тестирования

### Когнитивная дисциплина
Тесты следуют принципам когнитивной дисциплины:
- **Стабильность** - Тесты должны работать консистентно
- **Предсказуемость** - Результаты тестов должны быть предсказуемы
- **Работоспособность** - Тесты должны проверять реальные сценарии
- **Контроль** - Полный контроль над тестовой средой

## Отчеты

### Coverage Report
После запуска тестов с `--coverage` генерируется отчет в директории `coverage/`:
- `lcov-report/index.html` - HTML отчет
- `lcov.info` - LCOV файл для CI/CD
- `coverage.txt` - Текстовый отчет

### Test Results
Jest генерирует детальные отчеты о выполнении тестов с информацией о:
- Количестве пройденных/проваленных тестов
- Времени выполнения
- Покрытии кода
- Детальной информации об ошибках

## CI/CD Integration

Тесты готовы для интеграции с системами непрерывной интеграции:
- Поддержка exit codes для определения успешности
- LCOV отчеты для анализа покрытия
- Параллельное выполнение тестов
- Детальное логирование результатов
