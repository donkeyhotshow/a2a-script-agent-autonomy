# Обновление путей импорта и рефакторинг в gateway-app.js

## Описание задачи

После реорганизации директории `libs/` необходимо обновить пути импорта в файле `gateway-app.js`. Этот файл активно использует модули из старых путей, а также имеет потенциал для выноса кода.

## Требуемые изменения: Обновление импортов

Ниже приведен список текущих импортов и предложенные новые пути на основе реорганизации `libs/`:

1.  `const { ApiUtils } = require('../../utils/api');`
    *   **Предложение**: `const { ApiUtils } = require('@libs/app-framework/api/api');` (или, если ApiUtils перенесено в core: `require('@libs/app-framework/core/api');` - это требует проверки)
2.  `const { AuthenticationUtils } = require('../../utils/authentication');`
    *   **Предложение**: `const { AuthenticationUtils } = require('@libs/app-framework/core/authentication');` (или `require('@libs/app-framework/security/authentication');` - это требует проверки)
3.  `const { ConfigurationUtils } = require('../../utils/configuration');`
    *   **Предложение**: `const { ConfigurationUtils } = require('@libs/app-framework/core/configuration');`
4.  `const configPath = path.join(process.cwd(), 'libs/utils/authentication/data/store.json');`
    *   **Предложение**: `const configPath = path.join(process.cwd(), 'libs/app-framework/security/authentication/data/store.json');` (или соответствующий путь к файлу конфигурации после перемещения)

**Важно**: Необходимо проверить точные новые пути для `ApiUtils`, `AuthenticationUtils` и `ConfigurationUtils`, так как они могли быть перемещены в другие подкатегории в `app-framework/`.

Пожалуйста, обновите все подобные импорты в файле `gateway-app.js`.

## Требуемые изменения: Вынос кода (неизбыточен)

Рассмотрите возможность выноса следующих частей кода:

1.  **Логика загрузки конфигурации аутентификации (строки 44-134)**: Этот блок кода довольно обширен и включает логику загрузки, обработки и предоставления fallback конфигурации для аутентификации. Эту логику можно вынести в отдельный модуль, например, `AuthenticationConfigLoader` в `libs/app-framework/security/authentication/`.
2.  **Обработчики ошибок (`app.use((err, req, res, next) => { ... })`)**: Если логика обработки ошибок является стандартной и повторяющейся, ее можно вынести в общий модуль `ErrorHandlingMiddleware` в `libs/app-framework/error-handling/`.
3.  **404 Handler (`app.use('*', (req, res) => { ... })`)**: Аналогично, этот обработчик может быть вынесен в общий модуль для обработки несуществующих маршрутов.

Цель выноса кода — сделать `gateway-app.js` более сфокусированным на своей основной задаче (маршрутизация и проксирование запросов), а вспомогательную логику перенести в специализированные модули.
