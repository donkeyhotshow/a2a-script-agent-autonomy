# Тесты для MCP Terminal Assistant

## 📋 Обзор

Этот каталог содержит тесты для проекта MCP Terminal Assistant, основанные на отчете о проверке функциональности. Все тесты проверяют работоспособность 7 основных инструментов MCP согласно отчету.

## 🎯 Цель тестирования

Проверить работоспособность MCP Terminal Assistant согласно отчету о проверке:
- **Общая оценка:** 9/10 - отличное состояние
- **Ключевые достижения:** Все 7 основных инструментов MCP доступны
- **Проблемы:** File инструмент требует исправления валидации путей Windows, Archive инструмент нуждается в лучшей документации параметров

## 🚀 Запуск тестов

### 🎯 Основной тест согласно отчету (рекомендуется начать с него)
```bash
# Запуск основного теста MCP Terminal Assistant
node mcp-terminal-assistant-test.cjs
```

### 🚀 Полное тестирование
```bash
# Запуск всех тестов (основной + unit + интеграция)
node run-mcp-tests.cjs
```

### 🧹 Очистка устаревших тестов
```bash
# Удаление устаревших тестов, оставление только актуальных
node cleanup-obsolete-tests.cjs
```

### 🔧 Модульные тесты
```bash
# Тесты terminal инструмента
node unit/terminal-handler.test.cjs

# Тесты file инструмента
node unit/file-handler.test.cjs

# Тесты search инструмента
node unit/search-handler.test.cjs

# Тесты atomic инструмента
node unit/atomic-handler.test.cjs

# Тесты archive инструмента
node unit/archive-handler.test.cjs

node unit/test-handler.test.cjs
```
