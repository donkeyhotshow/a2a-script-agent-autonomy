# Plan to Fix Server Startup Error: Cannot find package '@a2a/server-utils'

## Problem Analysis

The server is failing to start with error:
```
Error [ERR_MODULE_NOT_FOUND]: Cannot find package '@a2a/server-utils' imported from C:\workspace\org-carrier\a2a-script-agent\a2a-server\packages\server\src\index.ts
```

From code analysis, the issue is that the a2a-server workspace has:
1. **Missing package.json files** for many packages (actions, core, daemon, features, gray-room, llm, memory, server, services, transform)
2. **Conflicting workspace names** - both `utils` and `server-utils` packages exist but have naming conflicts
3. **Broken workspace dependencies** using `workspace:*` protocol which npm can't resolve
4. **Duplicate utility files** in both `packages/utils/src/` and `packages/utils/src/lib/`

## Immediate Solution Strategy

### Phase 1: Create Missing Package.json Files (30 min)
For each package missing package.json, create minimal package.json with proper exports and dependencies.

### Phase 2: Fix Workspace Dependencies (45 min)  
Replace `workspace:*` references with proper relative paths or rename packages to avoid conflicts.

### Phase 3: Consolidate Utilities (20 min)
Remove duplicate utilities in lib/ directory and establish single source of truth.

### Phase 4: Build and Test (30 min)
Build all packages and verify server starts successfully.

## Detailed Implementation Steps

### Step 1.1: Create package.json for all missing packages

Create package.json files for packages that don't have them:

- `packages/actions/package.json`
- `packages/core/package.json` 
- `packages/daemon/package.json`
- `packages/features/package.json`
- `packages/gray-room/package.json`
- `packages/llm/package.json`
- `packages/memory/package.json`
- `packages/server/package.json`
- `packages/services/package.json`
- `packages/transform/package.json`

Each should have minimal structure:
```json
{
  "name": "@a2a/[package-name]",
  "version": "1.0.0",
  "type": "module",
  "main": "dist/index.js",
  "types": "dist/index.d.ts",
  "scripts": {
    "build": "tsc",
    "test": "vitest run"
  },
  "dependencies": {},
  "devDependencies": {
    "typescript": "^5.3.3"
  }
}
```

### Step 1.2: Rename conflicting packages
- Rename `packages/utils` → `packages/server-utils` (since that's what server imports)
- Update any references to `@a2a/utils` to `@a2a/server-utils`

### Step 1.3: Fix workspace dependencies
Replace all `workspace:*` references with explicit relative paths:
```json
// OLD
"@a2a/server-utils": "workspace:*"

// NEW  
"@a2a/server-utils": "file:../server-utils"
```

### Step 2.1: Consolidate utilities
Remove all files from `packages/server-utils/src/lib/` since they're duplicates of `packages/server-utils/src/`

### Step 2.2: Update imports
Find and update any imports from `lib/` to use parent directory:
```typescript
// OLD: import { validate } from '../lib/validation.js'
// NEW: import { validate } from '../validation.js'
```

### Step 2.3: Update package exports
Ensure `packages/server-utils/package.json` exports both locations for backward compatibility:
```json
{
  "exports": {
    "./validation": "./dist/validation.js",
    "./lib/validation": "./dist/validation.js"
  }
}
```

### Step 3.1: Install dependencies
```bash
cd a2a-server
npm install
```

### Step 3.2: Build packages in dependency order
```bash
npm run build:deps  # config, server-utils, protocol, transform, core
npm run build:services  # llm, p2p, daemon, actions
npm run build:app  # server
```

### Step 3.3: Test server startup
```bash
npm run dev:no-auth
```

Expected result: Server starts successfully without module resolution errors.
