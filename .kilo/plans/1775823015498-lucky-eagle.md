# Plan to Fix AI Integration Issues

## Problem Analysis
The AI integration log shows that the Local LLM upstream service is failing to start. The docker-compose command is not recognized, and even if it were, the image `compat_llm/compat_llm:latest` does not exist. The proxy service runs on port 11434 but cannot connect to the upstream on port 11435.

## Root Causes
1. Docker-compose may not be installed or in PATH on Windows.
2. The docker-compose.yml files reference a non-existent image.
3. Missing environment configuration for the LLM model.

## Solution Steps

### 1. Verify Docker Setup
- Ensure Docker Desktop is installed and running on Windows.
- Install docker-compose if not available (may require Docker Desktop or separate installation).
- Confirm docker and docker-compose commands work in the terminal.

### 2. Update Docker Compose Configurations
- Locate docker-compose.yml files:
  - Root: `docker-compose.yml`
  - AI Hub: `a2a-ai-hub/docker-compose.yml`
- Replace `image: compat_llm/compat_llm:latest` with `image: ollama/ollama:latest` in the compat_llm service.
- Add environment variable `OLLAMA_MODEL=qwen3:8b` to the compat_llm service.

### 3. Alternative Local LLM Setup
- If Docker is not preferred, set `LOCAL_LLM_SERVE_CMD` to run Ollama locally (e.g., `ollama serve`).
- Ensure Ollama is installed and the model is pulled.

### 4. Restart Services
- Stop any running containers: `docker-compose down`
- Start services: `docker-compose up -d`
- Monitor logs for successful startup.

### 5. Test Integration
- Check health endpoints: `/health`, `/health/local-llm-upstream`
- Verify port 11435 is accessible.
- Test API calls to ensure LLM upstream is responding.

### 6. Update Documentation
- Document the changes in README or relevant docs.
- Note the switch to Ollama image.

## Risk Assessment
- Switching images may require API compatibility checks.
- Docker on Windows may have resource constraints.
- Ensure no production data loss during restarts.

## Success Criteria
- Proxy service starts without warnings.
- Health checks pass for both proxy and upstream.
- AI integration log shows successful connections.</content>
