# Plan to Fix A2A Server Startup Failure

## Problem
The a2a-server fails to start with error: "Cannot find module 'C:\workspace\org-carrier\a2a-script-agent\a2a-server\src\index.ts'"

The runbook-cli.js runs `npm run dev:no-auth` in the a2a-server directory, which executes `cross-env SKIP_AUTH=1 tsx watch src/index.ts`. However, the actual entry point is located at `packages/server/src/index.ts`, not `src/index.ts`.

## Root Cause
The package.json script references `src/index.ts`, but the file structure has the server code in `packages/server/src/index.ts`. This mismatch causes the module resolution to fail.

## Solution
Create `a2a-server/src/index.ts` as a re-export/import of the actual server entry point to maintain compatibility with the existing script.

## Steps
1. Create `a2a-server/src/index.ts` with content: `import './packages/server/src/index.ts';`
2. Test the startup by running `node .\scripts\runbook-cli.js start a2a-server`
3. Verify the server starts successfully and listens on port 3000
4. If successful, commit the change
