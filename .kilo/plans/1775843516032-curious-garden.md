# Plan to Integrate a2a-client Launch into runbook-cli.js

## Goal
Update the runbook-cli.js script to correctly launch the a2a-client components (Client API and Web UI) and ensure all dependencies are resolved.

## Prerequisites
- Node.js >=20.0.0 installed
- a2a-client workspace dependencies installed
- Shared package exports fixed and built
- Ports 3001 (Client API) and 5173 (Web UI) available

## Steps

1. **Fix Shared Package Exports**
   - Ensure all missing exports are added to `a2a-client/packages/shared/package.json`
   - Add `"./projects-document.js": "./src/projects-document.mjs"` to exports
   - Create missing files in `a2a-client/packages/shared/src/`
   - Build the shared package: `cd a2a-client/packages/shared && npm run build`

2. **Fix Import Issues in SDK and Storage**
   - Update import paths in SDK and storage packages to use correct exports
   - Change `.js` extensions to `.ts` where files are TypeScript
   - Ensure all dependencies are properly linked

3. **Update runbook-cli.js Service Definitions**
   - Modify the 'client-api' service startCmd to use `npx tsx src/server/index.ts`
   - Ensure the 'web-ui' service startCmd is `npm run dev` from a2a-client root
   - Update health endpoints and dependencies as needed

4. **Reinstall a2a-client Dependencies**
   - Run `npm install` in a2a-client to update workspace links

5. **Test Service Startup**
   - Use runbook-cli.js to start client-api and web-ui services
   - Verify health checks: Client API at http://localhost:3001/health, Web UI at http://localhost:5173

6. **Verify Integration**
   - Confirm services start in correct dependency order
   - Check logs for any remaining errors
   - Ensure web UI is accessible

## Notes
- The runbook-cli.js already has service definitions for client-api and web-ui
- For full stack, start all services: a2a-ai-hub, a2a-server, client-api, web-ui
- Services should auto-reload on code changes in dev mode
