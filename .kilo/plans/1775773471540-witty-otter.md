# Plan: Create File Renaming Script Based on JSON Schema

## Objective

Create a Node.js script that reads a JSON file containing a renaming schema and renames files sequentially according to that schema.

## Assumptions

- The script will be written in Node.js using JavaScript.
- The JSON schema is an object mapping old filenames to new filenames, e.g., `{"oldfile.txt": "newfile.txt"}`.
- The JSON file is named `rename-schema.json` and located in the current working directory.
- Files to rename are in the current working directory.
- Paths are relative.
- If a file to rename doesn't exist, skip and log a warning.
- No overwriting of existing files allowed (add check to prevent accidental overwrites).

## Implementation Steps

1. Create the script file `rename-files.js` in the root directory.
2. Read and parse the JSON file using `fs/promises`.
3. Validate the JSON format (ensure it's an object with string keys/values).
4. For each entry in the schema, check if old file exists.
5. If new file already exists, skip with error log.
6. Rename the file using `fs.rename` (promisified for async).
7. Process renames sequentially to avoid race conditions.
8. Add console logging for each operation (success/error).
9. Handle errors gracefully (e.g., permissions, invalid JSON).
10. Create a simple test by running the script with sample files.

## Risks and Considerations

- File system permissions: Script may fail if no write access.
- Overwriting: Prevented by check, but user can modify if needed.
- Large schemas: Sequential processing is fine for typical use.
- Cross-platform: Use path module for compatibility.

## Verification

- Create test files and JSON schema.
- Run script and verify files are renamed correctly.
- Test edge cases (missing files, existing targets, invalid JSON).
