# File Tree Normalization Plan

## Objective

Normalize the file tree structure by moving all remaining files from `core/` directory to their proper locations in the `kernel/features/packages` organization.

## Current State Analysis

- **kernel/**: Core orchestration and infrastructure
- **features/**: Specialized functionality (LLM, P2P, daemon, actions, etc.)
- **packages/**: Shared infrastructure (protocol, utils, config)
- **core/**: Original directory with 20 remaining TypeScript files that need to be moved
