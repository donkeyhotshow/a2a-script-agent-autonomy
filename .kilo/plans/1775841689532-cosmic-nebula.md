# Plan: Eliminate Triple Nesting in Actions Package

## Problem Summary
The action definitions are duplicated across three locations:
1. `a2a-server/packages/actions/src/definitions/` (main source)
2. `a2a-server/packages/features/src/actions/definitions/` (duplicate)
3. `a2a-server/packages/features/src/actions/src/actions/definitions/` (extra nesting duplicate)

Content comparison confirms definitions are identical across locations. Core action code (action-service.ts, etc.) exists only in `a2a-server/packages/actions/src/`.

## Current Load Mechanism
Definitions are loaded at runtime via `action-service.ts` using:
```typescript
path.resolve(process.cwd(), 'src/actions/definitions')
```
This resolves to `a2a-server/src/actions/definitions/` when server runs from `a2a-server/` directory.

## Solution Steps

### Step 1: Establish Single Source of Truth
- **Main location**: `a2a-server/packages/actions/src/definitions/`
- **Rationale**: Aligns with package structure and existing action code location
- **Status**: Confirmed as most complete and up-to-date

### Step 2: Update Load Path
- **File**: `a2a-server/packages/actions/src/action-service.ts:66`
- **Change**: Update load path from `'src/actions/definitions'` to `'packages/actions/src/definitions'`
- **Impact**: Ensures runtime loading uses the consolidated definitions location
- **Backup copies**: Also update in `.kilo/scripts/duplicates/backups/` if needed for testing

### Step 3: Remove Duplicate Directories
- **Remove**: `a2a-server/packages/features/src/actions/definitions/`
- **Remove**: `a2a-server/packages/features/src/actions/src/actions/definitions/`
- **Preserve**: Any unique files in `a2a-server/packages/features/src/actions/` (verify none exist)
- **Safety**: Create backups before removal

### Step 4: Clean Up Related Artifacts
- **Index files**: Remove or update any index.ts files in duplicate locations that reference removed definitions
- **Backup files**: Clean up `.kilo/scripts/duplicates/backups/` after verification
- **Documentation**: Update any references to duplicate paths

### Step 5: Verification
- **Tests**: Run action-related tests (`a2a-server/packages/actions/tests/`)
- **Load verification**: Confirm definitions load correctly from new path
- **Integration tests**: Run server integration tests to ensure no broken imports
- **Linting**: Run `npm run lint` across affected packages

## Benefits
- **Code maintenance**: Reduce maintenance burden by 3x
- **Consistency**: Single source of truth for action definitions
- **Performance**: Eliminate duplicate file storage and potential load conflicts
- **Clarity**: Simplified directory structure

## Risk Mitigation
- **Backups**: Preserve all files before deletion
- **Testing**: Comprehensive test runs before and after changes
- **Rollback**: Ability to restore from backups if issues arise

## Dependencies
- No static imports to update (runtime loading only)
- Minimal impact on other packages
- Server restart required for path changes to take effect
