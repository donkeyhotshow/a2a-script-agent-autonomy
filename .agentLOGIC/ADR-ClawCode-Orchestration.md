# ADR: Архитектурные паттерны Claw Code для A2A Orchestration

- **Статус**: Предложено
- **Дата**: 2026-04-01
- **Контекст**: Проект Claw Code представляет собой высокоуровневую реализацию агентского каркаса (harness). Основная ценность заключается в управлении сложными сессиями, интеграции MCP и производительном рантайме на Rust.

## Решение

Внедрить ключевые паттерны Claw Code в A2A Script Agent для повышения автономности и масштабируемости.

### 1. Маршрутизация промптов (Prompt Routing)
Вместо прямой передачи всех инструментов в LLM, использовать легковесный пре-скоринг (как в `runtime.py`), чтобы выбирать наиболее релевантные инструменты и сокращать размер контекста.

### 2. Поддержка MCP (Model Context Protocol)
Использовать MCP SDK для динамического подключения инструментов. Это заменяет жестко прописанные `action-handlers`.

### 3. Session Compaction (Сжатие сессии)
При достижении порога в 80% контекстного окна, выполнять автоматическую суммаризацию "отработанных" этапов, сохраняя только финальные состояния файлов и ключевые решения.

### 4. Реализация на Rust
Для критических узлов (парсинг сообщений, управление состоянием сессии) рассмотреть возможность выноса логики в Rust-модули (через N-API или как бинарные утилиты), следуя примеру `crates/runtime` в Claw Code.

## Примеры реализации

#### Пример маршрутизатора (Python/Node.js logic)
```javascript
// Упрощенный скоринг инструментов
function routePrompt(prompt, tools) {
    const tokens = prompt.toLowerCase().split(' ');
    return tools.map(tool => ({
        name: tool.name,
        score: tokens.filter(t => tool.description.includes(t)).length
    })).sort((a, b) => b.score - a.score).slice(0, 5);
}
```

#### Схема MCP-вызова
```json
{
  "execute": {
    "mcp-call": {
      "server": "google-search-server",
      "tool": "search",
      "arguments": { "query": "latest rust news" }
    }
  }
}
```

## Последствия

- **Плюсы**:
    - Существенная экономия токенов за счет сжатия и маршрутизации.
    - Доступ к сотням готовых MCP-инструментов.
    - Повышение стабильности на длинных задачах.
- **Риски**:
    - Усложнение логики управления историей сессии.
    - Необходимость поддержки MCP-клиента в серверной части.
