# Старт Помощник

## Входной промпт для многоагентной системы

Скопируйте и используйте этот промпт для запуска оркестрации:

---

**Задача**: [Введите вашу задачу здесь]

После ввода задачи система автоматически:
1. Запустит 10 специализированных ролей
2. Организует последовательную проверку и критику решений
3. Сгенерирует документы в директории `state/` ([индекс этапов](state/README.md))
4. Проверит convergence (сходимость) через Quality Controller

## Режимы работы

| Тип задачи | Режим | Описание |
|------------|-------|----------|
| Проектная | state-файлы | Последовательные этапы (00-09) |
| Точечная | direct | Работа строго по задаче |

## Критерии остановки

Система завершает когда Контроллер-Качества подтверждает:
- Логическую целостность
- Соответствие исходной задаче
- Отсутствие внутренних противоречий

## Ролевой состав (10 ролей)

1. Стратег-Декомпозитор → scope
2. Архитектор-Системщик → architecture  
3. Аналитик-Требований → requirements
4. Инженер-Реализации → implementation
5. Оптимизатор → optimization
6. Критик-Аудитор → audit
7. Документатор → documentation
8. Валидатор-Целей → validation
9. Синтезатор → final
10. Контроллер-Качества → quality_gate
