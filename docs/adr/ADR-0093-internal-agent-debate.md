# ADR-0093: Internal Agent Debate Pattern

## Status
Approved

## Context
Агенты часто совершают ошибки при планировании сложных задач, если не получают критической обратной связи.

## Decision
Внедрить паттерн "Внутренний Спор" (Internal Debate). Перед выполнением основной задачи в Gray Room, LLM-сервис запускает цикл:
1. **Architect**: Предлагает план.
2. **Critic**: Ищет ошибки и граничные случаи в плане.
3. **Architect (Refining)**: Обновляет план с учетом критики.

## Consequences
+ Повышенная точность планирования.
+ Минимизация галлюцинаций.
- Увеличение расхода токенов на первую итерацию.
