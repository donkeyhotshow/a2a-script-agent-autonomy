# ADR-0059: Интеграция LangChain Agent Chat UI как базового интерфейса

- **Статус**: Предложено
- **Дата**: 2026-04-02
- **Контекст**: Для реализации "премиального" пользовательского опыта и поддержки концепции "артефактов" (ADR-unified-agent-logic), необходимо выбрать стабильную базу для фронтенда. Проект `agent-chat-ui` (LangChain AI) предоставляет готовую архитектуру для работы с графовыми агентами.

---

## Решение

Использовать кодовую базу `agent-chat-ui` (Next.js) в качестве основного интерфейса для `a2a-script-agent`, адаптировав её под специфику нашего протокола.

### 1. Поддержка LangGraph SDK
Использовать `@langchain/langgraph-sdk` для управления сессиями. Это позволит нам бесшовно интегрировать сложные графы логики, разработанные на сервере, с визуальным отображением.

### 2. Панель Артефактов (Side Panel)
- Задействовать встроенный механизм `useArtifact` для отображения результатов работы инструментов (код, логи, браузерные скриншоты).
- Все "тяжелые" ответы агента будут направляться в панель артефактов через метаданные сообщения.

### 3. Механизм фильтрации технических сообщений
- Использовать префикс `do-not-render-` для ID сообщений, которые содержат сырые вызовы инструментов или промежуточные шаги "размышления" (Thinking), оставляя в чате только чистый диалог.

### 4. Адаптация под A2A Protocol
- Модифицировать `useTypedStream` (или аналогичный хук в проекте) для поддержки наших специфических Action-Keys и структуры Context.

## Последствия

### Плюсы:
- **Скорость внедрения**: Мы получаем готовый профессиональный интерфейс с поддержкой темной темы, Markdown, подсветки синтаксиса и потокового вывода.
- **Совместимость**: Стандарт LangChain/LangGraph поддерживается большинством современных LLM и фреймворков.
- **UX**: Пользователь получает "Claude-like" интерфейс с разделением чата и контента.

### Риски:
- **Зависимости**: Проект завязан на экосистему LangChain, что может усложнить кастомизацию под нестандартные протоколы.
- **Next.js Overhead**: Необходимость поддержки полноценного React-приложения вместо легковесного Vite-плагина.

---

## Альтернативы
1. **Кастомный React-фронтенд с нуля**: Дает полный контроль, но требует значительных временных затрат на реализацию стриминга и панелей.
2. **Vite Plugin (текущий)**: Ограничен в возможностях построения сложного интерактивного UI.
