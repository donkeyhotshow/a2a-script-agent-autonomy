# ADR-0104: Self-Evolving Registry (SweepAI/OpenSpace)
**Status:** Approved | **Effort:** 120min | **ROI:** 9.5

**Context:** Агенты должны иметь возможность исправлять свои инструменты или создавать новые при высоком уровне ошибок (failRate > 30%).
**Decision:** Реализация эндпоинта `/evolve` и системы автоматического тестирования/развертывания кастомных инструментов.
**Implementation:** `src/api/tools-evolve.ts` + `loadCustomTools` hot reload.

# ADR-0105: Context Swinging (AgentSwing/LangGraph)
**Status:** Approved | **Effort:** 180min | **ROI:** 8.2

**Context:** Ограничение контекста (token overflow) в длинных задачах приводит к потере качества.
**Decision:** Использование парадигмы LangGraph для ветвления при достижении 70% лимита токенов (KeepLastN/Summary/Discard).
**Implementation:** `src/services/core/context/AgentSwing.ts` интеграция с `@langchain/langgraph`.

# ADR-0106: P2P Session Relay (openfang/libp2p)
**Status:** Approved | **Effort:** 240min | **ROI:** 7.8

**Context:** Централизованная архитектура является узким местом при масштабировании.
**Decision:** Использование `libp2p` Relay Rooms для распределения сессий и артефактов между узлами.
**Implementation:** `src/p2p/node.ts` (обновление под Relay).

# ADR-0107: Actor Sub-Agents (BullMQ/vibecosystem)
**Status:** Approved | **Effort:** 200min | **ROI:** 6.5

**Context:** Динамические инструменты позволяют запускать сотни параллельных воркеров для ускорения сложных задач.
**Decision:** Использование BullMQ для управления очередями задач и масштабирования команд субагентов (до 136+).
**Implementation:** `src/orchestrator/actors.ts`.
