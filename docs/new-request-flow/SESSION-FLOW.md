# Поток сессий (Session Flow)

> **⚠️ Важно:** Старый формат (`actions[]`, `proposedActions`, `subActions`, `executingAction`, `dslScript`) устарел.
> Используйте `execute.form.choices` для первого ответа.
> 
> **См.:** [PROTOCOL.md](PROTOCOL.md), [SCHEMA.md](SCHEMA.md)

> **ВАЖНО:** Сервер (a2a-server) STATELESS - не хранит сессии!
> Все сессии хранятся на Client API. Сервер только обрабатывает запросы через `/invoke`.

## Обзор

Сессия представляет собой контекст выполнения задачи пользователя. Сессия проходит через несколько состояний от создания
до завершения.

**Два типа действий в первом ответе:** (1) **actions** — первоочередно; шаги захардкожены, сервер сам переключает шаг. (

2) **ai-actions** — второстепенно (диалог с LLM); отображается список доступных шагов, следующий шаг определяется из
   ответа LLM; возможен отдельный запрос на каждый шаг.

## Состояния сессии

```
┌──────────┐     ┌─────────┐     ┌──────────────┐     ┌────────────────────┐
│ PENDING  │────▶│  READY  │────▶│ IN_PROGRESS  │────▶│ COMPLETED          │
└──────────┘     └─────────┘     └──────────────┘     └────────────────────┘
     │                │                  │                         ▲
     │                │                  │                         │
     │                │                  ├────────────┐            │
     │                │                  ▼            ▼            │
     │                │           ┌──────────────┐ ┌─────────┐       │
     │                │           │ WAITING_      │ │  ERROR  │───────┘
     │                │           │ CONFIRMATION  │ └─────────┘
     │                │           └──────────────┘
     │                │
     │                │     ┌─────────┐
     └───────────────▶│ CANCELLED │
                        └─────────┘
```

| Состояние              | Описание                                             |
|------------------------|------------------------------------------------------|
| `PENDING`              | Сессия создана, ожидает выбора действия из `actions` |
| `READY`                | Пользователь выбрал действие, готова к выполнению    |
| `IN_PROGRESS`          | Выполняются шаги (steps)                             |
| `WAITING_CONFIRMATION` | Ожидает подтверждения от пользователя                |
| `COMPLETED`            | Все шаги выполнены успешно                           |
| `ERROR`                | Ошибка при выполнении                                |
| `CANCELLED`            | Отменена пользователем                               |

## Панель сессии (Session Panel)

Каждая сессия отображается в отдельной панели (SessionPanel).

### Состояния панели

| Состояние   | Внешний вид    | Ограничения                               |
|-------------|----------------|-------------------------------------------|
| `inactive`  | Серый бордер   | Нельзя закрыть, пока есть активные задачи |
| `active`    | Цветной бордер | Можно взаимодействовать                   |
| `minimized` | Иконка в доке  | Клик для восстановления                   |

## Сохранение сессий

Сессии хранятся локально на Client:

1. **В памяти** - для активных сессий
2. **В файловой системе** - для персистентности
    - `~/.a2a-client/sessions/` - JSON файлы
3. **В БД** - для масштабирования (опционально)
