# Ограничения команд/промптов на сервер

**Индекс:** [docs/README.md](README.md)

Клиент **не может** отправлять произвольные задачи. Сервер принимает только допустимые команды.

---

## Разрешённые команды

| Команда | context | codeBlocks | Описание |
|---------|---------|------------|----------|
| **Сбор контекста** | `project_path`, `new_task` (ограниченный текст) | — | Инициализация: путь к проекту, краткое описание |
| **Передача файлов** | `project_path` | path + content | Клиент отдаёт файлы по запросу сервера |
| **Продолжение** | `continue: true` | — | Кнопка «Делаем» — без ввода текста |
| **Подтверждение** | `confirm: true` | path + content | Верификация применённых изменений |

---

## Ограничения new_task

- **Не** произвольный промпт пользователя.
- **Разрешено:** краткий текст задачи + подсказки из индекса + `architectural_features`.
- Фильтрация по правилам: только релевантные данные.
- Первый промпт не может быть пустым (кроме `continue`).

---

## Роли

| Роль | Назначение |
|------|------------|
| **Сервер** | Сбор контекста, анализ, выполнение задачи через ChatGPT |
| **Клиент** | Выдача файлов (codeBlocks), отображение результата |

---

## Запрещено

- Произвольные инструкции в `new_task`.
- Задачи, не связанные со сбором контекста и анализом кода.
- Изменение графа знаний через диалог (граф настраивается локально).
