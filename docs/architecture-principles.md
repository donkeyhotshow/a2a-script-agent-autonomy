# Архитектурные принципы A2A

**Индекс:** [docs/README.md](README.md)

---

## Главный принцип: Сервер не хранит данные клиента

### Что это значит:

1. **Граф знаний** — не хранится на сервере
2. **Контекст** — передаётся клиентом в каждом запросе
3. **Сессия** — идентификатор, не хранилище данных
4. **codeBlocks** — содержимое файлов от клиента

---

## Где хранятся данные?

| Данные | Где хранятся | Кто владеет |
|--------|--------------|-------------|
| Код проекта | Файловая система клиента | Клиент |
| Граф знаний | В контексте (передаётся) | Клиент |
| История сессии | Локальное хранилище клиента | Клиент |
| Нейроны | В коде сервера (статичные) | Сервер |
| Запросы (Request) | Временное хранилище для polling | Сервер (временно) |

---

## Протокол: Контекстный блок

Вместо хранения графа на сервере, граф передаётся в контексте:

```typescript
// Запрос от клиента
{
  context: {
    project_path: "C:/workspace/project",
    
    // Граф знаний (от клиента)
    graph: {
      entities: [
        { id: "model-user", type: "MODEL", name: "User", path: "app/Models/User.php" },
        { id: "controller-user", type: "CONTROLLER", name: "UserController", path: "app/Http/Controllers/UserController.php" }
      ],
      relations: [
        { from: "controller-user", to: "model-user", type: "HANDLES" }
      ]
    },
    
    // Задача
    new_task: ["Add email field to User model"],
    
    // Запрошенные файлы (от предыдущей итерации)
    request_files: ["app/Models/User.php"]
  },
  
  // Содержимое файлов
  codeBlocks: [
    { path: "app/Models/User.php", content: "<?php ..." }
  ]
}
```

## Ответ сервера

```typescript
// Ответ от сервера
{
  outcome: "completed" | "graph_incomplete",
  
  // Обновлённый граф (если были новые codeBlocks)
  graph: {
    entities: [...],
    relations: [...]
  },
  
  // Активированные нейроны
  activated_neuron_ids: ["neuron-detect-n1-queries"],
  
  // Запрос дополнительных файлов
  request_files: ["app/Http/Controllers/UserController.php"],
  
  // Вопросы (если граф неполный)
  questions: ["Which controller handles User CRUD operations?"],
  
  // Инъекция знаний
  injected_content: "## Detect N1 Queries..."
}
```

## Что хранится на сервере

### Постоянно:
- **Нейроны** — статичные правила детекции (код)
- **Конфигурация** — настройки сервера

### Временно (для async polling):
- **Request** — запрос с контекстом, удаляется после обработки
- **Результат** — сохраняется до получения клиентом

### НЕ хранится:
- ❌ Код проекта клиента
- ❌ Граф знаний проекта
- ❌ История сессий
- ❌ Персональные данные

## Изменения в архитектуре

### До (неправильно):
```typescript
// GraphStore сохранял в PostgreSQL
await prisma.graphEntity.create({ ... });
```

### После (правильно):
```typescript
// Граф возвращается в ответе, не сохраняется
return {
  graph: {
    entities: recognizedEntities,
    relations: recognizedRelations
  }
};
```

---

## Клиентская ответственность

Клиент должен:
1. **Хранить граф** между итерациями
2. **Передавать граф** в каждом запросе
3. **Объединять графы** от разных итераций
4. **Управлять сессиями** локально
