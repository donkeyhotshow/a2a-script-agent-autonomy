# Agentic AI Patterns Library

### 1. Evaluator-Optimizer
Iterative loop where one agent generates and another evaluates/refines.

### 2. Context-Augmentation
Predictive context retrieval based on current task state.

### 3. Prompt-Chaining
Breaking complex instructions into a sequence of dependent LLM calls.

### 4. Orchestration
Centralized control plane managing multiple specialized sub-agents.

### 5. Multi-Agent Delegation
Dyanmic hand-off between roles (Architect → Builder → Reviewer).

### 6. Intent Preservation Gate
Hard-lock on initial user intent to prevent drift during long cycles.
