# ADR-0084: Enterprise Governance

## Status
Approved

## Context
Production agent usage requires strict governance, audit logs, and risk management.

## Decision
Introduce `/docs/adr-enterprise/` to store governance artifacts:
- `agent-governance.md`: Rules for autonomous actions.
- `risk-matrix.md`: Impact assessment for critical components.

## Consequences
- Compliance ready.
- Clear operational boundaries for operators.
