# Симуляция: graph-build

## Описание

Симуляция построения графа зависимостей для проекта. Этот экшен позволяет просканировать кодовую базу, извлечь сущности (классы, интерфейсы, функции, модули) и построить граф связей между ними на основе импортов и экспортов.

## Тип экшена

`action_proposal` — сервер предлагает действия на основе задачи пользователя.

## Входные данные (request.json)

- **action**: `task_request`
- **task**: "построить граф зависимостей для проекта"
- **options**:
  - `includeNodeModules`: false (исключить node_modules)
  - `includeTests`: true (включить тестовые файлы)
  - `maxDepth`: 15 (максимальная глубина анализа)

## Ожидаемый ответ (response.json)

Сервер предлагает набор действий для построения графа:

1. **graph-build** (приоритет 10) — основное действие
   - scan-files: сканирование файлов проекта
   - extract-entities: извлечение сущностей (классы, интерфейсы, функции)
   - build-relations: построение связей на основе импортов/экспортов
   - save-graph: сохранение графа

2. **graph-update** (приоритет 8) — инкрементальное обновление

3. **graph-visualize** (приоритет 6) — визуализация графа

## Тестовые сценарии

1. Построение полного графа для нового проекта
2. Инкрементальное обновление при изменении файлов
3. Обработка циклических зависимостей
4. Глубокий анализ вложенных модулей
