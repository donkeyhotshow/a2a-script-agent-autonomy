# coder-smart simulation

Симуляція для створення MD документу контексту задачі. AI аналізує вхідну задачу, створює план вивчення проблеми та генерує повноцінний MD документ.

## Workflow:
1. Користувач відправляє задачу
2. Сервер аналізує задачу (capture-task + analyze-intent)
3. LLM створює план вивчення (llm-first-iteration)
4. Сервер генерує MD документ контексту (create-context-document)
5. Клієнт отримує документ

## Особливості:
- Сервер створює файли (context document)
- Немає персистенції - документи повертаються клієнту
- Клієнт передає контекст з попередніх сесій
- Багато ітерацій для детального вивчення
