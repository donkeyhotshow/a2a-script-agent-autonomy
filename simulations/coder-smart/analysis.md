# Coder Smart — workflow

## Відмінність від coder-dialog

- **Без steps:** один action `coder-smart`, весь сценарій керується LLM.
- **Контекст-документ:** один MD-файл у проекті (запит, формулювання, план, чеклист).
- **Ітерації:** після кожної виконаної дії history обнуляється; перше повідомлення = контент MD. LLM виконує наступний пункт чеклиста.

## Фази

| Фаза | Що відбувається |
|------|------------------|
| 1 | Запит → actions → вибір coder-smart → LLM генерує 4 блоки MD → write-file у проект |
| 2 | History = [content MD]. LLM виконує перший пункт чеклиста → write-file оновленого MD |
| 3+ | Повтор: history = [content MD], LLM — наступний пункт, оновлення MD, до кінця чеклиста |

## Очікувані результати

- Сервер пропонує один action `coder-smart` без масиву steps.
- Відповіді сервера містять `execute.write-file` з шляхом і контентом MD.
- У кроках з LLM: request.md з system prompt і контентом (запит або MD), response.md — вивід LLM (контент документа або результат виконання пункту).
