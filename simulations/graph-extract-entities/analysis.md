# Analysis: Graph Extract Entities

## Опис

Симуляція для тестування екшена `graph-extract-entities` - витягування сутностей з коду для побудови графа залежностей.

## Що тестуємо

- Здатність системи аналізувати код і витягувати сутності (класи, функції, модулі)
- Формування структурованих даних для графа

## Очікувані результати

- Список витягнутих сутностей з метаданими
- Типи сутностей (class, function, module, variable)
- Позиції в коді

## Тестовий сценарій

1. **task_request** - запит на витягування сутностей
2. **approve_action** - підтвердження екшена
3. **step_result** - результати аналізу коду
4. **action_complete** - завершення екшена

## Критерії успіху

- [ ] Правильно ідентифіковано типи сутностей
- [ ] Вказані позиції в коді
- [ ] Повернуто структурований JSON
