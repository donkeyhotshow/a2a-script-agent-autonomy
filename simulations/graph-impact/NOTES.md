# Заметки: graph-impact

## Реализация

- **Статус**: ✅ Реализовано
- **Дата**: 2026-02-25

## Особенности реализации

1. **Двунаправленный обход**: Анализирует как нисходящие (от чего зависит), так и восходящие (что зависит) зависимости
2. **Классификация**: Разделяет зависимости на прямые и транзитивные
3. **Оценка риска**: Присваивает уровень риска каждой зависимости на основе типа связи
4. **Рекомендации**: Предлагает приоритетный порядок тестирования

## Зависимости

- Требует предварительного построения графа (graph-build)
- Использует результаты graph-query для детального анализа

## Ожидаемые результаты

- Список затронутых файлов с уровнем риска
- Рекомендации по порядку тестирования
- Визуализация дерева зависимостей
- Оценка complexity change

## Тестирование

- Тесты на корректность обхода графа в обоих направлениях
- Тесты на классификацию зависимостей
- Тесты на оценку риска
- Интеграционные тесты с реальными контроллерами
- E2E тесты для проверки отчётов
