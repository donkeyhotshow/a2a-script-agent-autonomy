# Симуляция: hybrid-refactor

## Описание
Гибридный рефакторинг - комбинация анализа кода, проектирования сервиса, генерации кода, анализа графа зависимостей, миграции импортов и обновления маршрутов.

## Тип экшена
`action_proposal`

## Входные данные
- action: `task_request`
- task: "рефакторить контроллер UserController - вынести бизнес логику в сервис"
- options:
  - targetFile: "src/controllers/UserController.ts"
  - refactorType: "extract_service"
  - createService: true
  - updateRoutes: true
  - includeTests: true

## Ожидаемое поведение
Сервер должен предложить гибридный экшен, который комбинирует:
1. Анализ (analyze-*) - анализ бизнес-логики в контроллере
2. Генерация (generate-*) - генерация нового сервиса и тестов
3. Граф (graph-*) - анализ зависимостей и миграция импортов
4. Действия по обновлению маршрутов

## Sub-actions (гибридный подход)
1. **analyze-controller-logic** - анализ бизнес-логики контроллера
2. **graph-controller-deps** - анализ графа зависимостей контроллера
3. **design-service-interface** - проектирование интерфейса сервиса
4. **generate-user-service** - генерация нового сервисного файла
5. **migrate-controller** - миграция контроллера с вызовом сервиса
6. **update-routes** - обновление маршрутов
7. **graph-migrate-imports** - миграция импортов в зависимых файлах
8. **generate-service-tests** - генерация unit-тестов для сервиса

## Особенности гибридного экшена
- Комбинирует аналитику + генерацию + граф операции + действия
- subActions включают действия из разных категорий (analyze, generate, graph)
- Обеспечивает полный цикл рефакторинга: проанализировать → спроектировать → сгенерировать → мигрировать → протестировать
