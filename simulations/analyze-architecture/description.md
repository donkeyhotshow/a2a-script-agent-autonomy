# Симуляция: analyze-architecture

## Описание
Анализ архитектуры проекта - определение паттернов проектирования и компонентной структуры.

## Тип экшена
`action_proposal`

## Входные данные
- action: `task_request`
- task: "проанализировать архитектуру проекта"

## Ожидаемое поведение
Сервер должен предложить экшен analyze-architecture с набором sub-actions для анализа архитектуры.

## Sub-actions
1. detect-patterns - обнаружение архитектурных паттернов
2. analyze-components - анализ компонентной структуры
3. analyze-module-deps - анализ зависимостей между модулями
4. detect-layers - выявление слоёв приложения
5. generate-arch-docs - генерация документации
