## Критические нарушения структуры

### 1. `fix-vue-imports-batched/5/response.json` - Некорректная структура response
- **Тип проблемы**: структура
- **Описание**: Поле `result` находится на верхнем уровне response.json наряду с `execute`
- **Ожидалось по схеме**: Response должен содержать только `context`, `execute` и опционально `message`. Данные результата должны быть в `context.history` или обрабатываться сервером
- **Фактически найдено**: `"result": { "script": { "totalFiles": 50, "currentFile": 1, "message": "..." } }` на том же уровне что и `execute`
- **Статус**: ✅ Исправлено

### 2. `phpunit-deprecations/3/request.json` - Неправильный action-key в result
- **Тип проблемы**: структура
- **Описание**: Результат скрипта использует ключ `scan-phpunit` вложенным в `script`
- **Ожидалось по схеме**: `result: { "scan-phpunit": { "files": [...], "total": 45 } }`
- **Фактически найдено**: `result: { "script": { "scan-phpunit": { "files": [...], "total": 45 } } }` - лишняя вложенность
- **Статус**: ✅ Исправлено

### 3. `phpunit-deprecations/5/request.json` - Некорректный формат результата
- **Тип проблемы**: тип данных
- **Описание**: Поле `script` содержит строку вместо объекта с action-key
- **Ожидалось по схеме**: `result: { "script": { "report": "..." } }`
- **Фактически найдено**: `result: { "script": "# PHPUnit Deprecations\n\n..." }` - строка вместо объекта
- **Статус**: ✅ Исправлено

### 4. `task-decomposition/7/request.json` - Некорректный формат результата
- **Тип проблемы**: тип данных
- **Описание**: Аналогично пункту 3 - строка вместо объекта
- **Ожидалось по схеме**: `result: { "script": { "path": "..." } }`
- **Фактически найдено**: `result: { "script": ".carrier/tasks/task-1.md" }`
- **Статус**: ✅ Исправлено

## Рекомендации по исправлению

1. **Убрать `result` с верхнего уровня response.json** - данные результата должны передаваться через `context` или обрабатываться сервером

2. **Стандартизировать action-key shape** - все результаты должны использовать формат `result: { "action-name": { ...params } }`

3. **Преобразовывать строки в объекты** - поля `result.script` и аналогичные должны содержать объекты, не строки

4. **Всегда включать `execute` в response** - даже пустой объект для финальных шагов

## Примечание

Поля внутри `context` (включая `history`) имеют свободный формат и регулируются системой. Эти поля не проверяются на соответствие схеме.
