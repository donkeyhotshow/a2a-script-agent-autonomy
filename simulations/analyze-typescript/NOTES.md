# Заметки: analyze-typescript

## Тестирование
- Проверка обнаружения использования `any` типов
- Валидация анализа generics и type-only импортов

## Зависимости
- Требует TypeScript компилятор API для анализа типов
- Использует AST для статического анализа кода

## Примечание
Это симуляция gold standard - используется для тестирования парсера и валидации ответов сервера.
