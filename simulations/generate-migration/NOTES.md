# Заметки: generate-migration

## Тестирование
- Экшен предлагает три варианта: полная миграция, базовая, ALTER
- При получении запроса "создать миграцию для таблицы users" сервер должен вернуть предложения с суб-экшенами
- Если таблица уже существует - предложить ALTER миграцию

## Зависимости
- Требует шаблон миграции Laravel
- Для индексов требуется понимание часто запрашиваемых полей
- Для ALTER требуется анализ текущей структуры

## Примечание
- Это симуляция gold standard - используется для тестирования парсера и валидации ответов сервера
- Имя файла миграции должно соответствовать конвенции: YYYY_MM_DD_HHMMSS_create_users_table.php
- Миграция должна содержать методы up() и down()
- При создании таблицы users рекомендуется добавлять уникальный индекс для email
