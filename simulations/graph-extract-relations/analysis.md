# Analysis: Graph Extract Relations

## Опис

Симуляція для тестування екшена `graph-extract-relations` - витягування зв'язків між сутностями для побудови графа залежностей.

## Що тестуємо

- Здатність системи аналізувати код і витягувати зв'язки (імпорти, наслідування, виклики)
- Формування структурованих даних для графа

## Очікувані результати

- Список витягнутих зв'язків з типами
- Джерело і ціль зв'язку
- Типи зв'язків (import, extends, implements, calls)

## Критерії успіху

- [ ] Правильно ідентифіковано типи зв'язків
- [ ] Вказані джерело і ціль
- [ ] Повернуто структурований JSON
