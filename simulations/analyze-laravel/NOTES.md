# Заметки: analyze-laravel

## Тестирование
- Проверка анализа Eloquent моделей и связей
- Валидация анализа миграций и структуры БД

## Зависимости
- Требует PHP AST парсер для анализа Laravel файлов
- Использует анализ классов и аннотаций

## Примечание
Это симуляция gold standard - используется для тестирования парсера и валидации ответов сервера.
