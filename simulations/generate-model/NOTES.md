# Заметки: generate-model

## Тестирование
- Экшен предлагает два варианта: с полными связями/мутаторами и с Factory
- При получении запроса "создать модель Order" сервер должен вернуть предложения с суб-экшенами

## Зависимости
- Требует шаблон модели Laravel
- Для связей требуется информация о связанных моделях
- Для Factory требуется шаблон factory

## Примечание
- Это симуляция gold standard - используется для тестирования парсера и валидации ответов сервера
- Модель должна следовать конвенциям Laravel Eloquent
- При выполнении должен создавать файл в app/Models/
- total_amount рекомендуется хранить в копейках/центах (integer), использовать accessor для форматирования
