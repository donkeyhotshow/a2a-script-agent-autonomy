# Запрос к LLM (симуляция dialog/2)

## Контекст

```json
{
  "context": {
    "task": "диалог",
    "execution": {
      "action": "task",
      "step": "router"
    }
  }
}
```

## Результат

Пользователь выбрал вариант `dialog`.

## Инструкция

Подтверди выбор и сформируй следующую стадию диалога: запусти обработку сообщения пользователя. Ответ можно оставить в
виде заметки или execute-описания, которое будет передано дальше в симуляции.
