# Заметки: graph-query

## Реализация

- **Статус**: ✅ Реализовано
- **Дата**: 2026-02-25

## Особенности реализации

1. **Поиск узла**: Использует индекс для быстрого поиска сущности по имени
2. **Обход графа**: Поддерживает BFS и DFS с ограничением глубины
3. **Фильтрация**: Позволяет фильтровать по типу файлов, типу связей
4. **Кэширование**: Результаты запросов кэшируются для повторного использования

## Зависимости

- Требует предварительного построения графа (graph-build)
- Использует индексы для быстрого поиска

## Ожидаемые результаты

- Список файлов с указанием типа использования
- Поддержка различных типов связей: imports, extends, implements, calls, aggregates
- Возможность ограничения глубины поиска

## Тестирование

- Тесты на производительность запросов
- Тесты на корректность обхода графа
- Тесты на фильтрацию результатов
- E2E тесты для интеграции с клиентом
