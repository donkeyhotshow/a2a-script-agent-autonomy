# Симуляция: graph-query

## Описание

Симуляция запроса к графу зависимостей для поиска использований конкретной сущности. В данном случае — поиск всех файлов, которые используют модель User.

## Тип экшена

`action_proposal` — сервер предлагает действия на основе задачи пользователя.

## Входные данные (request.json)

- **action**: `task_request`
- **task**: "найти все файлы которые используют модель User"
- **options**:
  - `searchType`: "entity_usage" (тип поиска)
  - `entityType`: "model" (тип сущности)
  - `entityName`: "User" (имя сущности)
  - `maxResults`: 50 (максимальное количество результатов)

## Ожидаемый ответ (response.json)

Сервер предлагает набор действий для выполнения запроса к графу:

1. **graph-query** (приоритет 10) — основное действие
   - find-entity: поиск узла User в графе
   - query-graph: выполнение запроса на поиск всех связей
   - filter-results: фильтрация результатов
   - format-output: формирование итогового отчёта

2. **graph-query-direct** (приоритет 8) — поиск только прямых зависимостей

3. **graph-query-typed** (приоритет 7) — поиск с фильтрацией по типу связей

## Тестовые сценарии

1. Поиск всех использований модели User
2. Поиск только ближайших зависимостей (depth=1)
3. Поиск с фильтрацией по типу связи (только imports)
4. Поиск с учётом наследования (extends/implements)
5. Проверка производительности на больших графах
