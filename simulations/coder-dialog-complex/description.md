# coder-dialog-complex Simulation

## Опис

Симуляція показує діалог з AI-асистентом, який:
- Веде діалог з користувачем
- Шукає файли в проекті (RAG)
- **Читає вміст файлів** (ключова відмінність від coder-dialog)
- Аналізує код
- Записує результати

Це комбінована симуляція на основі легасі документа ai-session-context.md:
- Формат діалогу з coder-dialog
- Читання файлів як окрема дія
- Аналіз коду та створення плану

## Workflow

| Крок | Опис |
|------|------|
| 1 | User відправляє задачу |
| 2 | Сервер повертає доступні дії |
| 3 | Користувач обирає coder-dialog |
| 4 | LLM аналізує → RAG пошук |
| 5 | LLM читає знайдені файли |
| 6 | LLM аналізує та відповідає |
| 7 | Користувач просить записати звіт |
| 8 | LLM створює MD документ |
