# Тест вибору дій (test-action-flow)

## Опис

Тестова симуляція для перевірки повного потоку: server → execute.form.choices → client → web.

## Мета

Перевірити, що протокол працює правильно:
1. Сервер повертає `execute.form` з `choices`
2. Клієнт обробляє відповідь
3. Веб відображає вибір дій

## Кроки

### Крок 1: Початковий запит
- `request.json`: `{ "task": "тест вибору дій" }`
- `response.json`: Форма з вибором двох дій

### Крок 2: Вибір користувача
- `request.json`: `{ "result": { "choice": "action-1" } }`
- `response.json`: Завершення з повідомленням

## Формат протоколу

```json
{
  "execute": {
    "form": {
      "title": "Виберіть дію",
      "choices": [
        { "id": "action-1", "label": "Дія 1" },
        { "id": "action-2", "label": "Дія 2" }
      ]
    }
  }
}
```
