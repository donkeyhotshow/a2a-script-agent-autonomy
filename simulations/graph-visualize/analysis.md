# Analysis: Graph Visualize

## Опис

Симуляція для тестування екшена `graph-visualize` - візуалізація графа залежностей.

## Що тестуємо

- Здатність системи генерувати візуальне представлення графа
- Формати виводу (DOT, SVG, JSON для VueFlow)

## Критерії успіху

- [ ] Правильно сформовано візуальне представлення
- [ ] Підтримка різних форматів виводу
