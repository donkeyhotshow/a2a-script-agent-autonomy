# Заметки: generate-controller

## Тестирование
- Экшен предлагает два варианта: полный контроллер и API контроллер
- При получении запроса "создать контроллер для товаров" сервер должен вернуть предложения с суб-экшенами

## Зависимости
- Требует шаблон контроллера
- Может потребовать анализ модели для правильной генерации связей
- Для API контроллера требует шаблон API Resource

## Примечание
- Это симуляция gold standard - используется для тестирования парсера и валидации ответов сервера
- Контроллер должен следовать RESTful принципам
- При выполнении должен создавать файл в правильной директории (app/Http/Controllers)
