# Coder Complex Simulation

## Опис

Симуляція показує складного AI-асистента (кодера) з:
1. Різингом - аналіз задачі
2. Збором контексту - RAG пошук та читання файлів
3. Чеклістом - структурований план задач
4. Виконанням задач по черзі

Це відрізняється від `coder-dialog` де був простий діалог. Тут - складний workflow з декомпозицією задачі.

## Workflow

| Крок | Опис |
|------|------|
| 1 | task |
| 2 | Вибір екшена |
| 3 | Різинг → потрібні файли → context-gathering |
| 4 | RAG результати |
| 5 | Різинг → чекліст → execute-task |
| 6-... | Кожна задача виконується по черзі |
