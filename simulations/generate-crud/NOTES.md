# Заметки: generate-crud

## Тестирование
- Экшен является композиционным - объединяет несколько generate-* экшенов
- При получении запроса "сгенерировать CRUD" сервер должен вернуть полный набор subActions

## Зависимости
- Требует шаблоны для генерации файлов (модель, контроллер, миграция)
- Может использовать шаблонизатор для генерации кода
- Контроллер должен соответствовать RESTful принципам

## Примечание
- Это симуляция gold standard - используется для тестирования парсера и валидации ответов сервера
- generate-crud является высокоуровневым экшеном, который декомпозируется на отдельные generate-* экшены
