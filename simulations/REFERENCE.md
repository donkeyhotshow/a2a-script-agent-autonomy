# Довідник: Типи дій (Actions vs AI-Actions)

## Огляд

У системі A2A Script Agent існує два типи дій, які визначають як приймаються рішення про виконання наступного кроку:

---

## Actions (Закодовані дії)

**Характеристики:**
- Кроки захардкожені у definition файлі
- Сервер автоматично перемикає кроки на основі `result`
- `step` в `execution` змінюється сервером
- Не використовують LLM для прийняття рішень
- Передбачуваний, детермінований потік

**Приклади симуляцій:**
- [`fix-vue-imports/`](fix-vue-imports/description.md) - виправлення імпортів у Vue файлах
- [`fix-vue-imports-batched/`](fix-vue-imports-batched/description.md) - пакетне виправлення імпортів

**Структура:**
```json
{
  "execute": {
    "step": "vue-import-detect",
    "action": "rag-search"
  }
}
```

---

## AI-Actions (AI-керовані дії)

**Характеристики:**
- Кроки НЕ захардкожені - LLM вирішує динамічно
- LLM аналізує результати і визначає наступний крок
- Гнучкий, адаптивний потік
- Може змінювати поведінку на основі контексту
- Використовує LLM для прийняття рішень

**Приклади симуляцій:**
- [`dialog/`](dialog/description.md) - простий діалог з LLM
- [`coder/`](coder/description.md) - кодер з RAG пошуком
- [`coder-smart/`](coder-smart/description.md) - розумний кодер з документом задачі

**Структура:**
```json
{
  "execute": {
    "form": {
      "message": "Що ви хочете зробити?"
    }
  },
  "llmPrompt": "Проаналізуй запит користувача і визнач наступну дію"
}
```

---

## Порівняння

| Характеристика | Actions | AI-Actions |
|----------------|---------|------------|
| Кроки | Захардкожені | Динамічні |
| Прийняття рішень | Сервер (код) | LLM |
| Гнучкість | Низька | Висока |
| LLM | Ні | Так |
| Передбачуваність | Висока | Змінна |
| Складність | Простіше | Складніше |

---

## Коли використовувати

### Actions
- Автоматичні задачі з чітким алгоритмом
- Пакетна обробка файлів
- Прості операції (пошук, запис, виконання команд)
- Коли потрібна висока передбачуваність

### AI-Actions
- Діалогові інтерфейси
- Складні задачі, що потребують аналізу
- Коли алгоритм невідомий заздалегідь
- Коли потрібна адаптивна поведінка
