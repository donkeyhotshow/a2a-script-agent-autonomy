# Довідник: Типи дій (Actions vs AI-Actions)

## Огляд

У першій відповіді сервера пропонуються два типи: **actions** (первоочергово) та **ai-actions** (другочергово). Від типу залежить обробка кроків (steps).

---

## Actions (первоочергові, захардкоджені кроки)

**Характеристики:**
- Кроки захардкожені у definition; сервер сам перемикає кроки за `result`
- `execution.step` змінюється сервером; наступний крок однозначно визначається
- LLM для вибору кроку не використовується

**Приклади:** [`fix-vue-imports/`](fix-vue-imports/description.md), [`fix-vue-imports-batched/`](fix-vue-imports-batched/description.md)

**Структура execute (canonical: key = action type):**
```json
{
  "context": { "execution": { "action": "fix-vue-imports", "step": "vue-import-detect" } },
  "execute": { "script": { "input": "...", "output": "...", "code": "..." } }
}
```

---

## AI-Actions (другочергові, діалог з LLM)

**Характеристики:**
- Кроки не в жорсткій послідовності: показується список *доступних* кроків, наступний крок визначає LLM зі свого відповіду
- Сервер відображає доступні кроки; з відповіді LLM вирішує, який крок активувати — можливі окремі запити на кожен крок
- Steps потрібні (для відображення), але не захардкоджені як послідовність

**Приклади:** [`dialog/`](dialog/description.md), [`coder/`](coder/description.md), [`coder-smart/`](coder-smart/description.md), [`auto-ai/`](auto-ai/description.md)

**Структура:** `execute.form`, `execute.message`, `execute.llm` або `execute["read-file"]` тощо — за рішенням LLM.

---

## Порівняння

| Характеристика | Actions | AI-Actions |
|----------------|---------|------------|
| Кроки | Захардкожені, сервер перемикає | Список доступних; наступний — з відповіді LLM |
| Хто визначає step | Сервер | LLM (з відповіді) |
| Окремі запити на крок | Ні (один потік) | Так, можливо |
| LLM | Ні | Так |

---

## Коли використовувати

### Actions
- Автоматичні задачі з чітким алгоритмом
- Пакетна обробка файлів
- Прості операції (пошук, запис, виконання команд)
- Коли потрібна висока передбачуваність

### AI-Actions
- Діалогові інтерфейси
- Складні задачі, що потребують аналізу
- Коли алгоритм невідомий заздалегідь
- Коли потрібна адаптивна поведінка
