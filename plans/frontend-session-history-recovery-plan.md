# План: История сессий и восстановление

## Выбранные улучшения

**Направление:** Улучшение интеграции с сервером → Сессии и управление состоянием → История сессий и восстановление

---

## Анализ текущего состояния

### Существующая функциональность (sessions.js)
- Создание/открытие/удаление сессий через API
- Загрузка списка сессий с фильтрацией (all/active/waiting/completed)
- Сообщения в сессиях с статусами (pending/completed/failed)
- Polling для получения обновлений (каждые 5 секунд)
- Graph panel для отображения сущностей

### Проблемы
1. **Нет локального кэширования** - при перезагрузке страницы данные теряются
2. **Нет истории изменений** - невозможно увидеть предыдущие состояния сессии
3. **Нет восстановления** - при сбое сети сессия "зависает"
4. **Нет поиска** - нельзя искать по содержимому сессий
5. **Нет импорта/экспорта** - нельзя сохранить/восстановить сессию

### Фаза 2: История изменений (History)

#### 2.1 Отслеживание изменений
- [ ] Добавить `HistoryManager` класс
- [ ] Логировать каждое изменение состояния сессии
- [ ] Хранить историю в структурированном виде:

```
javascript

    sessionId: string,
    events: [

        timestamp: Date,

        data: object,
        previousState: object
      }
    ]
  }
  
```
