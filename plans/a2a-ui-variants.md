## Вариант 1: Текущий UI (Sidebar + Chat + Flow)

```
┌─────────────────────────────────────────────────────────────────┐
│ Header: Logo | Search | Nav | Status                            │
├──────────┬────────────────────────────────────┬──────────────────┤
│ Sessions │        Chat Panel                 │                  │
│  List    │                                    │   VueFlow        │

│          │  │                            │  │                  │
│          │  └────────────────────────────┘  │                  │
│          │  ┌────────────────────────────┐  │                  │
│          │  │ Input                       │  │                  │
│          │  └────────────────────────────┘  │                  │
├──────────┴────────────────────────────────────┴──────────────────┤
│ Footer                                                         │
└─────────────────────────────────────────────────────────────────┘
```

**Плюсы:**
- ✅ Классический layout
- ✅ Знаком пользователям
- ✅ Flow не мешает

**Минусы:**
- ❌ Flow скрыт по умолчанию
- ❌ Три колонки могут быть тесными

## Вариант 2: Split View (50/50)

```
┌─────────────────────────────────────────────────────────────────┐
│ Header                                                         │
├────────────────────────────┬────────────────────────────────────┤
│                            │                                    │
│      Chat Panel            │         VueFlow Graph              │
│                            │                                    │
│                            │                                    │
│                            │                                    │
├────────────────────────────┴────────────────────────────────────┤
│ Action Progress Bar                                            │
```

**Особенности:**

## Компоненты UI для реализации

### 1. Sessions Panel (слева)
- Список сессий
- Фильтр по статусу
- Поиск
- Кнопка "New Session"

### 2. Chat Panel (по центру)
- История сообщений
- Input поле
- Кнопки: Send, Continue
- Typing indicator

### 3. Graph Panel (справа/снизу)
- VueFlow граф
- Legend (легенда типов)
- Zoom controls
- Node details при клике

### 4. Action Progress Panel
- Прогресс выполнения
- Список шагов
- Логи
- Кнопки: Approve, Run, Cancel

### 5. Node Details Card
- Информация о выбранном узле
- DSL вкладки
- Input/Output данные
