# Plasticine UI – TODO / заглушки

## 1. Куб (× Close) vs Свёртка (− Minimize)

### Текущее (неправильно)
- При свёртывании панели создаётся отдельный куб в углу; при открытии панели куб не пропадает.
- Непонятно, где куб и зачем.

### Целевое поведение

#### 1.1 Кнопка **Close (×)**
- [ ] При нажатии × панель **не закрывается** полностью.
- [ ] Под курсором создаётся **кубик** (маленький квадрат).
- [ ] Куб можно **перетаскивать** левой кнопкой мыши.
- [ ] **Правый клик** по кубу — смена цвета куба.
- [ ] **Клик по кубу** (левый) — открыть панель обратно; куб **пропадает**.
- [ ] Пока куб есть — панель в состоянии "закрыта через куб" (контент скрыт, панель не в DOM или скрыта).

#### 1.2 Кнопка **Minimize (−)**
- [ ] Панель **не превращается в куб**.
- [ ] Панель **уезжает в футер** (нижняя зона).
- [ ] В футере панель — **узкая полоса**: без полной шапки, только **текст/заголовок** (и при желании маленькие кнопки −/×).
- [ ] Размеры блоков панели меняются (компактный режим).
- [ ] Шапка панели убирается, остаётся только заголовок (или иконка+название).

### Файлы
- `a2a-client/web/js/plasticine-ui.js` — логика куба при Close, логика свёртки в футер при Minimize.
- `a2a-client/web/css/plasticine-ui.css` — стили куба (позиция под курсором), стили панели в футере (strip).
