- Клиент не получает чёткие инструкции

### 2. Определить типы инструкций
```
typescript
type FixInstruction = {
  type: 'add_relation' | 'remove_relation' | 'update_entity' | 
        'add_file' | 'update_file' | 'delete_file' |
        'add_import' | 'remove_import' | 'update_config';
  target: string;           // путь или идентификатор
  content?: string;         // новое содержимое
  relation?: string;        // для relation типов
  line?: number;            // номер строки
  metadata?: Record<string, unknown>;
}
```
