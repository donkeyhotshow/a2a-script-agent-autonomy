# План: 4.6 Web UI Improvements

## Текущее состояние

### Существующие компоненты
- **E2E тесты**: `a2a-client/e2e/tests/`
  - `projects.spec.ts` - тесты проектов
  - `sessions.spec.ts` - тесты сессий
  - `navigation.spec.ts` - тесты навигации
  - `explorer.spec.ts` - тесты файлового браузера
  - `integration.spec.ts` - интеграционные тесты

- **Page Objects**: `a2a-client/e2e/pages/`
  - `base.page.ts` - базовый класс
  - `projects.page.ts` - страница проектов
  - `sessions.page.ts` - страница сессий
  - `explorer.page.ts` - файловый браузер

- **Текущий UI**:
  - Build Index кнопка (#buildIndex)
  - Index Status индикатор (#indexStatus)
  - Project cards
  - Session viewer
