# План: 1.4 Graph Store персистентность

## Информация Gathered

### Текущее состояние
- **graph-store.service.ts**: In-memory хранение, все данные в context
- **request-processor.service.ts**: Использует `parseGraphFromContext()` для получения графа от клиента
- **message-builder.ts**: `buildRequestContextBlock()` включает graph в ответ
- **Prisma schema**: Уже содержит `GraphEntity` и `GraphRelation` модели

### Ключевые файлы
- `a2a-server/src/services/graph-store.service.ts` - основной сервис
- `a2a-server/src/services/request-processor.service.ts` - интеграция
- `a2a-server/prisma/schema.prisma` - модели БД
- `docs/protocol/context.md` - документация context

### Принцип работы
Граф передается в context от клиента → сервер обрабатывает → возвращает обновленный граф в context → клиент сохраняет и передает в следующем запросе.
