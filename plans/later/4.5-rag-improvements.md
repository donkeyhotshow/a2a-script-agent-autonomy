# План: 4.5 Улучшение RAG

> **Относится к:** a2a-client

## Текущее состояние

### Существующие компоненты
- **RAG пакет** (`packages/rag/`):
  - `indexer.js` - индексация файлов проекта с chunking по классам/методам/функциям
  - `searcher.js` - гибридный поиск (keyword + TF-IDF)
  - `chunk-manager.js` - управление чанками кода
  - `semantic-search.js` - семантический поиск (требует embedding клиент)
  - `tfidf.js` - TF-IDF/BM25 sparse retrieval
  - `rag-integrator.js` - интеграция FileScanner + RAG с watching

- **FileScanner** (`packages/fs-utils/`):
  - Готовое сканирование директорий с include/exclude паттернами

## Использование

```javascript
const { RAGIntegrator } = require('@a2a/rag');

// Сканирование и индексация
const integrator = new RAGIntegrator({ projectPath: '/path/to/project' });
await integrator.scanAndIndex();

// Или с watching
integrator.startWatching();

// Поиск
const { SemanticSearcher } = require('@a2a/rag');
const searcher = new SemanticSearcher({ projectPath: '/path/to/project' });
const results = await searcher.searchHybridSemantic('query');
```
