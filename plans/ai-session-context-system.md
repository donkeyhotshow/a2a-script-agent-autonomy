# План: AI Session Context System (AI Prompt Saver)

> **Относится к:** a2a-client (history, sessions)

## Текущее состояние

### Описание системы
Система для сохранения и использования контекста из предыдущих сессий при работе с новыми задачами.

### Рабочий процесс (существующий)
1. **Создание сессии**: При новой сессии создается отдельный JSON документ (конвертируется в MD)
2. **Добавление запроса**: То что пользователь написал в новый чат добавляется в конец файла сессии
3. **Поиск по индексу**: Получаем массив релевантных частей файлов и пути к файлам
4. **Уточнение задачи LLM**: Контекст (вектор данных + задача) → LLM → уточнения записываются в файл
5. **План изучения**: Повторный поиск → LLM → план изучения задачи → записывается в конец файла
6. **План правок**: Сбор полного контекста + граф → LLM → план правок по кодбейсу
7. **Выполнение**: Агент работает в YOLO режиме
8. **Контекстное подкидывание**: Система может изредка подкидывать контекст или корректировать

## Критерии приёмки

1. Система работает с существующим RAG индексом
2. Контекстные уточнения улучшают качество плана
3. YOLO mode безопасен (есть rollback)
4. Подкидывание контекста работает корректно
5. Обратная совместимость с текущим API
