# План: 2.1 Расширение JSON API

## Текущее состояние
- Базовый протокол в `docs/protocol-json-api.md`
- Неполный - нет questions, fixes в полном объёме

## Проблема
- Нет поля `questions[]` для уточнений
- Нет поля `fixes[]` для инструкций по исправлению
- Нет поля `scan_results` для результатов сканирования
- Нет поля `iterations` для отслеживания итераций

## План реализации

### 1. Добавить поле questions[]
**Файлы:**
- `a2a-server/src/protocol/message-builder.ts`
- `a2a-server/src/types/index.ts`
- `docs/protocol-json-api.md`
- [ ] Добавить тип Question в types
- [ ] Обновить buildRequestApiResult() для включения questions
- [ ] Обновить request-processor для генерации questions

### 2. Добавить поле fixes[]
- [ ] Определить тип FixInstruction
- [ ] types: add_relation, remove_relation, update_entity, add_file, etc.
- [ ] Интегрировать с генератором инструкций

### 3. Добавить поле scan_results
- [ ] Определить структуру ScanResult
- [ ] Включить результаты сканирования кода

### 4. Добавить поле iterations
- [ ] Определить структуру IterationInfo
- [ ] current: number
- [ ] max: number
- [ ] history: IterationRecord[]

## Пример расширенного ответа
```
json
{
  "outcome": "need_files",
  "questions": ["Which model stores users?"],
  "fixes": [
    { "type": "add_relation", "target": "User", "relation": "hasMany" }
  ],
  "iterations": { "current": 1, "max": 5 }
}
```
