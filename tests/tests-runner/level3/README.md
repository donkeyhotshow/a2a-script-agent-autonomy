# Level 3: End-to-End Integration Tests

> **Комплексные E2E тесты - полная проверка всех компонентов системы**

## Структура подуровней

```
level3/
├── 1-workflow/     # Тесты полных рабочих процессов
├── 2-cli/          # CLI тестирование и автоматизация
├── 3-performance/  # Тесты производительности
└── run.ps1         # Запуск всех Level 3 тестов с fail-fast
```

## Принцип работы

- **Полная интеграция**: Все компоненты работают вместе
- **Реальные сценарии**: Тестирование пользовательских workflow
- **Производительность**: Проверка под нагрузкой
- **Fail-fast**: Остановка при первой критической ошибке

## Тестируемые сценарии

### 1. Complete Workflows
- **New Session Flow**: Создание сессии → отправка сообщения → получение ответа
- **AI Action Flow**: Выбор действия → выполнение → результат
- **File Operations**: Чтение/запись файлов через систему
- **Error Recovery**: Обработка ошибок и восстановление

### 2. CLI Automation
- **Remote Control**: Управление Web UI через CLI
- **Batch Operations**: Множественные команды через API
- **Monitoring**: Реальное время мониторинга через SSE
- **Automated Testing**: Полная автоматизация тест-кейсов

### 3. Performance & Load
- **Concurrent Requests**: Множественные одновременные запросы
- **Memory Usage**: Мониторинг потребления памяти
- **Response Times**: Измерение задержек
- **Resource Limits**: Тестирование пределов системы

## Запуск

```bash
# Полный Level 3 (после успешных Level 1 и 2)
.\scripts\tests\level3\run.ps1

# Или по отдельности
.\scripts\tests\level3\1-workflow\run.ps1
.\scripts\tests\level3\2-cli\run.ps1
.\scripts\tests\level3\3-performance\run.ps1
```

## Требования

- ✅ Level 1 и Level 2 пройдены успешно
- ✅ Все сервисы запущены и работают
- ✅ Web UI доступен на порту 5173
- ✅ Полная база данных и модели AI загружены
- ✅ Достаточно ресурсов для нагрузочного тестирования

## Ожидаемое время выполнения

- **Workflow Tests**: 2-5 минут
- **CLI Tests**: 1-3 минуты
- **Performance Tests**: 3-8 минут
- **Total Level 3**: 6-16 минут

## Риски и предосторожности

- **Resource Intensive**: Может потреблять значительные ресурсы
- **Database Impact**: Создает тестовые данные в БД
- **AI Usage**: Потребляет токены LLM
- **Cleanup Required**: После тестов требуется очистка
