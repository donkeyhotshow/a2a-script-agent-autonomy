# A2A Premium Console

A2A Premium Console is a modern, Next.js 15 based frontend for the A2A Script Agent. It provides a polished chat interface with real-time session tracking, artifact rendering, and advanced operator controls.

## Setup

1. Install dependencies:
   ```bash
   pnpm install
   ```

2. Configure environment:
   The console defaults to connecting to the A2A Client API on `http://localhost:5173/api/a2a`.

3. Run the app:
   ```bash
   pnpm dev
   ```
   The console will be available at `http://localhost:3000`.

## Features

- **Rich Chat Interface**: Support for streaming responses (simulated via polling) and multi-modal message types.
- **Artifact Side Panel**: View files, logs, and state changes generated by the agent in real-time.
- **Session Management**: Easily switch between projects and active sessions.
- **Tailwind 4 & Framer Motion**: Uses the latest styling and animation libraries for a premium feel.

## Integration with A2A Stack

This console acts as a client for the A2A Client API. It uses Next.js rewrites to proxy requests to the backend, ensuring a seamless developer experience.

- **API URL**: Configured in `next.config.mjs` to proxy to port 5173.
- **Data Hook**: Powered by `useA2AStream` for session synchronization.
