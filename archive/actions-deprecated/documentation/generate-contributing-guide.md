# generate-contributing-guide

| Параметр | Значение |
|----------|----------|
| actionId | generate-contributing-guide |
| categoryId | documentation |
| executorSystemId | agent |
| title | Генерация CONTRIBUTING.md |
| canMigrateToScript | ✅ |

## Описание

Агент генерирует руководство по участию в проекте (CONTRIBUTING.md).

## Типичные разделы

- Добро пожаловать
- Кодекс поведения
- Как начать
- Процесс разработки
- Стиль кодирования
- Процесс PR
- Процесс ревью
- Тестирование
- Документация
- Вопросы и Issues
- Связь

## Источники информации

- Структура проекта
- package.json / composer.json
- Существующие guidelines
- Лицензия проекта
- CI/CD конфигурация

## Форматы

- Markdown
- GitHub flavoured Markdown
- reStructuredText

## Шаблоны

- Шаблон PR
- Шаблон Issue
- Шаблон коммита
- Чеклист для ревью
