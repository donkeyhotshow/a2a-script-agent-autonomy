# suggest-doc-improvements

| Параметр | Значение |
|----------|----------|
| actionId | suggest-doc-improvements |
| categoryId | documentation |
| executorSystemId | agent |
| title | Предложение улучшений документации |
| canMigrateToScript | ✅ |

## Описание

Агент анализирует существующую документацию и предлагает улучшения.

## Анализируемые аспекты

- Полнота документации
- Читаемость
- Актуальность
- Структура
- Примеры использования
- Форматирование
- Орфография и грамматика
- Перекрёстные ссылки

## Критерии оценки

### Полнота
- Охват всех функций
- Описание всех параметров
- Примеры для каждого use case

### Читаемость
- Ясность изложения
- Структура заголовков
- Использование форматирования
- Длина разделов

### Актуальность
- Соответствие коду
- Отсутствие устаревшей информации
- Актуальные ссылки

## Рекомендации

- Добавить примеры
- Разбить длинные разделы
- Добавить диаграммы
- Обновить устаревшую информацию
- Добавить FAQ раздел
- Улучшить навигацию
- Добавить поиск

## Формат вывода

- Список проблем
- Приоритет исправлений
- Конкретные рекомендации
- Примеры улучшений
