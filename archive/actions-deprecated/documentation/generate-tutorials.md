# generate-tutorials

| Параметр | Значение |
|----------|----------|
| actionId | generate-tutorials |
| categoryId | documentation |
| executorSystemId | agent |
| title | Генерация туториалов |
| canMigrateToScript | ✅ |

## Описание

Агент генерирует пошаговые туториалы для изучения и использования проекта.

## Типы туториалов

### По уровню сложности
- Начинающий (Beginner)
- Средний (Intermediate)
- Продвинутый (Advanced)

### По типу
- Быстрый старт (Quick Start)
- Основы (Fundamentals)
- Продвинутые техники
- Интеграции
- Best Practices

## Структура туториала

1. Цель туториала
2. Предварительные требования
3. Установка
4. Пошаговая инструкция
5. Код примеров
6. Ожидаемый результат
7. Частые ошибки
8. Что дальше

## Форматы

- Markdown
- AsciiDoc
- reStructuredText
- HTML
- Интерактивные (Docosaurus, Gitbook)

## Примеры тем

- Установка и настройка
- Создание первого проекта
- Основные концепции
- Работа с базой данных
- Аутентификация
- API интеграции
- Деплой
- Тестирование

## Рекомендации

- Использовать понятный язык
- Добавлять скриншоты
- Включать проверочные шаги
- Предлагать дополнительные материалы
- Поддерживать актуальность
