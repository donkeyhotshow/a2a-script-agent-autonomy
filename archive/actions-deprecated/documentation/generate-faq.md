# generate-faq

| Параметр | Значение |
|----------|----------|
| actionId | generate-faq |
| categoryId | documentation |
| executorSystemId | agent |
| title | Генерация FAQ |
| canMigrateToScript | ✅ |

## Описание

Агент генерирует FAQ (Frequently Asked Questions) на основе анализа проекта и типичных вопросов.

## Типы вопросов

### Общие
- Что это за проект?
- Как начать использовать?
- Какие требования к системе?
- Какие языки поддерживаются?

### Технические
- Как установить?
- Как настроить?
- Как обновить?
- Как мигрировать?

### Проблемы и решения
- Ошибки при установке
- Проблемы с конфигурацией
- Ошибки выполнения
- Performance вопросы

### Лицензия и поддержка
- Какая лицензия?
- Как получить поддержку?
- Есть ли enterprise версия?
- Как связаться?

## Процесс генерации

1. Анализ документации
2. Сбор вопросов из issues
3. Анализ ошибок в коде
4. Изучение аналогичных проектов
5. Генерация структуры FAQ
6. Написание ответов

## Структура FAQ

```
FAQ/
├── general.md
├── installation.md
├── configuration.md
├── troubleshooting.md
└── licensing.md
```

## Форматы

- Markdown
- HTML
- Q&A формат
- Accordion (для веба)

## Рекомендации

- Группировать по темам
- Использовать краткие ответы
- Добавлять ссылки на документацию
- Обновлять регулярно
- Добавлять примеры кода
