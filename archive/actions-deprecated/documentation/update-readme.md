# update-readme

| Параметр | Значение |
|----------|----------|
| actionId | update-readme |
| categoryId | documentation |
| executorSystemId | agent |
| title | Обновление README |
| canMigrateToScript | ✅ |

## Описание

Агент обновляет существующую документацию README.md на основе изменений в проекте.

## Триггеры для обновления

- Добавление новых зависимостей
- Изменение структуры проекта
- Обновление технологического стека
- Изменение API
- Новые функции или возможности
- Изменение требований

## Процесс обновления

1. Чтение текущего README.md
2. Анализ изменений в проекте
3. Определение устаревшей информации
4. Добавление новых разделов
5. Обновление существующих секций
6. Проверка консистентности

## Форматы

- Markdown
- reStructuredText
- HTML
