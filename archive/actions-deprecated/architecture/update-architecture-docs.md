# update-architecture-docs

| Параметр | Значение |
|----------|----------|
| actionId | update-architecture-docs |
| categoryId | architecture |
| executorSystemId | agent |
| title | Обновление архитектурной документации |
| canMigrateToScript | ⏳ |

## Описание

Агент обновляет существующую архитектурную документацию на основе изменений в проекте.

## Триггеры для обновления

- Добавление новых компонентов
- Изменение структуры проекта
- Рефакторинг
- Добавление новых интеграций
- Изменение технологического стека
- Изменение паттернов
- Масштабирование системы

## Процесс обновления

1. Чтение текущей документации
2. Анализ изменений в коде
3. Сравнение с предыдущей версией
4. Обновление диаграмм
5. Обновление описаний
6. Добавление новых разделов
7. Удаление устаревшей информации

## Обновляемые разделы

### Диаграммы
- Component Diagram
- Class Diagram
- Sequence Diagram
- Deployment Diagram

### Описания
- Компоненты системы
- Технологический стек
- API архитектура
- База данных
- Инфраструктура

### ADR (Architecture Decision Records)
- Новые ADR
- Обновление статус решений
- Добавление контекста

## Валидация

- Проверка консистентности
- Соответствие коду
- Актуальность диаграмм

## Форматы

- Markdown
- Mermaid
- PlantUML
- AsciiDoc
