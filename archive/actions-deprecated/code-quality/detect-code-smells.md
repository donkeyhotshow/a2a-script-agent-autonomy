# detect-code-smells

| Параметр | Значение |
|----------|----------|
| actionId | detect-code-smells |
| categoryId | code-quality |
| executorSystemId | script |
| title | Детекция code smells |
| canMigrateToScript | ✅ |

## Описание

Автоматическое сканирование кода для выявления признаков некачественного кода (code smells).

## Примеры code smells

- Дублирование кода
- Слишком длинные функции
- Слишком много параметров
- Магические числа
- Мертвый код
- Циклические зависимости

## Инструменты

- ESLint
- SonarQube
- ReSharper
- Pylint
- PHPMD
