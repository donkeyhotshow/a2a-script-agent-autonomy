# generate-code

| Параметр | Значение |
|----------|----------|
| actionId | generate-code |

## Описание

Агент генерирует код на основе описания требований, спецификаций или существующих паттернов.

## Типы генерируемого кода

- CRUD операции
- API endpoints
- Database models
- Business logic
- UI components
- Tests
- Configuration
- Scripts

## Входные данные

- Текстовое описание
- User stories
- API спецификации
- Database schema
- Диаграммы
- Примеры кода

## Требования к качеству

- Соблюдение coding standards
- Type safety
- Error handling
- Documentation
- Testability
- Security best practices

- JavaScript/TypeScript
- Python
- PHP
- Java

- Rust
- и другие
