# Механические задачи (без AI)

Это задачи, которые решаются по чётким правилам, без понимания семантики кода.

---

## 1. Импорты и пути

### 1.1 Исправление импортов после перемещения файлов
- **Триггер:** "исправить импорты", "обновить импорты", "неверные импорты"
- **Действие:** Найти все импорты перемещённого файла, обновить пути
- **Данные:** Старый путь, новый путь
- **Алгоритм:** grep + replace

### 1.2 Удаление неиспользуемых импортов
- **Триггер:** "удалить неиспользуемые импорты", "очистить импорты"
- **Действие:** Найти импорты, где класс не используется в файле
- **Алгоритм:** AST-парсинг + поиск использования

### 1.3 Добавление недостающих импортов
- **Триггер:** "добавить импорты", "импорт не найден"
- **Действие:** Найти класс в проекте, добавить import
- **Алгоритм:** Поиск класса + AST-вставка

---

## 2. Namespaces (PHP/Laravel)

### 2.1 Обновление namespace после перемещения файла
- **Триггер:** "обновить namespace", "исправить namespace"
- **Действие:** Изменить namespace в файле согласно новой директории
- **Алгоритм:** Замена строки namespace

### 2.2 Обновление use statements
- **Триггер:** "обновить use", "исправить use statements"
- **Действие:** Найти все use старого класса, заменить на новый
- **Алгоритм:** grep + replace

---

## 3. Синхронизация

### 3.1 Синхронизация названия класса и файла
- **Триггер:** "синхронизировать класс и файл"
- **Действие:** Переименовать файл или класс
- **Алгоритм:** Проверка соответствия + rename

---

## 4. Форматирование

### 4.1 Сортировка импортов
- **Триггер:** "отсортировать импорты"
- **Действие:** Сортировка по алфавиту/длине
- **Алгоритм:** AST + sort

### 4.2 Форматирование кода
- **Триггер:** "отформатировать", "привести к стандарту"
- **Действие:** Prettier, ESLint, PHP-CS-Fixer
- **Алгоритм:** Вызов внешнего инструмента

---

## 5. Поиск

### 5.1 Найти все использования класса
- **Триггер:** "где используется", "найти использования"
- **Действие:** grep по проекту
- **Алгоритм:** grep + фильтрация

### 5.2 Найти файл по имени класса
- **Триггер:** "найти файл", "где находится класс"
- **Действие:** Поиск файла с именем класса
- **Алгоритм:** glob + match
