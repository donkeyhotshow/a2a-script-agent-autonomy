# Предложения по архитектуре системы

## Из симуляции следует

1. **Меню возможностей** — сначала механические, потом use-cases с AI
2. **Скрипты сценариев** — все сценарии проработаны и заскриптованы
3. **Механизм обучения AI** — система пустая, нужен способ обучения

## Предложение 1: Меню возможностей

```
┌─────────────────────────────────────┐
│ Меню возможностей                   │
├─────────────────────────────────────┤
│ Механические задачи:                │
│   • Исправить импорты               │
│   • Исправить namespace             │
│   • Форматировать код               │
│   • Найти дубликаты                 │
│                                     │
│ Use-cases с AI:                     │
│   • Рефакторинг                     │
│   • Добавить функционал             │
│   • Исправить баги                  │
│   • Оптимизация                     │
└─────────────────────────────────────┘
```

## Предложение 2: Скрипты сценариев

Каждый сценарий = скрипт с шагами:

```javascript
// scenario: fix-imports
{
  name: "Исправить импорты",
  type: "mechanical",
  steps: [
    { action: "scan-php-files", output: "files" },
    { action: "extract-imports", input: "files", output: "imports" },
    { action: "find-exports", input: "imports", output: "mappings" },
    { action: "apply-fixes", input: "mappings" },
    { action: "report-unresolved", if: "has-unresolved" }  // AI needed
  ],
  fallback: "ask-ai"  // если 1% не найден
}
```

## Предложение 3: Механизм обучения AI

Система учится от внешнего AI:

```
Пользователь → AI → Система
                ↓
         Новый сценарий/скрипт
                ↓
         Сохранение в базе
```

**Формат обучения:**
```javascript
{
  trigger: "пользователь просит X",
  scenario: { ... },
  learned: "2026-02-23"
}
```

## Что нужно реализовать

### На клиенте

1. **Меню** — отображение возможностей
2. **Исполнитель сценариев** — запуск скриптов
3. **Обратная связь** — когда нужен AI

### На сервере

1. **Хранилище сценариев** — база скриптов
2. **Классификатор** — определение типа задачи
3. **Обучение** — приём новых сценариев от AI
