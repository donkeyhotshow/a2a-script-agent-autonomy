# Archive: Actions Legacy

Это архив старых actions, которые были переработаны в новую систему.

## Структура

Старые actions имели формат:
- actionId
- categoryId
- executorSystemId
- title
- Описание с примерами кода

## Миграция

Новый формат:
```yaml
action_id: "глагол-объект"
description: "Краткое описание"
context: "Контекст"
steps: "Человекопонятные шаги"
```

## Где найти

Исходные файлы были в: `a2a-server/src/acions/`

Переработаны в: `a2a-server/src/actions/`

## Примечание

Эти файлы оставлены для референса. Не используются в новой системе.
