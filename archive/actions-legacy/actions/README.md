# Actions - Новая система

## Концепция

**Actions** - это человекопонятные сжатые инструкции для интерпретации системой (ollama/rnj-1).

Action - это НЕ код, а текстовое описание того что нужно сделать.

## Структура Action

```yaml
action_id: "глагол-объект"
description: "Краткое описание"
context: "Что нужно знать для выполнения"
steps: "Как это делается (человекопонятно)"
```

## Примеры

### fix-vue-imports
```
Исправить сломанные импорты в Vue файлах после рефакторинга

Контекст: Vue 3, Vite, aliases (@ -> resources/js)
Шаги:
1. Найти все файлы с import
2. Определить тип пути (alias/relative/npm)
3. Проверить существование файлов
4. Заменить неверные пути
5. Запустить lint для проверки
```

### generate-crud
```
Сгенерировать CRUD операции для сущности

Контекст: Laravel, Eloquent
Шаги:
1. Создать миграцию
2. Создать модель
3. Создать контроллер
4. Создать репозиторий
```

## Поиск

Система использует ollama для семантического поиска подходящего action по description.
