# Вариант 4: Граф = шаблоны задач

**Суть:** Граф — структура возможных задач: шаги, требуемые файлы, порядок действий.

**Источник данных:** Ручные шаблоны (YAML/JSON). Пример: задача "добавить валидацию" → шаг 1: Request, шаг 2: Controller, шаг 3: тесты.

**Роль в системе:**
- new_task сопоставляется с шаблоном
- request_files формируются по шаблону, не по извлечению
- Прогресс: на каком шаге мы

**Не делает:** Не извлекает структуру из кода. Индекс даёт поиск, граф даёт план.
