# Plan: fix-vue-imports-alternatives — Альтернативные подходы

## Цель

Документировать альтернативные алгоритмы для исправления Vue импортов.

## Варианты алгоритма

### Вариант 1: Grep-based
Использование `grep` для поиска импортов:
```
1. grep -r "from '\.\."  → получить все относительные импорты
2. resolve paths         → определить правильные пути
3. sed/editor.apply      → применить изменения
```

### Вариант 2: AST-based
Использование парсера AST (например, `vue-eslint-parser`):
```
1. parse Vue files       → получить AST
2. extract imports       → найти все import statements
3. resolve modules       → разрешить пути через node resolver
4. write-back            → записать исправленные файлы
```

### Вариант 3: LLM-assisted
Использование LLM для сложных случаев:
```
1. detect broken imports → найти проблемные импорты
2. categorize            → AI категоризирует по сложности
3. auto-fix (simple)    → автоматические простые исправления
4. llm-fix (complex)    → LLM для сложных случаев
5. review               → показать результаты пользователю
```

### Вариант 4: LLM-assisted
Использование LLM для сложных случаев:
```
1. detect broken imports → найти проблемные импорты
2. categorize            → AI категоризирует по сложности
3. auto-fix (simple)    → автоматические простые исправления
4. llm-fix (complex)    → LLM для сложных случаев
5. review               → показать результаты пользователю
```

## Сравнение вариантов

| Вариант | Точность | Скорость | Сложность |
|---------|----------|----------|-----------|

## Recommendation

Текущая реализация (`fix-vue-imports`) использует script-based подход (скрипты на клиенте). 
Для улучшения рекомендуется:
1. Добавить AST-based резолвинг для точности
2. Использовать LLM как fallback для сложных случаев
