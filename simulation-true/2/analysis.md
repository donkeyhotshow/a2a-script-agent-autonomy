# Simulation 2 - Analysis

## Случай: Action НЕ найден в базе

Когда запрашиваемая задача не имеет соответствующего action в базе [`a2a-server/src/acions/`](a2a-server/src/acions/), система предлагает использовать **ollama (rnj-1)** для генерации действий.

---

## Workflow: LLM Action Generator

### Этап 1: Генерация общих шагов

```
Пользователь: "создать новую фичу авторизации"
         ↓
    Ollama (rnj-1) генерирует общий список шагов
         ↓
    Результат:
    [
      { "id": 1, "title": "Создать модель данных", "description": "..." },
      { "id": 2, "title": "Создать миграцию", "description": "..." },
      { "id": 3, "title": "Создать контроллер", "description": "..." },
      { "id": 4, "title": "Создать представления", "description": "..." }
    ]
         ↓
    Пользователь: Подтвердить или Отклонить (перегенерировать)
```

**Промт для ollama:**
```
Разбей задачу '{task}' на 3-7 общих шагов. 
Верни JSON массив где каждый элемент имеет поля: id, title, description.
```

---

### Этап 2: Генерация подпунктов (итеративно)

После выбора общих шагов, для каждого шага ollama генерирует подпункты **по одному за итерацию**:

```
Шаг 1: "Создать модель данных"
         ↓
    Ollama генерирует подпункты:
    [
      { "id": "1.1", "title": "Определить поля", "description": "..." },
      { "id": "1.2", "title": "Добавить связи", "description": "..." }
    ]
         ↓
    Пользователь: Подтвердить или Отклонить
         ↓
    Переход к следующему шагу...
```

**Промт для ollama:**
```
Для шага '{step_title}' - '{step_description}', 
разбей на 2-4 подпункта. Верни JSON массив.
```

---

### Этап 3: Генерация скрипта

После выбора подпунктов, ollama генерирует **исполняемый скрипт** для конкретного шага:

```
Шаг 1.1: "Определить поля"
         ↓
    Ollama генерирует скрипт (PHP/Laravel):
    <?php
    
    namespace App\Models;
    
    use Illuminate\Database\Eloquent\Model;
    
    class AuthFeature extends Model
    {
        protected $table = 'auth_features';
        
        protected $fillable = [
            'name',
            'email',
            'password',
        ];
    }
    
    ?>
         ↓
    Клиент выполняет скрипт
         ↓
    Результат показан пользователю
```

**Промт для ollama:**
```
Сгенерируй исполняемый скрипт для шага '{step_title}'. 
Учти контекст проекта: {framework: laravel, vue}.
```

## User Flow

```
┌─────────────────────────────────────────────────────────────┐
│  Action не найден в базе                                    │
│  ↓                                                          │
│  [1] LLM Action Generator (ollama)                         │
│  [2] Auto-AI режимы                                         │
│  ↓                                                          │
│  Пользователь выбирает [1]                                  │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  Phase 1: Генерация общих шагов                             │
│  ↓                                                          │
│  Ollama → [step1, step2, step3, step4]                      │
│  ↓                                                          │
│  Пользователь: ✓ Подтвердить / ↻ Перегенерировать           │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  Phase 2: Генерация подпунктов (итеративно)                 │
│  ↓                                                          │
│  Для каждого выбранного шага:                               │
│    Ollama → [substep1, substep2]                            │
│    Пользователь: ✓ / ↻                                     │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  Phase 3: Генерация скрипта                                 │
│  ↓                                                          │
│  Ollama → Исполняемый код                                   │
│  ↓                                                          │
│  Клиент выполняет → Результат пользователю                  │
└─────────────────────────────────────────────────────────────┘
```
