## Архитектура

### 1.1 Реализация TaskDetailAnalyzer

**Текущее состояние:** Частично реализовано в `utils/task-detail-analyzer.ts`  
**Проблема:** Базовый анализ есть, но нет глубокой семантики  
**Улучшение:**
- Добавить NLP/embedding анализ для определения уровня детализации
- Интегрировать с RAG для семантического поиска похожих задач
- Реализовать classification: mechanical vs semantic

**Файлы:** `a2a-server/src/utils/task-detail-analyzer.ts`

---

### 1.3 Итеративная обработка задач

**Текущее состояние:** Базовый flow реализован в `request-processor.service.ts`  
**Проблема:** Нет полной поддержки итераций  
**Улучшение:**
- Реализовать полный workflow: Iter1 → Iter2 → IterN
- Добавить state machine для отслеживания итераций
- Интегрировать `external-ai-trigger` для финальной итерации

**Файлы:** `a2a-server/src/services/request-processor.service.ts`

## Протокол

### 2.1 Расширение JSON API

**Текущее состояние:** Базовый протокол в `docs/protocol-json-api.md`  
**Проблема:** Неполный - нет questions, fixes в полном объёме  
**Улучшение:**
- Добавить поле `questions[]` для уточнений
- Добавить поле `fixes[]` для инструкций по исправлению
- Добавить поле `scan_results` для результатов сканирования
- Добавить поле `iterations` для отслеживания итераций

**Пример расширенного ответа:**
```
json
{
  "outcome": "need_files",
  "questions": ["Which model stores users?"],
  "fixes": [
    { "type": "add_relation", "target": "User", "relation": "hasMany" }
  ],
  "iterations": { "current": 1, "max": 5 }
}
```

---

### 2.2 Версионирование протокола

**Текущее состояние:** Нет версионирования  
**Проблема:** Несовместимость при изменениях  
**Улучшение:**
- Добавить заголовок `Accept-Version: 1.0.0`
- Документировать изменения между версиями
- Реализовать backward compatibility

## Сервер (a2a-server)

### 3.1 Классификатор задач (Mechanical vs Semantic)

**Текущее состояние:** Нет отдельного классификатора  
**Проблема:** Не определено какая задача требует AI, а какая mechanical  
**Улучшение:**
- Создать `task-classifier.service.ts`
- Определить правила классификации:
  - Mechanical: "fix imports", "add field", "rename method"
  - Semantic: "implement login", "add feature"

**Новые файлы:** `a2a-server/src/services/task-classifier.service.ts`

---

### 3.2 Анализатор PSR-4

**Текущее состояние:** Нет анализа namespace  
**Проблема:** Не проверяется корректность PSR-4  
**Улучшение:**
- Создать `psr4-analyzer.service.ts`
- Парсить composer.json для получения autoload правил
- Проверять соответствие namespace → path

**Новые файлы:** `a2a-server/src/services/psr4-analyzer.service.ts`

---

### 3.3 Генератор инструкций (fixes)

**Текущее состояние:** Нейроны генерируют injected_content, не структурированные fixes  
**Проблема:** Клиент не получает чёткие инструкции  
**Улучшение:**
- Создать `instruction-generator.service.ts`
- Стандартизировать формат fixes[]
- Интегрировать с legacy нейронами для генерации исправлений

**Файлы:** `a2a-server/src/services/instruction-generator.service.ts`

---

### 3.4 Улучшение entity recognizer

**Текущее состояние:** Базовое распознавание в `entity-recognizer.service.ts`  
**Проблема:** Ограниченный набор сущностей  
**Улучшение:**
- Добавить распознавание Vue 3 Composition API
- Добавить TypeScript type inference
- Добавить поддержку React компонентов
- Улучшить relation detection

**Файлы:** `a2a-server/src/services/entity-recognizer.service.ts`

---

### 3.5 Session Context Management

**Текущее состояние:** Есть базовый `session-context.service.ts`  
**Проблема:** Не полностью интегрирован в workflow  
**Улучшение:**
- Расширить хранение контекста между итерациями
- Добавить cleanup старых сессий
- Интегрировать с PhaseMachine

**Файлы:** `a2a-server/src/services/session-context.service.ts`
