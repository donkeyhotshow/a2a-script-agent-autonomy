# Workflow: AI Prompt - от запроса до выполнения

## Обзор

Данный ворклоу описывает полный цикл обработки задачи от пользователя до её выполнения AI-агентом.

## Этапы выполнения

### Этап 1: Получение задачи от пользователя

**Входные данные:**
- Сырой запрос пользователя
- Контекст проекта
- Файловая структура
- Текущее состояние рабочей директории

**Действия:**
1. Принять и проанализировать запрос
2. Определить область действия задачи
3. Идентифицировать необходимые инструменты
4. Оценить сложность и время выполнения

**Результат:**
- Первичное понимание задачи
- Список требуемых файлов
- Предварительный план действий

---

### Этап 2: Уточнение и допрос (Clarification)

**Цель:** Уточнить неопределённости и получить недостающую информацию.

**Вопросы для уточнения:**

1. **Область применения**
   - Какие файлы/директории затрагиваются?
   - Какие пакеты или модули involved?

2. **Ожидаемый результат**
   - Что конкретно должно получиться на выходе?
   - Какие критерии успешного выполнения?

3. **Ограничения**
   - Какие есть технические ограничения?
   - Есть ли запрещённые подходы или технологии?

4. **Контекст**
   - Почему это нужно?
   - Как это вписывается в общую архитектуру?

**Результат:**
- Уточнённая формулировка задачи
- Подтверждённые требования
- Согласованный план

---

### Этап 3: Полная разведка (Deep Research)

**Цель:** Собрать полную информацию о предметной области.

**Действия:**

1. **Анализ структуры проекта**
   - Изучить файловую структуру
   - Определить зависимости
   - Найти связанные компоненты

2. **Исследование кода**
   - Прочитать релевантные исходные файлы
   - Понять существующие паттерны
   - Выявить используемые технологии

3. **Поиск аналогов**
   - Найти похожие реализации в проекте
   - Изучить документацию
   - Проверить best practices

4. **Анализ ограничений**
   - Выявить существующие ограничения
   - Найти потенциальные конфликты
   - Оценить технические риски

**Результат:**
- Полная картина предметной области
- Список файлов для модификации
- План реализации с учётом контекста

---

### Этап 4: Выполнение работ (Implementation)

**Цель:** Реализовать задачу согласно утверждённому плану.

**Процесс:**

1. **Подготовка**
   - Создать резервную копию (при необходимости)
   - Подготовить необходимые инструменты
   - Создать список контроля задач

2. **Реализация**
   - Выполнять задачи согласно плану
   - Использовать подходящие инструменты
   - Следовать кодстайлу проекта

3. **Проверка**
   - Верифицировать изменения
   - Запустить тесты
   - Проверить линтеры

4. **Документация**
   - Обновить документацию
   - Добавить комментарии в коде
   - Зафиксировать изменения

**Результат:**
- Выполненная задача
- Проверенный и задокументированный код

## Пример взаимодействия

### Вход (Пользователь)
```
"добавь новую функцию в API"
```

### Этап 2 (Уточнение)
```
AI: Уточните пожалуйста:
1. Какую именно функцию нужно добавить?
2. В какой endpoint или модуль?
3. Какие параметры должна принимать?
4. Какой ожидаемый формат ответа?
```

### Этап 3 (Разведка)
```
AI: Изучаю структуру проекта...
- Найдены related endpoints
- Определены существующие паттерны
- Выявлены зависимости
```

### Этап 4 (Выполнение)
```
AI: Выполняю задачу...
- Создан новый endpoint
- Добавлена валидация
- Написаны тесты
✓ Задача выполнена
```

## Ключевые принципы

1. **Ничего не принимать на веру** - всегда уточнять неопределённости
2. **Полная разведка** - изучить контекст перед выполнением
3. **Итеративный подход** - маленькие шаги с проверкой
4. **Документирование** - фиксировать все изменения
5. **Верификация** - всегда проверять результат
