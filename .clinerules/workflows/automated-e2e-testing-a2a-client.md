# Workflow: Автоматизированное E2E тестирование A2A Client

## Цель

Обеспечить качество A2A Client через комплексное автоматизированное тестирование с использованием Playwright.

## Типы тестов

### 1. Модульные тесты (Unit Tests)

- Тестирование отдельных функций и компонентов
- Изоляция зависимостей через моки
- Быстрое выполнение

### 2. Интеграционные тесты (Integration Tests)

- Взаимодействие между компонентами
- Тестирование API-взаимодействий
- Проверка работы с VueFlow

### 3. E2E тесты (End-to-End)

- Полное тестирование пользовательских сценариев
- Запуск реального браузера
- Проверка критических путей

## Тестовые сценарии

### Действия (Actions)

- `action-progress.spec.ts` - Отслеживание прогресса выполнения действий
- Проверка индикации выполнения
- Валидация статусов

### Рабочие процессы (Workflows)

- `complete-workflow.spec.ts` - Полный цикл выполнения workflow
- Проверка всех этапов
- Валидация результатов

### Сообщения (Messaging)

- `messaging.spec.ts` - Система обмена сообщениями
- Отправка и получение сообщений
- Обработка ошибок

### Сессии (Sessions)

- `sessions.spec.ts` - Управление сессиями
- Создание, сохранение, загрузка сессий

### UI элементы (UI Controls)

- `ui-controls.spec.ts` - Интерактивные элементы управления
- Кнопки, панели, модальные окна
- Drag-and-drop функциональность

## Конфигурация

```javascript
// playwright.config.ts
export default defineConfig({
  testDir: './tests/e2e',
  timeout: 30000,
  retries: 2,
  use: {
    baseURL: 'http://localhost:5173',
    trace: 'on-first-retry',
  },
});
```

## Запуск тестов

```bash
# Все тесты
npx playwright test

# Конкретный тест
npx playwright test tests/e2e/action-progress.spec.ts

# С UI режимом
npx playwright test --ui

# С генерацией отчёта
npx playwright show-report
```

## Метрики качества

- Покрытие тестами: > 80%
- Время выполнения полного набора: < 5 минут
- Стабильность тестов: > 95% (flaky tests < 5%)
