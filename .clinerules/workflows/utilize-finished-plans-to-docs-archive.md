# Workflow: Использование завершённых планов и архивирование в docs

## Порядок действий

### Шаг 1: Перенос завершённых планов в архив docs

Когда план полностью выполнен (все задачи отмечены как выполненные в чеклисте):

1. Переместить файл плана из `plans/` в `docs/archive/`
2. При необходимости обновить ссылку в основной документации

### Шаг 2: Проверка других планов на завершённость

После переноса завершённых планов:

1. Проверить оставшиеся планы в директории `plans/`
2. Для каждого плана проверить задачи на выполненность:
   - Открыть файл плана
   - Проверить чеклист задач (`- [ ]` vs `- [x]`)
   - Определить, все ли задачи выполнены

### Шаг 3: Отметка выполненных задач в чеклисте

При проверке плана:

1. Найти чеклист в документе плана
2. найди неотмеченые выполненые задачи . Отметить выполненные задачи: `- [ ]` → `- [x]`
3. Если все задачи выполнены → план готов к архивированию (Шаг 1)
4. Найди неотмеченые выполненые задачи .

## Пример чеклиста в плане

```markdown
## Чеклист задач

- [x] Задача 1 выполнена
- [x] Задача 2 выполнена
- [ ] Задача 3 ещё не выполнена
```

## Важно

- **Сначала** архивируем завершённые планы
- **Потом** проверяем оставшиеся планы на предмет выполненных задач
- Регулярно обновляем чеклисты в документах планов
