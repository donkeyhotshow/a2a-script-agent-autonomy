# Структура системы

## Основные компоненты

### Ядро системы

- **workflow-engine.js** - Главный движок системы
- **decision-engine.js** - Двигатель принятия решений
- **cli.js** - Командная строка для управления

### Рабочие директории

- **scripts/** - Скрипты системы
- **tracking/** - Отслеживание изменений
- **reviews/** - Система ревью
- **questions/** - Вопросы к пользователю

### Конфигурационные файлы

- **workflow-state.json** - Состояние текущей сессии
- **workflow-config.json** - Настройки системы
- **qtu-config.json** - Настройки QTU (вопросов к пользователю)

## Как работает система

1. **Запуск** - Начинается с workflow-engine.js
2. **Анализ** - Система сканирует документы
3. **Принятие решений** - decision-engine.js выбирает стратегию
4. **Обработка** - Выполняется обработка документов
5. **Контроль** - Проверяется качество и результаты

## Важные моменты

- Все временные файлы хранятся в .clinerules/
- Документация проекта - в docs/
- Система может спрашивать пользователя через QTU
- Результаты сохраняются в JSON файлах
