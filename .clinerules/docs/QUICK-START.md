# Quick Start Guide

## Что это за система?

Это система управления документацией проекта. Она помогает:

- Анализировать существующую документацию
- Обновлять устаревшие документы
- Создавать новую документацию
- Контролировать качество и актуальность

## Как пользоваться?

### 1. Запуск системы

```bash
# Запустить анализ документации
node .clinerules/scripts/workflow-engine.js --start --priority medium

# Проверить статус
node .clinerules/scripts/workflow-engine.js --status

# Остановить (если нужно)
node .clinerules/scripts/workflow-engine.js --stop --reason "manual_stop"
```

### 2. Что делает система?

1. **Анализ** - находит все документы в проекте
2. **Классификация** - определяет приоритеты обработки
3. **Обработка** - обновляет или создает документы
4. **Контроль качества** - проверяет результаты

### 3. Где смотреть результаты?

- Статус: `node .clinerules/scripts/workflow-engine.js --status`
- Отчет: `node .clinerules/scripts/workflow-engine.js --report`
- Документы: в папке `docs/`

### 4. Что нужно от вас?

- **Проверять результаты** после завершения
- **Подтверждать изменения** если система спрашивает
- **Править документы** если что-то не так

## Важные файлы

- `.clinerules/workflow-state.json` - состояние системы
- `.clinerules/docs/` - документация о системе
- `docs/` - основная документация проекта

## Если что-то пошло не так

1. Остановите систему: `--stop`
2. Проверьте логи: `--status`
3. Запустите заново: `--start`

## Подсказки

- Используйте `--priority high` для срочных задач
- Используйте `--priority low` для фоновой обработки
- Система сама спросит если нужно ваше решение
